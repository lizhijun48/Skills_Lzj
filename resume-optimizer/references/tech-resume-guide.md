# 技术岗位简历写作规范参考

## 一、各板块写法要点

### 基本信息

必须包含：
- 姓名
- 手机号码
- 邮箱地址
- GitHub 主页 URL（有则填，没有可省略）
- 个人博客 / LeetCode 主页（可选，有实质内容才填）

不建议填写：
- 照片（互联网技术岗通常无需照片）
- 年龄、民族、政治面貌（非必要）
- 家庭住址（填城市即可）

---

### 技能概览

格式建议：

```
编程语言：Go（熟悉）、Python（熟悉）、Java（了解）
后端框架：Gin、Spring Boot、FastAPI
数据库：MySQL、Redis、MongoDB、Elasticsearch
中间件：Kafka、RabbitMQ、Nginx
云平台 & 工具：Docker、Kubernetes、Git、Linux
```

注意：
- 分类列出，不要堆砌成一段
- 标注熟练程度（熟悉/了解/精通），不要虚报「精通」
- 只写真实使用过的技术

---

### 工作 / 实习经历

格式模板：

```
公司名称 | 职位名称 | 起止时间（YYYY.MM - YYYY.MM）
[团队/部门背景一句话介绍（可选）]
• [动词] [做了什么] [技术方案] [结果/量化指标]
• [动词] [做了什么] [技术方案] [结果/量化指标]
• [动词] [做了什么] [技术方案] [结果/量化指标]
```

**强动词参考列表：**

| 场景 | 推荐动词 |
|------|---------|
| 开发建设 | 设计、构建、实现、重构、开发、落地 |
| 优化改进 | 优化、提升、降低、缩短、改善、简化 |
| 主导推动 | 主导、推动、牵头、协调、统筹 |
| 数据分析 | 分析、挖掘、建模、调研、评估 |
| 运维部署 | 部署、迁移、搭建、维护、监控 |

**量化指标参考：**
- 性能类：响应时间（P99/平均）、QPS/TPS、资源利用率
- 规模类：日活/MAU、数据量（万/亿条）、业务覆盖用户数
- 效率类：研发效率提升 X%、上线时间缩短 X 天
- 质量类：Bug 率下降 X%、接口错误率 < X%

---

### 项目经历

格式模板：

```
项目名称 | 技术栈关键词 | 起止时间
项目背景：[一句话说明项目目的和规模]
• 负责模块：[说明个人承担的部分]
• 技术亮点：[核心技术难点及解决方案]
• 项目成果：[量化结果]
```

项目选择建议（按优先级）：
1. 有明确技术难点 & 量化结果的项目
2. 与目标岗位技术栈高度匹配的项目
3. 开源项目 / Star 数较高的个人项目
4. 公司内部系统重构 / 性能优化项目

---

### 教育背景

标准格式：

```
学校名称 | 专业名称 | 学历（本科/硕士/博士）| 起止年份
• GPA：3.8/4.0（若 GPA ≥ 3.5 才写）
• 相关课程：数据结构、操作系统、计算机网络、数据库原理
• 荣誉：国家奖学金、校级优秀毕业生（若有）
```

## 二、常见问题 & 反模式

| 问题 | 反模式 | 正确做法 |
|------|--------|---------|
| 描述太虚 | 「负责后端开发」 | 「基于 Spring Boot 实现订单服务 API，支持峰值 5000 QPS」 |
| 没有量化 | 「显著提升了性能」 | 「将 P99 延迟从 800ms 降至 120ms」 |
| 技术栈模糊 | 「熟悉后端技术」 | 「熟悉 Go/Python，有 Gin/FastAPI 框架开发经验」 |
| 篇幅过长 | 一个职位 8 条以上 | 每段经历控制 3-5 条要点 |
| 形容词堆砌 | 「高效、优秀、出色完成」 | 直接写结果数字，让成绩说话 |
| 被动语气 | 「参与了xxx系统的开发」 | 「独立设计并实现 xxx 模块」 |

## 三、大厂 JD 高频关键词（供参考）

### 后端工程师
分布式系统、微服务、高并发、高可用、性能调优、RPC、消息队列、缓存、服务治理、容器化

### 算法/机器学习工程师
模型训练、推理优化、特征工程、召回精排、A/B实验、TensorFlow/PyTorch、大模型、LLM、RAG、向量数据库

### 数据开发工程师
数仓建设、数据治理、ETL、实时计算、Flink、Spark、数据建模、数据质量、指标体系

### 前端工程师
React/Vue、工程化、性能优化、SSR、微前端、Webpack/Vite、TypeScript、跨端开发

## 四、篇幅建议

| 工作年限 | 建议页数 |
|---------|---------|
| 应届生 / 0-1 年 | 1 页（严格控制） |
| 1-5 年 | 1-2 页 |
| 5 年以上 | 2 页以内（精选经历） |
