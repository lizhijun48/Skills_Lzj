## 四、路线图决策框架

### 优先级排序（每周期评审）

| 候选举措 | 战略对齐(0-10) | 用户价值(0-10) | 技术可行性(0-10) | 综合分 | 入选 |
|---------|----------------|----------------|-----------------|--------|------|
| | | | | | |

### 路线图健康检查

- [ ] 每个主题/目标都有可量化的成功指标
- [ ] 路线图覆盖了至少 2 个战略优先级
- [ ] 有 20-30% 的「缓冲空间」应对突发需求
- [ ] 技术债务/基础设施投入占比 ≥ 15%
- [ ] 已与关键干系人（销售/客户成功/工程）对齐
