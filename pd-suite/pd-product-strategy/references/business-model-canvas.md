# 商业模式画布（Business Model Canvas）

> 用途：系统化梳理产品设计商业模式，识别价值创造与捕获逻辑。
> 适用场景：新产品立项、商业模式创新、投资人路演准备。
> 对标：NPDP Ch1 + `pd-product-strategy` Step 2

---

## 一、商业模式画布（9 要素）

```
┌─────────────────────────────────────────────────────────────────┐
│  合作伙伴(Key Partners)       关键活动(Key Activities)    价值主张(Value Proposition)  客户关系(Customer Relationships)  客户细分(Customer Segments)│
│  • 谁是我们的重要伙伴？      • 我们的核心价值活动？    • 我们向客户交付什么价值？   • 我们与客户建立什么关系？    • 我们在为谁创造价值？│
│  • 谁是我们的重要供应商？    • 我们的核心资源？       • 我们帮客户解决什么问题？   • 如何获取客户？             • 最重要的客户是谁？│
│                            •                       • 我们满足哪些客户需求？       • 如何留存客户？             │
├─────────────────────────────────────────────────────────────────┤
│  供应商(Suppliers)          关键资源(Key Resources)     渠道通路(Channels)│
│  • 核心资源是什么？         • 如何触达客户？│
│  • 资源来源？               • 销售渠道？│
│                             • 沟通渠道？│
├─────────────────────────────────────────────────────────────────┤
│  成本结构(Cost Structure)              |  收入来源(Revenue Streams)│
│  • 最重要的固定成本是什么？            |  • 客户真正愿意付费的是什么？│
│  • 哪些资源最贵？                      |  • 客户目前如何付费？│
│  • 哪些活动最贵？                      |  • 客户更喜欢哪种付费方式？│
└─────────────────────────────────────────────────────────────────┘
```

## 三、常见商业模式类型参考

| 类型 | 典型例子 | 适用场景 |
|------|---------|---------|
| 长尾模式 | 亚马逊、Netflix | 海量小众需求聚合 |
| 多边平台模式 | 淘宝、微信 | 连接多边用户，网络效应 |
| 免费增值模式 | Dropbox、Zoom | 基础免费 + 高级付费 |
| 订阅模式 | SaaS 产品 | 可预测的经常性收入 |
|  razor-and-blade 模式 | 打印机+墨盒 | 低价硬件 + 高价耗材 |
