# 感知图绘制模板（Perceptual Map Template）

> 用途：可视化产品在用户心智中的定位，识别市场空白（White Space）。
> 适用场景：竞品分析、定位策略制定、产品差异化方向决策。

---

## 一、2D 感知图标准格式

**X 轴**：[维度1，如：价格低 ← → 价格高]
**Y 轴**：[维度2，如：功能简单 ← → 功能丰富]

```
       功能丰富
          ↑
          │  A产品 ●
          │         ● B产品
          │  ●C产品
          │         ● D产品
          └──────────────────→ 价格低 → 价格高
```

## 三、感知图构建 3 步法

### Step 1：选定两个关键维度（X 轴 + Y 轴）

选择标准：
- 用户购买决策时的**Top 2 考量因素**
- 竞品之间**差异明显**的维度
- 本产品有**差异化机会**的维度

**常见维度库**：

| 维度类型 | 可选维度 |
|---------|---------|
| 价格相关 | 价格低/高、性价比 |
| 功能相关 | 功能丰富/简单、专业性/通用性 |
| 体验相关 | 易用性、设计感、品牌信任度 |
| 技术相关 | 创新性、稳定性、兼容性 |

---

### Step 2：将竞品和用户认知映射到图上

**数据来源（选一种）**：
- 用户调研：直接问用户「觉得A/B/C产品在XX维度上打几分（1-10分）」
- 专家评分：产品团队内部打分（快速版）
- 第三方评测：引用公开评测数据

**评分记录表**：

| 产品 | X轴得分(1-10) | Y轴得分(1-10) | 数据来源 |
|------|----------------|----------------|---------|
| 竞品A | | | |
| 竞品B | | | |
| 竞品C | | | |
| 本产品（感知中） | | | |
| 本产品（目标） | | | |

---

### Step 3：识别空白区域，制定定位策略

**4 种定位策略**：

| 策略 | 含义 | 适用场景 |
|------|------|---------|
| **填补空白** | 进入竞品未覆盖的象限 | 蓝海市场、差异化明显 |
| **正面挑战** | 放在最接近强势竞品的位置 | 本产品有明显优势、有足够资源打正面战 |
| **侧翼包抄** | 在竞品强势维度的相邻位置 | 避免正面冲突、逐步蚕食 |
| **重新定位** | 改变用户在感知图中的认知位置 | 产品本身未变，但沟通策略调整 |

## 四、感知图与 SWOT / 五力 的关系

| 分析工具 | 回答的问题 | 与感知图的关系 |
|---------|------------|----------------|
| 感知图 | 用户**认为**我们在哪 | 输出：定位策略 |
| SWOT | 我们**实际**强弱在哪 | 输入：感知图维度选择 |
| 五力 | 行业**竞争强度**如何 | 输入：竞品选择范围 |

**联动用法**：
1. 用五力 → 确定需要分析的竞品名单
2. 用 SWOT → 确定本产品的差异化优势维度
3. 用感知图 → 将优势维度可视化，制定定位策略

## 五、完整案例：智能音箱（2016年中国市场）

**维度选择**：X轴 = 价格（低→高），Y轴 = 音质（差→好）

| 产品 | X坐标(1-10) | Y坐标(1-10) |
|------|--------------|--------------|
| 天猫精灵 | 2 | 3 |
| 小米小爱 | 3 | 4 |
| 喜马拉雅小雅 | 5 | 7 |
| 本产品（科大讯飞） | **目标：2** | **目标：8** |

**定位策略**：填补空白 —— 低价 + 高音质（主打性价比音质党）
