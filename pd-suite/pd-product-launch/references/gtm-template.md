# GTM 策略模板（Go-To-Market Template）

> 用途：系统化规划产品从发布到用户手中的完整路径。
> 适用场景：新产品发布、重大版本上线、进入新市场。
> 对标：NPDP Ch3 + `pd-product-launch` Step 3

---

## 一、GTM 策略框架（4P 模型）

### Product（产品策略）
- **核心卖点（One Thing）**：[用户选择我们而不选竞品的唯一理由]
- **差异化定位**：[与竞品的核心差异]
- **发布阶段划分**：
  - MVP 发布（目标用户 _____ 人）
  - 正式发布（目标用户 _____ 人）
  - 规模扩张（目标用户 _____ 人）

### Price（定价策略）
- **定价模型**：[免费增值 / 订阅 / 一次性买断 / 按量计费]
- **价格档位**：
  | 档位 | 价格 | 目标用户 | 核心价值 |
  |------|------|---------|---------|
  | 免费版 | ¥0 | 试用用户 | [限制功能] |
  | 专业版 | ¥XX/月 | 个人专业用户 | |
  | 企业版 | ¥XX/年起 | 企业客户 | |
- **早鸟优惠**：[如有，写明折扣力度和时限]

### Place（渠道策略）
- **主要获客渠道**（按优先级排序）：
  1. [渠道1，如：应用商店搜索]
  2. [渠道2，如：内容营销/SEO]
  3. [渠道3，如：社交媒体投放]
- **渠道资源分配**：
  | 渠道 | 预算占比 | 预期转化率 | KPI |
  |------|---------|------------|-----|
  | | | | |

### Promotion（推广策略）
- **发布活动**：[线上发布会 / 线下沙龙 / KOL 合作 / 限时限量]
- **内容营销**：[白皮书 / 案例研究 / 视频教程]
- **合作伙伴**：[渠道合作 / 生态集成]

## 二、GTM 时间表（发布前 8 周 → 发布后 4 周）

| 时间节点 | 关键动作 | 负责人 | 成功标准 |
|-----------|---------|--------|---------|
| T-8 周 | 确定 GTM 策略 + 定价 | PM | 策略文档评审通过 |
| T-6 周 | 准备营销物料（官网/宣传视频） | 市场/运营 | 物料就绪 |
| T-4 周 | 种子用户内测 | PM/运营 | 50+ 内测用户反馈 |
| T-2 周 | 媒体预热 + KOL 合作 | 市场 | 10+ 篇预热文章 |
| T-1 周 | 全员演练 + 客服培训 | PM | 客服能回答 TOP20 问题 |
| **T-Day（发布日）** | 正式上线 + 发布会 | 全员 | 达成首日 XX 人注册 |
| T+1 周 | 收集首批用户反馈 | PM/客服 | 反馈归档 ≥ 50 条 |
| T+2 周 | 第一个快速迭代版本 | 研发 | 修复 TOP3 问题 |
| T+4 周 | 发布后复盘 + 数据报告 | PM | 复盘会议纪要 |

## 六、风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| 竞品在同一窗口期发布 | 高 | 差异化定位 + 提前 2 周发布 |
| 种子用户反馈不好 | 高 | 预留 2 周缓冲期，根据反馈快速迭代 |
| 渠道投放 ROI 低 | 中 | 准备 2 套渠道方案，随时切换 |
| 客服承接能力不足 | 中 | 提前培训 + 常见问题知识库 |

## 七、GTM 策略检查清单

- [ ] ICP（理想客户画像）已明确（ToB 必填）
- [ ] 4P 策略已填写完整
- [ ] 发布时间表已制定（T-8 到 T+4）
- [ ] 定价策略已确定，且与 `pd-product-launch` Step 2 定价策略一致
- [ ] 成功指标已设置 OKR，且可衡量
- [ ] 风险清单已识别，且有应对方案
- [ ] GTM 策略已与销售/市场/客户成功团队对齐
