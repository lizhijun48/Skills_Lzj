# Go/No-Go 评估评分表（Go-NoGo Scorecard）

> 用途：在立项前对产品机会进行 8 维度量化评估，输出 Go/No-Go 决策。
> 适用场景：新产品立项、重大功能投入决策、资源分配优先级判断。
> 对标：NPDP Ch1 + `pd-go-nogo` Step 2

---

## 一、8 维度评分表（标准版）

| # | 评估维度 | 权重 | 评分(0-10) | 加权分 | 一票否决 |
|---|---------|------|-----------|--------|---------|
| 1 | **市场吸引力**（TAM/SAM/SOM, 增长率） | 15% | | |
| 2 | **技术可行性**（技术成熟度, 团队能力匹配） | 15% | | |
| 3 | **财务回报**（ROI ≥ 30%, NPV > 0, 回收期 < 2年） | 20% | | |
| 4 | **战略契合度**（与公司战略/愿景对齐程度） | 15% | | |
| 5 | **合规与政策风险**（法规/资质/数据合规） | 10% | | ⚠️ 可否决 |
| 6 | **资源可获得性**（人力/预算/设备是否到位） | 10% | | |
| 7 | **竞争态势**（竞争格局, 进入壁垒） | 10% | | |
| 8 | **时机窗口**（是否是最佳进入时机） | 5% | | |
| | **合计** | **100%** | | **=SUM** |

> **评分标准（0-10分）**：
> - 9-10：非常有利，竞争优势明显
> - 7-8：较有利，有竞争力
> - 5-6：一般，需要优化
> - 3-4：不利，有较大风险
> - 0-2：非常不利，不推荐推进

---

## 二、一票否决项检查（必须先过这关）

| 否决项 | 检查标准 | 是否通过 | 说明 |
|---------|---------|---------|------|
| 合规性 | 产品不违反法律法规/行业监管 | ✅/❌ | |
| 核心资源 | 关键资源（专利/牌照/独家数据）可获得 | ✅/❌ | |
| 技术可行性 | 核心技术问题已有解决方案 | ✅/❌ | |
| 市场存在 | TAM > 1亿 或 SAM > 1000万 | ✅/❌ | |

> **规则**：任一否决项为 ❌，直接输出 **No-Go**，无需计算总分。

---

## 三、评分结果判定

| 加权总分 | 决策建议 | 后续动作 |
|-----------|---------|---------|
| ≥ 7.5 | ✅ **Go（推荐推进）** | 进入下一阶段（PRD/立项报告） |
| 6.0 - 7.4 | ⚠️ **Conditional Go（有条件推进）** | 针对低分维度制定改进计划，1个月后重评 |
| < 6.0 | ❌ **No-Go（不推荐推进）** | 终止或搁置，资源转向其他机会 |

## 四、简化版（快速决策，≤ 5 分钟）

仅评估 **4 个核心维度**：

| 维度 | 评分(0-10) | 说明 |
|------|-----------|------|
| 市场吸引力 | | 市场规模 + 增长率 |
| 技术可行性 | | 团队能否做出来 |
| 财务回报 | | ROI 粗略估算 |
| 战略契合度 | | 和公司方向是否一致 |
| **平均分** | **=AVG** | ≥ 7.0 → Go |
