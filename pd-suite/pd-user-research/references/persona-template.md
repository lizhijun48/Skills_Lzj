# 用户画像模板（Persona Template）

> 用途：将用户研究结果转化为具象化的人物档案，指导产品决策。
> 适用场景：PRD 用户分析、功能设计、营销文案撰写。
> 对标：NPDP Ch4 + `pd-user-research` Step 2

---

## 三、Persona 验证检查表

- [ ] 有真实用户数据支撑（访谈 ≥ 3 人，或问卷 ≥ 30 份）
- [ ] 包含「用户原话」（而非 PM 自己编的）
- [ ] 痛点 ≥ 3 条，且对应到需求池（P0/P1/P2）
- [ ] 有行为数据（非纯主观描述）
- [ ] 已分享给研发/设计/运营团队，并获得反馈
- [ ] 已保存到 PRD 的「用户与场景分析」章节

## 四、ToB vs ToC Persona 差异

| 维度 | ToC Persona | ToB Persona |
|------|--------------|--------------|
| 数量 | 3-5 个（覆盖主要用户群） | 1-3 个（每类角色 1 个） |
| 关注点 | 情感/体验/场景 | 效率/ROI/安全合规 |
| 数据来源 | 问卷/App 评论/用户访谈 | 客户访谈/实施记录/CSM 反馈 |
| 决策链 | 个人决策 | 多人决策（使用者/影响者/决策者） |
| 示例 | 「通勤族阿明」「宝妈小丽」 | 「CTO 阿杰」「运维阿强」 |

---

## 五、Persona 应用清单

| 产品环节 | 如何使用 Persona |
|-----------|-------------------|
| PRD 撰写 | 每个功能需求标注「对应哪个 Persona 的哪个痛点」 |
| 交互设计 | 问「阿花会在这里卡住吗？」 |
| 优先级排序 | Persona 痛点强度 × 受影响人数 = 优先级 |
| 营销文案 | 用 Persona 的语言风格写（阿花说「好烦」，别说「效率低下」） |
| 用户测试 | 招募受访者时，按 Persona 匹配度筛选 |

## 六、完整示例：排版工具阿花

```
╔══════════════════════════════════════════════════════╗
║  Persona 名称：运营阿花                                      ║
╠══════════════════════════════════════════════════════╣
║  基本信息：                                                  ║
║  - 年龄：28岁   职业：跨境电商新媒体运营（3人团队）       ║
║  - 公司规模：80人   行业：跨境电商                       ║
║  - 技术敏感度：低（只会用 SaaS 工具）                  ║
║  - 使用频率：每天，日均排版 5-8 篇文章                   ║
╠══════════════════════════════════════════════════════╣
║  🎯 目标与动机                                          ║
║  - 主要目标：每天 18:00 前完成所有公众号排版并发布       ║
║  - 成功标准：排版时间从 3 小时降到 1 小时内             ║
╠══════════════════════════════════════════════════════╣
║  😤 痛点与挫败                                          ║
║  1. 每次排版要手动调字体/行距/段距，重复操作 30 分钟     ║
║  2. 上周排好的文章，这周找不到了，又重排一次            ║
║  3. 同事同时编辑会覆盖我的修改，还要手动合并             ║
╠══════════════════════════════════════════════════════╣
║  ✅ 需求与期望                                          ║
║  - 必须有：一键套用上周排版样式（模板复用）              ║
║  - 最好有：团队素材库（图片/样式统一管理）               ║
║  - 惊喜功能：AI 自动根据文章内容配图                    ║
╠══════════════════════════════════════════════════════╣
║  💬 用户原话                                            ║
║  - "每次排版我都想撞墙，都是重复劳动！"                    ║
║  - "我们的素材散落在每个人电脑里，根本找不到。"            ║
║  - "如果有个模板库，点一下就能套用，我愿意付费。"        ║
╚══════════════════════════════════════════════════════╝
```
