## 三、工作规范

### 3.1 沟通规范
- **日常沟通**：[Slack/企微/飞书] + 频道规则
- **会议规范**：
  - 会前必须发议程
  - 会后 24 小时内发纪要
  - 无议程不开会
- **文档规范**：所有决策留痕（ADR 或会议纪要）
- **紧急联系**：[值班制度 / on-call 规则]

### 3.2 决策机制
| 决策类型 | 决策方式 | 升级路径 |
|---------|---------|---------|
| 日常需求优先级 | PM 决策，团队知情 | 争议 → 集体讨论 |
| 技术方案 | 技术负责人决策 | 争议 → 架构评审 |
| 资源分配 | PM + 技术负责人协商 | 争议 → 向上级升级 |
| 发布决策 | QA + PM 共同签字 | 质量不达标 → 延期 |

### 3.3 冲突解决
1. 直接沟通（1对1，24小时内）
2. 团队讨论（公开、基于事实）
3. 向上级升级（争议无法解决）

## 四、团队文化承诺

- [ ] **用户第一**：所有决策以用户价值为准绳
- [ ] **数据驱动**：假设必须可验证，决策基于数据
- [ ] **快速迭代**：失败是学习，但同一个错误不犯两次
- [ ] **公开透明**：信息默认公开，保密为例外
- [ ] **互相尊重**：质疑观点，不质疑动机

## 五、团队仪式（Rituals）

| 仪式 | 频率 | 目的 | 参与者 |
|------|------|------|--------|
| 每日站会 | 每天 | 同步进度，识别阻碍 | 全员 |
| 迭代复盘 | 每 2 周 | 回顾得失，持续改进 | 全员 |
| 产品评审 | 每月 | 展示成果，获得反馈 | 全员 + 干系人 |
| 1-on-1 | 每月 | 个人成长，情绪关注 | PM + 各成员 |
| 团队建设 | 每季度 | 增强凝聚力 | 全员 |

## 六、团队健康度自检（每季度）

| 维度 | 问题 | 评分(1-5) |
|------|------|----------|
| 目标清晰 | 每个人都知道本季度的核心目标吗？ | |
| 心理安全 | 成员敢于提出异议而不担心报复吗？ | |
| 决策效率 | 决策能够快速做出并被执行吗？ | |
| 技能匹配 | 团队成员的技能与任务匹配吗？ | |
| 意义感 | 成员觉得自己的工作有意义吗？ | |

> **平均分 < 3.5**：需要团队干预（复盘会议 + 改进计划）
