## 补充 PT-001 (pd-product-strategy)

### PESTLE 宏观环境分析

六维度扫描：政治(政策法规/税收/贸易)、经济(GDP/利率/汇率)、社会(人口/文化/数字化)、技术(新兴技术/自动化/IoT)、法律(数据保护/IP/合规)、环境(碳排放/ESG)。每维度识别3-5因素 → 评估影响度x可能性(H/M/L) → 区分机会/威胁 → 制定应急预案。与SWOT互补(宏观vs微观)。

### 波特五力分析

五力逐一评估(高/中/低)：竞争烈度(对手数量/增速/差异化/退出壁垒)、供应商议价力(集中度/切换成本)、买方议价力(集中度/切换成本)、替代品威胁(性价比/切换成本)、新进入者威胁(壁垒/规模经济/网络效应/监管)。综合判定行业吸引力，聚焦2-3个最关键力量。

### 定价策略（7种模型 + Van Westendorp）

7种模型：固定费率、按席位、按用量、分层定价、免费增值、免费增值+用量、价值定价。Van Westendorp四问法：太便宜(质量存疑)/便宜(性价比高)/贵(开始犹豫)/太贵(不会买) → 确定最优价格区间。输出：推荐模型 + 分层定价表 + 验证方法。

### Startup Canvas（11模块）

Part 1 战略9模块：愿景 → 市场细分(JTBD) → 成本定位 → 价值主张(Before→How→After) → 取舍(不做什么) → 关键指标(North Star+OMTM) → 增长策略(PLG/SLG) → 能力(自建/合作) → Can't/Won't测试。Part 2 商业模式2模块：成本结构 + 收入流。验证11模块是否相互增强。

## 补充 PT-002 (pd-innovation-process)

### Opportunity Solution Tree (OST) — Teresa Torres

四层树状结构：
- L1 期望成果 — 单一可衡量指标(如"7日留存至40%")
- L2 机会 — 客户痛点，用客户视角表述。优先级 = Opportunity Score = 重要性 x (1-满意度)
- L3 解决方案 — 每个机会至少3个方案(Product Trio: PM+设计师+工程师)
- L4 实验 — 快速低成本验证，四维度(Value/Usability/Viability/Feasibility)

核心原则：一次聚焦一个指标；只排序问题不让客户设计方案；每机会3+方案再选。

### 假设识别 — 四/八风险维度

四核心风险：Value(是否解决真实问题)、Usability(用户能否学会)、Viability(商业能否支撑)、Feasibility(技术能否实现)。新产品扩展为8类：+Ethics(是否应该做)、Go-to-Market(渠道/时机)、Strategy(竞品复制/PESTLE)、Team(人员/工具/留存)。

### Impact x Risk 假设优先级矩阵

Impact = Opportunity Score x 客户数；Risk = (1-信心度) x 工作量。四象限：高影响+低风险→直接实施；高影响+高风险→设计实验验证；低影响+低风险→延后测试；低影响+高风险→拒绝。

### 实验设计 — 6种类型 + XYZ假设

已有产品6种实验：First-click testing、Fake door tests、Technical spikes、A/B tests、Wizard of Oz、Survey validation。新产品用XYZ假设："至少X%的Y会做Z"。5种Pretotype：Landing Page、Explainer Video、Email Campaign、Pre-Order/Waitlist、Concierge/MVP。核心：衡量行为不衡量意见。

### Mom Test 访谈技巧

脚本四段式：Opening(声明学习非推销) → Warm-Up("告诉我你的典型一天") → Core(行为过去时："上次你做X是什么时候") → Wrap-Up("有什么我没问到的")。5种追问："能多说说吗"/"为什么"(温和2-3次)/"举个具体例子"/"然后呢"/"那让你感觉如何"。铁律：问生活不问想法，问过去不问未来，80/20少说多听。

### Product Trio 多视角构思

PM+设计师+工程师共同构思，每视角生成5个想法。PM视角(商业价值/战略匹配)、设计师视角(用户体验/可用性/愉悦感)、工程师视角(技术可能性/数据杠杆/可扩展)。排序：战略匹配 x 成果影响 x 可行性 x 差异化。

## 补充 PT-006 (pd-requirements-design)

### 功能请求分拣 — 四级优先级

流程：主题聚类 → 每主题统计(请求数+驱动用户细分+情绪信号) → 五维评估(Impact x Strategic Alignment x Effort x Risk x Revenue Signal)。四级：P1 Act Now / P2 Plan Next / P3 Collect More Signal / P4 Decline or Defer。关键：寻找请求背后的真实需求。

## 补充 PT-007 (pd-prd-writing)

### Pre-Mortem 预验尸法（Tigers/Paper Tigers/Elephants）

假设产品14天后上线并失败，逆向追溯。三类：Tigers(基于证据的真实风险，必须行动) → 按紧急度分Launch-Blocking/Fast-Follow/Track；Paper Tigers(表面合理但被夸大的担忧，记录对齐干系人)；Elephants(房间里的大象，未充分讨论的隐性隐患，需上线前调查)。

### Outcome Roadmap 成果导向路线图

转换公式：`Enable [客户群体] to [期望成果] so that [业务影响]`。逐项识别Output → 追问"为什么做？解决什么问题？改善什么指标？" → 改写为Outcome Statement。

## 补充 PT-008 (pd-product-launch)

### 滩头阵地策略 — Geoffrey Moore

四维度评估：痛点紧迫度(日常挫败/生产力损失/情绪紧迫)、付费意愿(已有预算/ROI清晰/决策者自主)、可赢份额(3-18月内60-70%份额)、转介绍潜力(行业社群/口碑文化/网络效应)。执行六步：列候选→调研痛点(10+访谈)→评估付费(ROI)→评估可赢性→识别转介绍路径→选最高分。核心：滩头越窄越好，集中资源先主导。

### 增长飞轮 — 5种类型 + 系数

5种：病毒循环(用户创建→分享→注册)、使用循环(创建→分享→消费→活跃)、协作循环(创建→邀请协作→发现价值)、UGC循环(发现→创建→分享→发现)、推荐循环(推荐→加入→奖励→更多)。飞轮系数 = 每用户邀请数 x 转化率。设计五步：定义核心价值→评估适配度→设计机制→计算系数→先实现最高杠杆飞轮。

### GTM 动作矩阵 — 7种类型

Inbound(集客)/Outbound(外拓)/Paid(付费)/Community(社区)/Partner(合作)/ABM(客户营销)/PLG(产品驱动)。每种按产品特征1-10分评分。选择2-4种组合，确定主次+资源配置+90天路线图。

### 竞争作战卡 — 8模块

公司概览 → 快速对比表 → 我方优势(含证据) → 对方优势(含反制) → 异议应对表 → 埋雷问题(暴露竞品弱点) → 赢/输模式(各3条) → 对话开场白(替换策略/竞争策略)。一页纸可扫描，每季度更新。

### ICP 理想客户画像 — 四维框架

人口统计(规模/行业/地理/职位) + 行为模式(评估方式/购买流程/技术素养) + JTBD(功能/情感/社会/回避) + 需求痛点(具体痛点/现有替代/影响/预算)。六步执行：收集数据→按价值分层→提取共性→识别行为→定义JTBD→记录痛点。含不合格标准(谁不是好客户)。

## 补充 PT-011 (pd-product-operations)

### North Star Metric + 三层商业游戏

North Star = 单一客户价值指标，是商业成功的领先指标。3种商业游戏分类：Attention(注意力型，如媒体)、Transaction(交易型，如电商)、Productivity(生产力型，如SaaS)。7验证 criteria。Input Metrics(3-5个可操作杠杆) + Health Metrics(护栏) + Counter-Metrics(防Goodhart定律)。好指标4标准：可理解/可比较/比率速率/改变行为。

### 队列分析 — 五步方法论

数据读取 → 量化分析(留存率/参与度/流失模式) → 可视化(留存热力图/进展折线图) → 洞察识别(早期流失/后期变化/功能采用) → 后续研究(流失访谈/胜负分析/A-B测试)。注意：至少3-4个队列才有意义；区分季节性vs真实趋势。

### A/B 测试分析 — 六步决策

理解实验 → 验证设计(样本量/时长/SRM/新奇效应) → 计算显著性(z检验/卡方/p值/置信区间) → 检查护栏 → 决策(Ship/Investigate/Extend/Stop/Don't ship) → 输出报告。核心：统计显著 != 实际显著；样本不足时答案是"延长"不是"无效果"。

## 补充 PT-013 (pd-tools-metrics)

### 9种优先级排序框架速查

| 框架 | 公式/方法 | 适用场景 |
|------|---------|---------|
| Opportunity Score | 重要性 x (1-满意度) | 需求优先级 |
| ICE | Impact x Confidence x Ease | 快速排序 |
| RICE | (Reach x Impact x Confidence) / Effort | 大团队 |
| KANO | 满意/不满意双轴 | 功能分类 |
| MoSCoW | Must/Should/Could/Won't | 版本规划 |
| Weighted Scoring | 多维度加权 | 复杂决策 |
| Pairwise Comparison | 两两比较 | 小集合 |
| Cost of Delay | 价值/时间 | 经济优先级 |
| WSJF | Cost of Delay / Job Size | SAFe框架 |

### 四层指标架构

L1 North Star(客户价值指标) → L2 Input Metrics(3-5个可操作杠杆) → L3 Health Metrics(护栏，定义健康范围) → L4 Business Metrics(收入/成本/单位经济)。Counter-Metrics防止Goodhart定律。

## 补充 S-018 (resume-optimizer)

### PM简历 XYZ+S 公式

`完成了X，通过Y衡量，通过做Z实现，具体S(上下文)`。70%成就要点应遵循此公式。十大评估：专业摘要(2-3行具体成就)/禁用代词/简洁(1-2页)/XYZ+S/专业邮箱/JD定制(提取5-10关键词)/展示产品能力/标准结构/应届生建议/标准职位名称。

### 简历-JD 匹配四步法

接收双文档 → 分析JD(必需技能/优先技能/职责/文化信号) → 定制简历(关键词对齐/XYZ+S重写/重排优先级) → 输出(匹配度评分/关键词差距表/改写简历)。核心：绝不捏造，只诚实重构。
