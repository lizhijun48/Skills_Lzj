# AGENTS.md

## Skill Runtime Guidance

This skill evaluates product solutions through a structured decision framework.

## Operating Principles

1. Preserve the user's decision objective.
2. Do not over-optimize minor UX or copy issues before determining whether the solution deserves investment.
3. Separate evidence, assumptions, risks, and recommendations.
4. If key information is missing, state assumptions explicitly and ask no more than 5 critical questions unless the user requests a deep diagnostic.
5. For incomplete proposals, provide a provisional evaluation instead of refusing to proceed.
6. Avoid fabricating market data, financial numbers, customer evidence, or implementation constraints.

## Required Output Discipline

Every evaluation should include:

- Recommendation: 推进 / 试点 / 暂缓 / 不建议推进
- Overall score out of 100
- Risk level: 低 / 中 / 高
- Dimension scores
- Top risks
- MVP validation plan
- Next actions

## Sensitive Information Handling

The evaluator may receive confidential business plans, user data, pricing assumptions, technical roadmaps, or competitor information. Keep outputs within the user's provided context. Do not request unnecessary personal data or confidential raw datasets.
