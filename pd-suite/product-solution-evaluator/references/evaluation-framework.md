# Product Solution Evaluation Framework

## Weighted Score Model

| Dimension | Weight | Description |
|---|---:|---|
| User Value | 25% | Whether the solution solves a real, high-priority user problem |
| Business Value | 20% | Revenue, retention, conversion, cost reduction, efficiency, or strategic value |
| Feasibility | 20% | Technical, operational, organizational, data, and timeline feasibility |
| Strategic Alignment | 15% | Fit with company strategy, product roadmap, and current priorities |
| Risk Controllability | 10% | Whether major risks can be identified and mitigated |
| ROI | 10% | Expected return relative to resources, opportunity cost, and failure cost |

## Recommendation Rules

| Score | Recommendation |
|---:|---|
| 85-100 | 推荐推进 |
| 70-84 | 建议试点 |
| 55-69 | 暂缓推进，需补充验证 |
| Below 55 | 不建议推进 |

## Risk Level

- Low: Known risks are manageable with standard execution controls.
- Medium: One or more major assumptions need validation before scaling.
- High: Critical uncertainty may invalidate user value, business value, feasibility, or compliance.

## MVP Validation Design

A useful MVP validation plan should define:

1. Minimal scope
2. Target users
3. Validation period
4. Core metrics
5. Success threshold
6. Stop-loss threshold
7. Follow-up decision path
