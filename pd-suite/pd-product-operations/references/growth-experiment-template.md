## 二、假设与成功指标

### 2.1 核心假设
> 我们坚信，通过 [改动 X]，会导致 [指标 Y] 提升，因为我们观察到 [证据/洞察]。

**示例**：我们坚信，通过「注册页增加社交登录按钮」，会导致「注册转化率提升 15%」，因为我们观察到「30% 用户在密码设置步骤流失」。

### 2.2 指标定义

| 指标类型 | 指标名称 | 当前值 | 目标值 | 置信度要求 |
|---------|---------|--------|--------|-----------|
| 核心指标（Primary） | | | +X% | p < 0.05 |
|  guardrail 指标（Guardrail，不能下降） | | | 不下降 | - |
| 观察指标（Secondary） | | | | - |

> ⚠️ **Guardrail 指标**：实验中必须监控，如果下降则立即终止实验。
> 例：优化支付流程时，Guardrail = 支付安全性评分（不能下降）。

## 六、常见陷阱

| 陷阱 | 说明 | 避免方法 |
|------|------|---------|
| 过早下结论 | 样本量不足就停止 | 用样本量计算器 |
| 多个指标 fishing | 试很多指标直到找到一个显著的 | 预先定义核心指标 |
| 新奇效应 | 用户只是因为「新」而互动 | 运行足够长时间 |
| 选择偏差 | 实验组和对照组不对等 | 随机分流 + 分层 |
