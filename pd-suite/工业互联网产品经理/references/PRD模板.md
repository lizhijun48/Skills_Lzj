## 五、数据字典

### 5.1 核心实体

#### 派工单

| 字段 | 类型 | 说明 | 必填 |
|------|------|------|------|
| id | string | 派工单唯一ID | ✓ |
| order_no | string | 关联订单编号 | ✓ |
| craft_id | string | 工艺ID | ✓ |
| team_id | string | 执行班组ID | ✓ |
| plan_qty | number | 计划数量 | ✓ |
| done_qty | number | 已完成数量 | |
| status | enum | 状态：待派发/待接收/生产中/已完成 | ✓ |
| plan_start | datetime | 计划开工日期 | ✓ |
| plan_end | datetime | 计划完工日期 | ✓ |
| actual_start | datetime | 实际开工日期 | |
| created_at | datetime | 创建时间 | ✓ |
| updated_at | datetime | 更新时间 | ✓ |

#### 报工记录

| 字段 | 类型 | 说明 | 必填 |
|------|------|------|------|
| id | string | 报工记录唯一ID | ✓ |
| dispatch_id | string | 关联派工单ID | ✓ |
| worker_id | string | 报工人员ID | ✓ |
| report_qty | number | 报工数量 | ✓ |
| good_qty | number | 良品数量 | ✓ |
| bad_qty | number | 不良品数量 | |
| bad_type | string | 不良类型 | |
| report_mode | enum | 报工模式：按件/按工时/混合 | ✓ |
| report_time | datetime | 报工时间 | ✓ |
| status | enum | 状态：待确认/已确认/已驳回 | ✓ |
