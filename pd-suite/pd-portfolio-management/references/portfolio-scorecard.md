# 产品组合计分卡（Portfolio Scorecard）

> 用途：对多个产品/项目进行组合层面量化评估，支持资源分配和优先级决策。
> 适用场景：季度产品组合评审、新产品立项排序、资源重新分配。
> 对标：NPDP Ch2 + `pd-portfolio-management` Step 2

---

## 一、产品组合计分卡（标准版）

| # | 产品/项目 | 战略对齐(0-10) | 市场吸引力(0-10) | 财务回报(0-10) | 技术可行性(0-10) | 资源需求(0-10,低=好) | 风险(0-10,低=好) | 综合分 | 组合决策 |
|---|----------|----------------|-----------------|----------------|-----------------|---------------------|-----------------|--------|---------|
| 1 | | | | | | | | | |
| 2 | | | | | | | | | |
| 3 | | | | | | | | | |
| 4 | | | | | | | | | |
| 5 | | | | | | | | | |

> **综合分计算**：战略对齐×0.25 + 市场吸引力×0.20 + 财务回报×0.20 + 技术可行性×0.15 + 资源需求×0.10 + 风险×0.10

### 组合决策说明
- ✅ **Invest（投入）**：综合分 ≥ 7.5，增加资源
- ⚠️ **Maintain（维持）**：综合分 6.0-7.4，保持现有资源
- 🔄 **Harvest（榨取）**：综合分 4.0-5.9，减少投入，最大化现金流
- ❌ **Divest（退出）**：综合分 < 4.0，停止投入，考虑退市

## 二、产品组合平衡检查（三维平衡）

### 2.1 风险-回报平衡

| 产品 | 预期回报 | 风险等级 | 平衡建议 |
|------|---------|---------|---------|
| 核心产品（Cash Cow） | 中 | 低 | 维持，提供现金流 |
| 增长产品（Star） | 高 | 中 | 重点投入 |
| 实验产品（Question Mark） | 很高 | 高 | 小步快跑，快速验证 |
| 衰退产品（Dog） | 低 | 低-中 | 榨取或退出 |

> **目标组合**：核心产品 1-2 个（提供现金流）+ 增长产品 1-2 个（未来引擎）+ 实验产品 2-3 个（期权）

### 2.2 长短平衡

| 时间维度 | 产品数量 | 收入贡献占比 | 健康度 |
|---------|---------|------------|--------|
| 短期（< 1 年） | | | 应有足够现金流产品 |
| 中期（1-3 年） | | | 应有增长型产品 |
| 长期（> 3 年） | | | 应有战略型产品 |

### 2.3 跨市场/跨技术平衡

| 维度 | 分布 | 风险分散度 |
|------|------|-----------|
| 市场（ToB/ToC/ToG） | | 是否过度依赖单一市场？ |
| 技术栈 | | 是否过度依赖单一技术？ |
| 客户类型 | | 是否过度依赖单一客户？ |
