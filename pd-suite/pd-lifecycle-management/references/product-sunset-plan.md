# 产品退市计划模板（Product Sunset Plan）

> 用途：系统性规划产品（或功能）的退市流程，最小化客户影响和法律风险。
> 适用场景：老旧产品下线、功能合并/替代、战略调整导致的产品终止。

## 二、退市时间表（T-周期）

| 时间节点 | 动作 | 负责人 | 状态 |
|---------|------|--------|------|
| T-90 天 | 内部决策确认，通知核心团队 | PM | |
| T-60 天 | 公告客户（邮件 + 站内信 + 帮助中心） | PM + CS | |
| T-45 天 | 停止新用户注册/购买 | 工程 | |
| T-30 天 | 最后一轮客户支持，数据导出工具上线 | CS + 工程 | |
| T-14 天 | 再次提醒（剩余 2 周） | CS | |
| T-7 天 | 最后警告，服务即将停止 | CS | |
| T-0 | 服务下线，重定向至替代方案 | 工程 | |
| T+30 天 | 数据彻底删除（按隐私政策） | 工程 + 法务 | |

## 三、客户迁移方案

### 3.1 替代方案

| 客户类型 | 替代方案 | 迁移激励 |
|---------|---------|---------|
| 付费客户 | 升级至 [新产品] 享 X 折 | 剩余时长折算 |
| 免费客户 | 导出数据，迁移至 [竞品/开源] | 提供导出工具 |
| 企业客户 | 专属迁移顾问，1对1支持 | 延期服务 3 个月 |

### 3.2 客户沟通模板

**邮件标题**：【重要通知】关于 [产品名] 停止服务的公告

**核心信息**：
1. 退市原因（简洁、真诚）
2. 时间表（关键节点）
3. 替代方案（具体、可操作）
4. 数据导出方式
5. 客服联系方式
