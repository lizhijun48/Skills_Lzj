# QFD 质量屋模板（House of Quality Template）

> 用途：将用户需求（VOC）转化为技术需求，并识别关键技术指标。
> 适用场景：硬件产品、SaaS 产品核心模块、需要量化"用户需求→技术实现"映射时。

### 第三部分：关系矩阵（V × T）

**符号含义**：
- ◎ 或 9 = 强相关
- ○ 或 3 = 中等相关

## 三、简化版（产品经理快速填法，≤ 10 分钟）

**只填 3 列**，快速得出优先级：

| 用户需求 | 重要度(1-5) | 对应技术需求（一句话） | 优先级得分 |
|---------|---------------|---------------------|----------|
| [需求1] | 5 | [技术需求A] | =5×关系强度 |
| [需求2] | 4 | [技术需求B] | =4×关系强度 |
| [需求3] | 3 | [技术需求C] | =3×关系强度 |

> 优先级得分最高的技术需求，就是 QFD 输出的**最该先做的技术特性**。

## 四、完整案例：智能门锁

### 用户需求 × 技术需求 关系矩阵

| 用户需求 | 指纹识别率 | 解锁速度 | 电池续航 | 防破解能力 | 用户重要度 |
|---------|-----------|---------|---------|-----------|----------|
| 安全性高 | △(3) | | ○(3) | ◎(9) | 5 |
| 开门快 | | ◎(9) | | | 4 |
| 不用频繁换电池 | | | ◎(9) | | 3 |
| 识别准（不误判） | ◎(9) | | | △(3) | 4 |

**技术需求重要度计算**：
- 指纹识别率 = 5×3 + 4×0 + 3×0 + 4×9 = **51**
- 解锁速度 = 5×0 + 4×9 + 3×0 + 4×0 = **36**
- 电池续航 = 5×3 + 4×0 + 3×9 + 4×0 = **42**
- 防破解能力 = 5×9 + 4×0 + 3×0 + 4×3 = **57** ← **最高，优先投入**

**结论**：QFD 输出 —— 最该先投入的技术方向是「防破解能力」（得分为 57）。

## 五、填写注意事项

1. **用户需求来自哪里**：用户访谈、KANO 调查、客服反馈归档
2. **技术需求谁来定**：产品经理 + 研发负责人共同开会确定（1-2小时）
3. **关系强度谁打**：产品经理主导，研发参与（避免产品经理瞎打分）
4. **输出是什么**：技术需求重要度排序 → 直接指导产品路线图优先级
