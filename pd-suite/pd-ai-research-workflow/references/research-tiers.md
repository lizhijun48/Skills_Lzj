## T1 · 快问快答（Quick Insights）

**代表工具**：任意 LLM CLI（Gemini CLI / Claude / ChatGPT / 通义/文心等）。
**投入**：5 分钟。**PM 价值**：秒级专家级市场分析。

### 用法原则
- **具体**：带上行业、公司阶段、目标市场。
- **要结构**：要求分点、排名、框架输出。
- **链式追问**：在前一轮基础上深挖。
- **存好结果**：把有价值洞察拷进策略文档。

### 可直接抄的 prompt 模板

**竞品定位对比**
```
对比 [竞品A]、[竞品B]、[竞品C] 的商业模式。各自的战略优势是什么，差距在哪？
```

**市场进入分析**
```
[B2B SaaS] 公司进入 [欧洲] 市场的关键成功因素有哪些？含合规考量与文化差异。
```

**功能优先级调研**
```
基于 2024 用户反馈趋势，项目管理软件最被诉求的 [功能] 有哪些？按潜在业务影响排序。
```

**技术趋势分析**
```
未来 2 年，AI 集成将如何影响 [笔记类应用：Notion/Obsidian/Roam] 的竞争态势？
```

**战略追问（在上一层基础上）**
```
基于上面的分析，新进入者最有效的方法论差异化策略是什么？给出具体战术。
```

**落地计划**
```
为 launch 一个解决上述风险的 [PM 培训] 业务，做一份 90 天 GTM 计划，含里程碑与成功指标。
```

### 典型场景
- 董事会前快速补行业背景与竞品动态；
- 策略会实时查资料支撑讨论；
- 写 PRD 时补"市场背景/竞品分析"段；
- 每周竞品情报快更。

## T2 · 财务对标（Financial Benchmarking）

**代表工具**：财经数据终端（OpenBB Terminal / 同花顺 iFinD / Wind / 手动查年报）。
**投入**：30 分钟。**PM 价值**：任意上市公司的深度财务情报。

### 标准命令流（以 OpenBB 为例，逻辑通用）
```
stocks
load [TICKER]          # 载入目标公司，后续命令都聚焦它
overview               # 业务描述/行业/市值/营收/员工/关键比率/近期表现
income                 # 营收趋势、利润率、同比增速、运营效率
compare [A] [B] [C]   # 竞品并排财务对比、相对表现、估值倍数
news                   # 近期公告、产品发布、战略动作、分析师观点、行业趋势
```

### 进阶分析方向
- **市场定位**：`load [TICKER]` → `sectors performance`（看相对板块表现）
- **投资/增长信号**：`insider` / `analyst`（内部交易与分析师评级）
- **行业趋势**：`etf [QQQ]` → `holdings`（机构信心流向）

### PM 应用
- 董事会材料补竞品财务背景；
- 战略周期理解竞品资源约束与优势；
- 评估潜在伙伴财务稳定性；
- 融资前对标自身指标与上市公司。

### 提示
- 始终分析 3–5 家同赛道公司；
- 跨竞品对比财务趋势，找规律；
- 看 P/E、营收增速、利润率讲的战略故事；
- 把财务事件与产品/战略公告时间线连起来。

## T3 · 自主深研（Autonomous Deep Research）

**代表工具**：多步研究 agent（Deep Researcher / LangGraph / ChatGPT Deep Research / Claude research）。
**投入**：数小时（主要 AI 自主跑）。**PM 价值**：无咨询费拿到咨询级报告。

### Brief 模板（直接改括号内容即可）
```
就 [AI 驱动笔记应用] 的竞争态势生成一份综合报告，聚焦市场趋势、关键玩家、新兴技术。
含商业模式分析与对新进入者的战略建议。
```
进阶 brief 可加：地理/时间/行业边界、要支撑的决策、要的格式（SWOT / 推荐矩阵）。

### 报告标准结构（交付物）
1. **执行摘要**：关键发现与战略含义
2. **市场概览**：规模、增长、趋势
3. **竞品分析**：玩家档案与定位
4. **技术趋势**：新兴能力与颠覆
5. **战略建议**：市场进入的具体行动
6. **附录**：来源引用与原始数据

### 进阶研究主题 brief 示例
- **技术可行性**：当前 AI 代码生成工具的能力、采纳壁垒、竞争格局、市场机会、商业模式可行性。
- **客户细分**：[B~C 轮 SaaS] 的 PM 具体需求与痛点，含薪酬趋势、工具使用、职业挑战、未满足的教育需求。
- **合规研究**：美欧 [AI 医疗] 监管态势，含合规要求、审批流程、竞争含义、产品开发建议。
- **市场进入**：[美国生产力软件] 进 [日本] 的机会，含文化、本地竞品、合作、GTM。

### 提示
- 范围要具体（地理/时间/行业边界）；
- 交代决策背景（这份研究会支撑什么决策）；
- 要具体格式（框架/SWOT/矩阵）；
- 基于初稿迭代细化后续问题。

### 何时用 T3
重大产品决策前验证市场机会与威胁；年度/季度战略周期；融资；董事会材料；考虑 pivot 时研究相邻市场。

---

## 通用原则（三层共用）
- **研究必须改变决策**：每次研究结束都要有具体行动 / 待验证假设 / 对路线图的战略含义。
- **从直觉驱动转向证据驱动**：让研究能力比肩昂贵咨询公司。
