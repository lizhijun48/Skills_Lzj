# 组合编排范式 + 研究质量与验证

> 来源：外部 `ai-pm-exploration-toolkit` 的 `playbooks/MARKET_RESEARCH_PLAYBOOK.md`（"Mastery: Combining All Research Tiers" 与 "Research Quality and Validation" 章节）。提取为可复用编排知识。

---

## 一、3 种组合编排范式

真正的能力来自**分层叠加**，而非单用某一层。

### 范式 A · 竞品分析流水线（Competitive Analysis Pipeline）
1. **T1（快问）**：快速竞品格局概览、识别关键玩家；
2. **T2（财务）**：对上市公司做财务分析；
3. **T3（深研）**：综合战略分析与建议；
4. **合成**：汇成高管可读的战略简报。

### 范式 B · 市场进入决策框架（Market Entry Decision）
1. **T3（深研）**：综合市场研究与机会评估；
2. **T2（财务）**：关键玩家与市场动态的财务分析；
3. **T1（快问）**：对具体战略假设做快速验证；
4. **行动**：数据驱动的 Go/No-Go + 支撑证据。

### 范式 C · 产品策略验证（Product Strategy Validation）
1. **T1（快问）**：竞品功能与定位快速研究；
2. **T3（深研）**：客户需求与市场的缺口深研；
3. **T2（财务）**：不同商业模式的财务表现分析；
4. **输出**：经验证的、具竞争性差异化的产品策略。

> 设计新范式时遵循同一逻辑：**按"广度→深度→财务→决策"或反向组合，末步必落到可行动产出**。

## 二、研究质量与验证原则

### 确保高质量洞察
- **交叉验证来源**：不同研究方法的结果相互比对；
- **查时效性**：确保数据当前且相关；
- **校验假设**：用领域知识测试 AI 结论；
- **记录方法论**：沉淀"哪些研究方法好用"，形成可复用资产。

### 常见研究陷阱（务必规避）
- **过度依赖 AI**：关键结论始终用人的判断验证；
- **信息茧房**：确保来源类型与视角多样；
- **分析瘫痪**：为各研究阶段设时间边界；
- **确认偏误**：主动要求 AI 挑战你的既有假设。

### 与现有技能的方法论衔接
- 框架层（TAM/SWOT/五力/PESTLE/12 种方法）一律回查 **PT-003（pd-market-research）**；
- 真实访谈/会议转录的洞察抽取用 **PT-012.insight-extraction**；
- 研究结论要落决策用 **PT-004（pd-go-nogo）**；
- 用户画像/痛点严禁随机合成，必须基于 **PT-012** 的真实研究。

## 三、编排自检清单（每次启动研究前）

- [ ] 明确研究对象（竞品/市场/功能）与要支撑的决策；
- [ ] 选对层级：T1 快/ T2 财务 / T3 深研，或组合范式；
- [ ] 若涉及用户数据，确认来自真实研究（PT-012），非合成；
- [ ] 框架方法缺位时先查 PT-003；
- [ ] 设时间边界，避免分析瘫痪；
- [ ] 末步产出可行动结论 / 待验证假设 / 路线图含义。
