# 一页纸 PRD 模板（One-Page PRD）

> 用途：快速对齐需求，适用于敏捷迭代、小功能、需求评审会前同步。
> 对标：`pd-prd-writing` Step 2 一页纸 PRD

---

## 使用场景判断

| 场景 | 推荐文档类型 |
|------|-------------|
| 大版本功能（≥5个功能点） | 完整 PRD（8模块） |
| 小功能 / 迭代需求（≤3个功能点） | ✅ 一页纸 PRD |
| Bug 修复 / 文案修改 | 直接在需求管理工具写卡片即可 |
| 紧急上线（Hotfix） | 一页纸 PRD（极简版）|

---

## 模板正文（直接复制使用）

```
# [功能名称] — 一页纸 PRD

## 背景与目标
- **背景**：[为什么做？现在的痛点是什么？]
- **目标**：[做完了怎么衡量成功？用 1 句话 + 1 个指标]

## 用户故事
- 作为 [用户角色]，我想要 [完成什么动作]，以便 [获得什么价值]

## 功能范围（打勾确认）
- [ ] 功能点 A
- [ ] 功能点 B
- [ ] 功能点 C
- **本次不做**：[明确边界，防止需求蔓延]

## 核心流程（Mermaid 图或文字）
```mermaid
graph LR
    A[用户操作] --> B[系统处理]
    B --> C[结果展示]
```

## 验收标准（AC）
- Given [前提条件]，When [用户操作]，Then [预期结果]
- Given [前提条件]，When [用户操作]，Then [预期结果]

## 风险与依赖
- **风险**：[有什么可能搞砸？]
- **依赖**：[需要谁先完成什么？]

## 发布建议
- **灰度策略**：[全量 / 灰度 10% / 仅内测]
- **回滚方案**：[如果出问题，怎么快速撤回？]
```

## 填写示例：批量导出功能

```
# 批量导出 — 一页纸 PRD

## 背景与目标
- **背景**：用户反馈「每次只能导出一条数据，重复操作太累」
- **目标**：支持批量勾选导出，导出成功率 ≥ 99%

## 用户故事
- 作为运营人员，我想要批量勾选数据并导出 Excel，以便减少重复操作时间

## 功能范围
- [x] 列表页添加复选框
- [x] 支持勾选后点击「批量导出」按钮
- [x] 导出格式：Excel (.xlsx)
- [ ] 导出 PDF（下版本再做）
- **本次不做**：导出 CSV、导出按模板填充

## 核心流程
用户勾选数据 → 点击「批量导出」→ 后端生成 Excel → 前端弹出下载

## 验收标准（AC）
- Given 用户已勾选 ≥1 条数据，When 点击「批量导出」，Then 立即下载 Excel 文件
- Given 用户未勾选任何数据，When 点击「批量导出」，Then 提示「请至少选择一条数据」

## 风险与依赖
- **风险**：数据量过大（>1万行）时生成超时
  - 应对：限制单次导出上限 5000 行，超出提示分批导出
- **依赖**：后端导出服务需支持异步生成（由后端组在 Week 2 完成）

## 发布建议
- **灰度策略**：先开放给内测用户（约 50 人），1 周无异常后全量
- **回滚方案**：前端隐藏「批量导出」按钮即可（无需后端回滚）
```

## 一页纸 vs 完整 PRD 对照

| 维度 | 一页纸 PRD | 完整 PRD |
|------|------------|---------|
| 篇幅 | 1 页 | 5-20 页 |
| 适用 | 小功能 / 迭代需求 | 大版本 / ToG 项目 |
| 非功能需求 | 可选 | 必填 |
| 数据需求 | 可选 | 必填 |
| 评审时长 | 15 分钟 | 1-2 小时 |
