## 模块一：产品概述

### 1.1 产品定位

一句话描述产品是什么、为谁服务、解决什么问题。

```
[产品名称] 是一款面向 [目标用户] 的 [产品类型]，
通过 [核心功能/技术]，解决 [核心痛点]，实现 [核心价值]。
```

### 1.2 产品背景与行业分析

- **行业趋势**：用 3-5 条 bullet 说明行业正在发生什么变化
- **用户痛点**：现有解决方案的不足（用用户原话更有说服力）
- **产品机会**：为什么是现在？为什么是我们？

### 1.3 产品愿景（Vision）

```
让 [某类用户] 能够 [做某事]，不再需要 [当前痛点行为]。
```

### 1.4 产品目标（OKR 格式）

| 目标(O) | 关键结果(KR) | 目标值 | 衡量周期 |
|---------|---------------|--------|---------|
| O1：[用户增长] | KR1：DAU 达到 XX | XX万 | Q3 |
| | KR2：留存率达到 XX | XX% | Q3 |
| O2：[商业变现] | KR1：付费转化率 XX | XX% | Q4 |
