# 七类决策维度提取库

按维度逐项核对，**每维都要给结论**（有内容 / 本维无内容 + 检索依据）。本文件是提取清单，不是提示词扩写：每行都能对照原文判"提没提到"。

---

## 一、时间维度

**问什么**：什么时候、多久内、以哪一天为基准。

| 必提项 | 判据（缺即记缺口） |
|---|---|
| 起算基准日 | 明确写"自 X 日起"还是"自签订/批复/进场之日起" |
| 期限长度 | 日历日 / 工作日 / 自然月，是否排除节假日 |
| 关键节点 | 交付、验收、付款、报批、答复各自的截止时间 |
| 顺延条件 | 哪些情况可顺延、需谁书面确认、顺延后是否影响其他节点 |
| 有效期 | 批复/资质/保函/报价的有效截止 |
| 时限罚则 | 逾期后果（违约金/视为放弃/自动失效） |

**常见坑**
- 只写"30 天内"却不说从哪天起算 → 必记缺口
- 工作日与日历日混用（差 30%+ 工期）
- 节点之间互相依赖但资料未给联动关系（A 延后是否自动延后 B）
- 批复有效期短于实施周期

**合格写法**：`自开工令签发之日起 90 个日历日内完成初验`（`§4.1`）
**不合格写法**：`工期约三个月`、`时间要求较紧`

## 二、金额维度

**问什么**：多少钱、怎么算、什么条件下付、能不能调。

| 必提项 | 判据 |
|---|---|
| 总额与构成 | 是否为含税价、税率、是否含运输/安装/运维 |
| 计量方式 | 总价包干 / 单价计量 / 成本加成 / 工料机分离 |
| 支付节点 | 预付款比例与条件、进度款计量周期、质保金比例与退还条件 |
| 调整机制 | 是否可调价、调价触发条件、调价基数、调价上限 |
| 扣款条款 | 违约金、考核扣款、审计核减的承担方 |
| 超支红线 | 超概算/超预算的处理与审批要求 |

**常见坑**
- "含税"未说明税率（toG 项目税率差 3 个点很常见）
- 质保金比例与退还条件缺失 → 现金流风险
- 只给总价不给构成 → 无法核单价合理性
- 调价条款写了但未给基数口径（按什么指数、按哪一期）

**合格写法**：`合同总价 860 万元（含 6% 增值税），预付款 20%，进度款按月计量，质保金 5% 于终验后 24 个月退还`（`第6条`）
**不合格写法**：`金额较大`、`付款方式按合同`

## 三、义务维度

**问什么**：谁必须做什么、在什么条件下、不做怎样。

| 必提项 | 判据 |
|---|---|
| 义务主体 | 逐一明确到"甲方/乙方/监理/第三方"，不许写"双方" |
| 义务内容 | 可验证的动作或交付物（份数、格式、时限） |
| 前提条件 | 该义务的触发前提（前置交付完成、款项到账、批文取得） |
| 不履行后果 | 违约处理、替代履行、解除权 |
| 配合义务 | 谁提供什么配合（场地、资料、接口、人员） |

**常见坑**
- "双方应积极配合"——不可验证，等于没写
- 义务有内容无时限 → 无法主张违约
- 只写乙方义务、甲方配合义务缺失（ToG 项目最常见的履约陷阱）
- 义务转嫁：把本应由甲方承担的审批义务写成乙方"协助"

**合格写法**：`甲方于开工前 7 日内提供施工场地及既有管线资料（第8条第3款）；未提供导致停工，工期相应顺延且乙方不承担违约责任`
**不合格写法**：`甲方应提供必要支持`

## 四、权限维度

**问什么**：谁批、谁签、授权到哪、超了怎么办。

| 必提项 | 判据 |
|---|---|
| 审批权 | 各事项的最终审批人/机构 |
| 签署权 | 谁有权签（法人/授权代表/项目经理），授权书是否要求 |
| 授权额度 | 变更、索赔、付款的审批分级（多少额度归哪一级） |
| 越权后果 | 越权签署/越权承诺的效力与追责 |
| 上报义务 | 什么情况下必须上报上级/业主/监管 |

**常见坑**
- 变更审批额度未写 → 现场签证随意签，结算被砍
- 授权书与合同签署人不对应
- 口头指示无书面确认程序
- 分级授权在附件中与正文不一致（以谁为准未写）

**合格写法**：`单项变更金额 50 万元以下由项目总监审批，50 万元以上报业主董事会（第12条第2款）`
**不合格写法**：`重大变更需报批`

## 五、风险维度

**问什么**：罚则、违约、免责、兜底、责任转移。

| 必提项 | 判据 |
|---|---|
| 违约金 | 比例或上限、封顶条款、双向还是单向 |
| 免责事由 | 不可抗力定义、政策变化、第三方原因是否免责 |
| 责任上限 | 是否有总额限制（不超过合同额 X%） |
| 保险与担保 | 履约保函、质保保函、险种与额度 |
| 追责链条 | 审计追责、倒查机制、质量终身责任 |
| 索赔程序 | 索赔时限、证据要求（逾期视为放弃） |

**常见坑**
- 违约金无封顶（理论上可超合同额）
- 索赔程序有"逾期视为放弃"但未在时间维度登记
- 免责条款把"政策调整"排除在免责外（ToG 高风险）
- 保函有效期短于质保期

**合格写法**：`逾期违约金按日 0.5‰ 计，累计不超过合同额的 5%（第15条）；不可抗力含政府行为与政策变动（第16条）`
**不合格写法**：`按国家有关规定承担违约责任`

## 六、凭证维度

**问什么**：要交什么材料、几份、什么形式、认不认电子件。

| 必提项 | 判据 |
|---|---|
| 材料清单 | 逐份列出（报告/图纸/台账/影像/证书），非"相关资料" |
| 份数与格式 | 纸质几份、是否需盖章、是否需电子件、格式与命名 |
| 签字盖章链 | 谁签、谁盖、是否需第三方（监理/业主/检测机构）确认 |
| 时点要求 | 提交时点、补正期限、逾期后果 |
| 认可形式 | 电子签章/扫描件/复印件是否被认可 |

**常见坑**
- 验收资料清单在正文与附件不一致
- 隐蔽工程影像记录要求明确但无归档格式 → 后期无法举证
- 只要求"提交"不要求"签收" → 无交付证据
- 电子件效力未约定

**合格写法**：`竣工资料一式四份（含电子件 PDF 一套），经监理签认后报业主档案室，缺件于 15 日内补齐（§7.3）`
**不合格写法**：`提交完整的竣工资料`

## 七、口径维度

**问什么**：定义、计量方式、验收标准、争议解释顺序。

| 必提项 | 判据 |
|---|---|
| 术语定义 | 关键技术/商务术语是否有明确定义 |
| 计量口径 | 工程量计算规则（按什么规范、什么版本） |
| 验收标准 | 合格判定依据（国标/行标/企标，哪个版本） |
| 争议解释 | 多份文件冲突时的优先解释顺序（合同>技术协议？正文>附件？） |
| 变更口径 | 什么算变更、什么算优化（决定能不能调价） |

**常见坑**
- 技术协议与合同正文对同一指标两个数（无解释顺序 → 争议无解）
- 验收标准引用旧版规范
- "优化"与"变更"边界模糊 → 干了活拿不到钱
- 计量规则未约定，结算时按审计口径砍量

**合格写法**：`解释顺序：合同协议书 > 中标通知书 > 专用条款 > 通用条款 > 技术协议（第2条）；工程量按《建设工程工程量清单计价规范》GB50500-2013 计算`
**不合格写法**：`按国家标准执行`

## 八、维度结论的写法

每维都必须落一句结论，三选一：

| 情形 | 写法 |
|---|---|
| 有内容 | 在矩阵中逐条出要素，维度列填该维度名 |
| 确实无内容 | 简报中写：`维度：口径 — 本维无内容（已检索§1-§9、关键词"解释""标准""定义"，未见约定）` |
| 资料缺失导致无法判断 | 进缺口：`缺 XX → 无法判断 YY → 后果 ZZ` |

**禁止**：留空、写"暂无"、写"待补充"而不说明检索依据。
