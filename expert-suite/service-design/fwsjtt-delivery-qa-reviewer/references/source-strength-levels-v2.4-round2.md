# FWSJTT V2.4 Round2｜知识源强度分级与输出权限

## 1. 模块目标

把 Round1 的 L0-L4 来源强度规则升级为“强制标签 + 输出权限 + 伪权威拦截”的执行规范。

本模块北极星：**阻止模型把推理、经验、公开常识或未经核证的材料包装成权威结论。**

## 2. 来源强度分级

| 等级 | 定义 | 允许用途 | 禁止用途 |
|---|---|---|---|
| L0 | 无明确来源，模型推理、常识推断、创意假设 | 仅可作为假设、启发、待验证问题 | 禁止写成事实、行业规律、专家共识 |
| L1 | 用户口述、访谈片段、单点经验、未核证内部材料 | 可作为客户线索或待验证事实 | 禁止代表整体客户、行业或稳定规律 |
| L2 | 一般公开资料、媒体文章、二手整理、非正式报告 | 可作为背景参考 | 禁止作为强结论的唯一依据 |
| L3 | 权威公开资料、经典著作、同行评审、官方报告、知名咨询/研究机构报告 | 可支持方法、框架、趋势判断 | 禁止替代客户一手数据 |
| L4 | 客户一手数据、系统日志、交易数据、真实实验、经核验访谈样本 | 可支持强业务判断、ROI 测算、优先级排序 | 不得超出数据覆盖范围泛化 |

## 3. 强制证据标签模板

所有关键结论必须使用以下模板：

```markdown
【结论】...
【来源强度】L0/L1/L2/L3/L4
【依据】说明来源、样本、时间、范围
【可推断】本结论在什么范围内成立
【不可推断】不能由当前证据推出什么
【下一步核证】需要补充哪些数据或访谈
```

## 4. 输出权限矩阵

| 最高证据等级 | 允许输出 | 不允许输出 |
|---|---|---|
| L0 | 假设、问题清单、探索方向 | 事实判断、趋势判断、ROI、优先级结论 |
| L1 | 客户线索、初步问题假设 | 行业结论、整体客户结论、确定根因 |
| L2 | 背景、类比、参考案例 | 强策略建议、定量收益 |
| L3 | 理论框架、方法依据、外部趋势 | 客户内部绩效判断、确定 ROI |
| L4 | 强业务结论、测算、排序、决策建议 | 超出样本与时间范围的泛化 |

## 5. 伪权威禁用表达

如无 L3/L4 依据，禁止使用：

- “行业最佳实践证明……”
- “数据显示……”但不给数据来源；
- “专家认为……”但不说明专家与出处；
- “必然提升……”
- “可显著提高 ROI……”
- “客户普遍……”但只有单点访谈；
- “根据经典理论……”但不说明理论与适用边界。

## 6. 强结论闸门

出现以下结论时，必须至少有 L3 方法依据 + L4 客户数据，或明确降级为假设：

1. ROI、回本周期、收入增量；
2. 客户整体画像；
3. 核心根因；
4. 优先级排序；
5. 大规模投入建议；
6. 组织变革建议。

## 7. QA 检查

交付前逐条检查：

- 是否每个关键结论都有来源强度？
- 是否区分事实、假设、推断、建议？
- 是否把 L0/L1 写成 L3/L4？
- 是否对 L2/L3 资料注明适用边界？
- 是否对 L4 数据注明样本、时间、范围？

未通过任一项，必须返工。
