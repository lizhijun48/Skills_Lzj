# FWSJTT V2.4 Round2｜ROI 讨论路由器

## 1. 模块目标

把 ROI 讨论从“模型估算”升级为“数据完整度评分 + 输出权限控制 + 测量计划”。

本模块北极星：**在数据不足时阻止伪精确，在数据充分时支持有边界的测算。**

## 2. ROI 输入字段完整度评分

| 字段 | 权重 | 说明 |
|---|---:|---|
| 当前基线指标 | 20 | 当前线索量、转化率、处理时长、成本、收入等 |
| 干预对象与范围 | 15 | 哪些人、流程、系统、客户段受影响 |
| 单位经济模型 | 15 | 客单价、毛利、获客成本、服务成本、复购等 |
| 变化机制假设 | 15 | 为什么该措施会影响指标 |
| 数据来源强度 | 15 | 是否有 L4 数据或经核验实验 |
| 时间窗口 | 10 | 观察周期、实施周期、滞后效应 |
| 风险与约束 | 10 | 产能、合规、组织执行、样本偏差 |

总分 100。

## 3. 输出权限矩阵

| 完整度 | 允许输出 | 禁止输出 |
|---|---|---|
| 0-30 | 数据需求、测算框架、假设清单 | ROI 数字、回本周期、收益承诺 |
| 31-60 | 情景假设、指标树、实验设计 | 确定 ROI、单点收益数 |
| 61-80 | 区间测算、敏感性分析、试点收益假设 | 无边界承诺、全量推广收益 |
| 81-100 | 有边界 ROI、回本周期、投入产出对比 | 超出样本/周期/范围的泛化 |

## 4. ROI 路由

```text
用户要求 ROI
→ 检查输入字段
→ 计算完整度
→ 判断最高来源强度
→ 根据权限矩阵选择输出类型
→ 标明假设、不可推断部分和补数计划
```

## 5. 禁止伪精确规则

缺少以下任一项时，不得输出精确 ROI：

- 当前基线；
- 单位经济模型；
- 干预范围；
- 时间窗口；
- 数据来源；
- 变化机制。

## 6. 合规输出模板

```markdown
【ROI 判断】当前不具备/部分具备/具备测算条件
【完整度评分】xx/100
【允许输出类型】数据需求/情景假设/区间测算/有边界 ROI
【已知数据】...
【关键缺口】...
【测算公式】...
【敏感变量】...
【下一步补数计划】...
```

## 7. 理论来源转化

- Lean Startup：用实验学习指标替代早期伪 ROI；
- Balanced Scorecard：区分财务、客户、流程、学习成长指标；
- DMAIC：用 Define-Measure-Analyze-Improve-Control 约束改善收益；
- TOC：识别瓶颈，避免把非瓶颈优化夸大为整体收益。
