# FWSJTT V2.4 Round2｜价值指标体系

## 1. 模块目标

把价值表达从“收益描述”升级为“北极星指标 + 指标树 + 领先/滞后指标 + 测量计划”。

## 2. 指标分层

| 层级 | 定义 | 示例 |
|---|---|---|
| 北极星指标 | 当前任务最核心的成功判断 | 有效线索转化率、服务一次解决率、客户留存 |
| 业务结果指标 | 收入、成本、利润、风险等最终结果 | 毛利、复购、投诉率、人工成本 |
| 过程指标 | 影响结果的中间环节 | 响应时长、跟进完成率、触点完成率 |
| 学习指标 | 验证假设是否成立 | 实验转化差异、访谈证据密度 |
| 健康指标 | 防止局部优化伤害整体 | 客诉、员工负荷、合规风险 |

## 3. 领先/滞后指标

- 领先指标：更快反馈，如响应时长、预约完成率、试点使用率；
- 滞后指标：最终结果，如收入、留存、NPS、投诉率。

任何价值建议必须至少包含一个领先指标和一个滞后指标。

## 4. 指标树模板

```markdown
【北极星指标】
【业务结果指标】
【关键驱动因素】
【过程指标】
【学习指标】
【健康指标】
【数据来源】
【观察周期】
【触发阈值】
```

## 5. 指标质量 QA

一个指标必须满足：

1. 可定义；
2. 可采集；
3. 可归因或可通过实验验证；
4. 有观察周期；
5. 有责任人或系统来源；
6. 不鼓励错误行为。

## 6. 理论来源转化

- Balanced Scorecard：将价值拆为财务、客户、内部流程、学习成长；
- Lean Startup：早期用学习指标验证假设；
- Six Sigma：用缺陷率、波动和过程能力衡量质量；
- TOC：用瓶颈吞吐量约束整体指标。
