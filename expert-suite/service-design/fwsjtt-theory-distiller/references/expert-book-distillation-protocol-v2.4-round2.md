# FWSJTT V2.4 Round2｜专家与经典书目蒸馏协议

## 1. 模块目标

把“专家/经典书目源头”转化为可执行技能模块，同时避免伪引用、泛化引用和理论滥用。

本模块北极星：**让高价值理论进入技能包前，必须经过来源、概念、方法、边界、测试五道闸门。**

## 2. 入库门槛

一个理论源头进入 FWSJTT 模块库前，必须满足：

1. 有明确专家、书目、论文、方法传统或权威出处；
2. 能提炼出可操作方法，而不只是概念口号；
3. 能定义适用场景与不适用场景；
4. 能映射到一个或多个技能模块；
5. 能设计至少一个回归测试场景；
6. 来源强度至少达到 L2；若用于强约束，建议达到 L3。

## 3. 蒸馏卡片强制字段

```markdown
# 蒸馏卡片｜<理论/书目/专家>

## 1. 来源信息
- 专家/作者：
- 经典来源：
- 来源类型：书籍/论文/实践框架/方法传统
- 来源强度建议：L2/L3/L4
- 是否已核证原文：是/否/待核证

## 2. 核心理论
用 3-5 句话说明理论本身，不扩写应用方案。

## 3. 高价值方法
理论可转化为哪些操作步骤、判断准则或模板？

## 4. 可进入的技能模块
- 模块名称：
- 输入：
- 处理步骤：
- 输出：
- QA 门槛：

## 5. 适用边界
适用于什么场景？不适用于什么场景？需要哪些前提？

## 6. 证据与风险
可能被误用在哪里？哪些结论不能由该理论推出？

## 7. 回归测试建议
至少一个能检验该理论模块是否生效的场景。
```

## 4. 理论到模块转化规则

理论不能直接作为结论输出，必须转成以下至少一种形式：

- 判断规则；
- 工作流；
- 输入字段；
- 输出模板；
- 评分卡；
- 禁止项；
- 回归测试。

## 5. 后续核证标记

若来源尚未核对原文，必须标记：

> 【待核证】本理论为公开二手理解/方法传统归纳，正式入库前需补充原文出处、章节或页码。

## 6. 进入 Round2 模块的优先级

优先进入：

1. 能显著降低伪权威、伪精确、表层建议的理论；
2. 能增强服务设计、客户需求、商业价值、交付 QA 的理论；
3. 能形成硬门槛、评分卡、回归测试的理论。

暂缓进入：

- 只提供观点、不提供方法；
- 无法定义边界；
- 争议较大且未核证；
- 与 FWSJTT 北极星关系弱。
