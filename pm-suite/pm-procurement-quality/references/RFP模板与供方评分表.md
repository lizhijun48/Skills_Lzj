# RFP模板与供方评分表

> 适用于政府/国企信息化项目采购，对标PMBOK第12章采购管理

---

## 一、RFP（建议书邀请）核心要素

### 1.1 RFP标准结构

| 章节 | 内容 | 页数建议 |
|------|------|---------|
| 1.项目概述 | 背景/目标/范围/约束 | 2-3页 |
| 2.工作说明书(SOW) | 详细工作内容/交付物/验收标准 | 5-10页 |
| 3.技术要求 | 技术规格/性能指标/兼容性/安全要求 | 3-5页 |
| 4.资质要求 | 企业资质/团队资质/类似业绩 | 1-2页 |
| 5.报价要求 | 报价方式/付款条件/报价明细表 | 2-3页 |
| 6.评审标准 | 技术分/商务分/价格分权重 | 1-2页 |
| 7.合同条款 | 通用条款/专用条款/SLA | 3-5页 |
| 8.投标要求 | 截止时间/格式/份数/密封要求 | 1页 |

### 1.2 政府项目RFP特殊条款

- 必须明确是否属于集中采购目录内项目
- 报价须含税，须区分硬件/软件/服务
- 须符合《政府采购法》规定的采购方式（公开招标/邀请招标/竞争性谈判/竞争性磋商/单一来源/询价）
- 须明确是否允许联合体投标
- 须明确中小企业优先/监狱企业/残疾人福利性单位加分政策

| | | 财务状况 | 0-25分 |

### 2.2 价格分计算公式

**最低评标价法**：
```
价格得分 = (最低报价 / 本供应商报价) × 价格满分
```

**综合评估法**：
```
价格得分 = (评标基准价 / 本供应商报价) × 价格满分
评标基准价 = 满足要求的最低报价（或有效报价的均值）
```

## 三、合同类型选择指南

| 合同类型 | 买方风险 | 卖方风险 | 适用场景 | 政府项目常用度 |
|---------|---------|---------|---------|-------------|
| 固定总价(FFP) | 低 | 高 | 范围明确、需求稳定 | ★★★★★ 最常用 |
| 总价+激励(FPIF) | 低 | 中 | 有激励目标 | ★★★ |
| 总价+经济价格调整(FP-EPA) | 低 | 中 | 周期长、通胀风险 | ★★ |
| 成本+固定费(CPFF) | 高 | 低 | 范围不确定 | ★★ |
| 成本+激励(CPIF) | 中 | 中 | 有成本激励 | ★★ |
| 工料(T&M) | 高 | 低 | 小额、紧急、范围不明 | ★ |

> 政府项目原则上优先使用固定总价合同
