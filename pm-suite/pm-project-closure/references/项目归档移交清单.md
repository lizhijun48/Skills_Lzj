## 三、归档质量检查

| 检查项 | 标准 | 结果 |
|--------|------|------|
| 文件完整性 | 分类清单中所有文件齐全 | ☐ |
| 签章完整性 | 需签字盖章的文件已签章 | ☐ |
| 版本一致性 | 电子版与纸质版内容一致 | ☐ |
| 编目规范性 | 按分类编号，目录清晰 | ☐ |
| 保管期限标注 | 每类文件标注保管期限 | ☐ |
| 移交确认单 | 所有移交对象已签字确认 | ☐ |
