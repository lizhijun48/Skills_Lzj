# 招标文件废标风险自查清单

> 在分析任何招标文件之前，逐项完成本清单。存在🔴项时立即标红。

---

## 一、资质类废标风险

```
□ 是否明确列出企业资质要求（如建筑业企业资质等级）？
  → 若有：我方是否满足？[是/否/联合体可补]

□ 是否要求项目经理/技术负责人持有特定证书？
  → 若有：我方是否有满足要求的人员？[是/否]
  → 人员是否在我方单位缴纳社保满X个月？[是/否]

□ 是否要求近X年完成类似业绩Y个及以上？
  → 若有："类似"定义是否与我方业绩匹配？[是/争议/否]
  → 我方符合条件的业绩有__个（要求≥__个）

□ 是否有年营业额/净资产要求？
  → 若有：我方是否满足？[是/否]

□ 是否有ISO认证/体系认证要求（强制）？
  → 若有：我方是否持有有效证书？[是/否]

□ 是否有等保/信创/其他行业特定认证要求（强制）？
  → 若有：[填入具体要求和我方状态]
```

---

## 二、时间节点合规性核查

```
□ 招标文件发售期（从开始发售到停止发售）
  → 实际天数：__日 → 要求：≥5日 → [合规✅/违规❌]

□ 等标期（从发售日/发布日到投标截止日）
  → 计算：投标截止日______ 减去 发售日______ = __日
  → 项目类型：[依法必须招标工程/政采公开招标/竞争性谈判/磋商/询价]
  → 法定最低要求：[20日/10日/3工作日]
  → [合规✅/违规❌]

□ 中标候选人公示期（如已知）
  → 要求：≥3日 → [合规✅/违规❌/未见说明]

□ 如发现时间节点违规，可在投标截止前10日内提出书面异议
  → 异议截止时间：______
```

## 三、限制性条款扫描

```
□ 是否有注册地/地域限制？（如"本市注册企业"）
  → 若有：🔴 涉嫌违法设定限制，评估是否提出异议

□ 是否要求必须独立承包（禁止联合体）？
  → 若有：且我方资质有短板，则评估放弃参与

□ 是否指定了特定品牌/型号/技术标准？
  → 若有：🟠 疑似定制化，记录具体条款，评估申诉价值

□ 是否设置了异常高的业绩门槛（精确到某一数字）？
  → 若有：🟠 疑似围标，评估竞争对手范围

□ 是否要求"与业主有长期合作关系"或类似表述？
  → 若有：🔴 涉嫌设定不合理条件，可提出异议或投诉
```

---

## 四、合同条款风险扫描

```
□ 付款条件：
  → 预付款：合同金额的__%
  → 里程碑付款：[节点] → [比例]
  → 质保金：合同金额的__% 保留__年
  → 风险评估：[是否可接受/需谈判]

□ 工期条款：
  → 合同工期：__日历天/工作天
  → 工期延误赔偿：每日罚款合同金额的__%，上限__%
  → 风险评估：[工期是否可实现/罚款上限是否可接受]

□ 验收条款：
  → 验收标准：[是否清晰可量化]
  → 验收流程：[描述]
  → 风险：[验收标准模糊=验收风险高]

□ 知识产权条款：
  → 是否要求著作权转让？[是/否]
  → 是否要求源代码移交？[是/否]
  → 风险：[是否影响核心产品知识产权]

□ 不可抗力条款：
  → 是否包含疫情/政策变化等现代不可抗力因素？[是/否]
```

## 五、技术要求合规扫描

```
□ 是否有国产化要求？
  → 若有：CPU/OS/数据库/中间件国产化率要求 = __%
  → 我方方案是否满足？[是/部分满足/否]

□ 是否有等级保护要求？
  → 等保等级：[二级/三级/四级]
  → 我方是否有等保测评能力或资质？[是/否]

□ 技术指标是否存在"唯一性"描述？
  → 示例："响应时间≤500ms"→ 正常
  → 示例："采用XXX算法引擎"→ 🟠 疑似品牌绑定

□ 系统集成是否涉及已有系统对接？
  → 若有：已有系统厂商是否与我方存在竞争关系？[是/否]
  → 接口文档是否开放获取？[是/否/需签NDA]
```

## 六、投标文件编制合规性预查

```
□ 是否要求原件（非复印件）的证书/资质？
  → 若有：[列出清单]，需提前准备借阅/复印授权

□ 是否要求电子投标（CA证书）？
  → 若有：CA证书是否有效？[是/否/需新办]

□ 是否要求递交纸质版+电子版？
  → 份数：正本__份，副本__份，U盘__个

□ 开标方式：[现场开标/电子开标]
  → 如现场开标：开标地点是否需要提前踩点？[是/否]

□ 投标保证金：
  → 金额：__万元
  → 形式：[现金/银行保函/电子保函]
  → 递交截止时间：______
  → 退还时间要求：合同签订后≤5日/5个工作日
```

## 七、竞争格局快速判断

```
□ 本项目是否已有明显的"意向中标人"迹象？
  → 判断依据：[技术参数量身定制/业绩门槛精确匹配/低于市场价格/时间极紧]
  → 综合判断：[有迹象/无明显迹象]

□ 是否了解主要竞争对手？
  → 预计参与的竞争对手：[企业A/企业B/...]
  → 我方优势：[...]
  → 我方劣势：[...]

□ 参照历史中标记录（同类型同规模项目）：
  → 市场均价：__万元
  → 中标价通常为预算的__%~__%
```
