# 评分矩阵计算模板

> 用于快速还原招标文件中的价格评分公式，辅助报价决策

---

## 一、常见价格评分模型公式

### 1. 最低价得满分模型（Low Price Wins）

**公式**：
```
价格得分 = （最低报价 ÷ 投标报价）× 价格满分
```

**适用场景**：货物采购、简单服务采购

**报价策略**：在不低于成本价的前提下尽量压低报价

**示例**：
- 价格满分：20分
- 最低报价（假设为竞争对手）：100万
- 我方报价：105万
- 我方得分：100 ÷ 105 × 20 = 19.05分

---

### 2. 基准价法（Benchmark Price）

**公式（常见变种A）**：
```
基准价 = 所有有效报价的算术平均值
价格得分 = 价格满分 - |（投标报价 - 基准价）÷ 基准价| × K × 价格满分
```
其中 K 为系数，一般取1.0~2.0

**公式（常见变种B）**：
```
基准价 = 控制价 × X%（X通常为85~95）
```

**适用场景**：政府采购工程服务、复杂系统集成项目

**报价策略**：
- 变种A：需预判所有竞争对手报价，预测均价
- 变种B：按照控制价×X%精确计算最优报价点

**示例（变种B）**：
- 控制价：1000万
- 基准价比例：90%，则基准价 = 900万
- 偏差系数K：1.0，价格满分：30分
- 我方报价890万：|（890-900）÷900| × 1.0 × 30 = 0.33分扣分 → 得分29.67分
- 我方报价920万：|（920-900）÷900| × 1.0 × 30 = 0.67分扣分 → 得分29.33分

---

### 3. 中间价法（Middle Price）

**公式**：
```
基准价 = 去掉最高价和最低价后的平均值
评分同基准价法
```

**适用场景**：多家竞争的综合评分项目

**报价策略**：预测去除极值后的均价，向均价靠拢

---

### 4. 固定价差模型（Fixed Deviation）

**公式**：
```
在控制价 ±X% 范围内报价得满分，超出范围每偏差1%扣Y分
```

**示例**：
- 控制价：500万，允许区间：490万~510万
- 区间内报价：满分20分
- 低于490万：每低1%扣1分
- 高于510万：废标

---

### 5. 最低价中标法（Lowest Price）

**适用场景**：竞争性谈判、询价采购、标准货物

**特别注意**：
- 有些项目要求"报价不低于成本"，但"成本"很难核实
- 异常低价投标可能被要求说明，无法说明则废标
- 底线：不能低于直接成本+税费

## 二、技术评分分项计算

### 常见技术评分结构

| 评分项 | 常见分值范围 | 评分依据 |
|-------|------------|---------|
| 技术方案/实施方案 | 15-25分 | 评委主观打分，需针对评分细则定向写 |
| 资质与业绩 | 10-20分 | 客观核查，业绩数量/合同金额 |
| 项目团队 | 5-15分 | 人员证书、经验年限、类似经历 |
| 质量/服务承诺 | 5-10分 | 质保期长度、响应时间承诺 |
| 创新方案 | 5-10分 | 方案亮点、技术先进性 |
| 本地化服务 | 0-5分 | 本地服务中心/维保能力 |

### 业绩加分计算示例

```
基础业绩（满足要求，≥2个）：5分
每多1个类似业绩加0.5分，最高加3分
→ 如有5个业绩：5 + 3 × 0.5 = 6.5分（封顶6.5分，超出按封顶计）
→ 实际若最高8分，则有5个业绩可拿8分
```

## 四、常见坑点

| 坑点 | 说明 |
|-----|-----|
| 业绩"类似"定义 | 招标方可能对"类似"定义极窄，需在答疑期要求明确 |
| 人员证书有效期 | 部分证书有年检要求，过期证书不被认可 |
| 业绩合同金额 | 注意是合同金额还是结算金额，差别可能很大 |
| 评分权重临时调整 | 有些项目在澄清文件中调整了权重，需以最终版为准 |
| 价格得分公式变种 | 同名公式在不同文件中可能有细微差异，必须以原文为准 |
