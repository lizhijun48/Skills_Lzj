# 投标决策 Agent 工作流配置说明书（优化版）

------

## 工作流概览

| 序号 | 节点名称                   | 节点类型 | 模型            | 温度 | Max Token | 描述说明                                                     | 是否可以跳过 |
| ---- | -------------------------- | -------- | --------------- | ---- | --------- | ------------------------------------------------------------ | ------------ |
| 1    | 开始节点                   | 开始     | -               | -    | -         | 接收用户上传的招标文件和公司信息，作为整个流程的入口         | 否           |
| 2    | Step0 GO NO-GO决策         | 大模型   | ERNIE 4.0 Turbo | 0.1  | 2000      | 快速初筛，判断是否值得继续投标，不值得的直接终止，节省成本   | 否           |
| 3    | Step0结果确认              | 交互确认 | -               | -    | -         | 将Step0的初筛结果返回给用户，用户确认是否继续，避免无效计算  | 是           |
| 4    | Step0终止输出              | 结束     | -               | -    | -         | Step0初筛为NO-GO时，输出终止报告，说明不值得投标的原因       | 否           |
| 5    | Step1 招标文件结构化提取   | 大模型   | ERNIE 4.0 Turbo | 0.1  | 4000      | 从招标文件和公司信息中提取结构化数据，为后续决策提供依据     | 否           |
| 6    | Step2 投标决策             | 大模型   | ERNIE 4.0 Turbo | 0.15 | 2000      | 根据提取的信息做出正式投标决策（Go/Conditional Go/Defer/No-Go） | 否           |
| 7    | Step2决策确认              | 交互确认 | -               | -    | -         | 将Step2的决策结论返回给用户，用户确认方向是否正确，可补充信息后再继续 | **否**       |
| 8    | Step2终止输出              | 结束     | -               | -    | -         | Step2决策为No-Go时，输出终止报告，说明不投标的原因           | 否           |
| 9    | Step2.5 关键信息结构化提取 | 大模型   | ERNIE 4.0 Turbo | 0.1  | 3000      | 从Step1的解析结果中提取6项关键结构化信息，作为响应文件生成的对照标准 | 否           |
| 10   | Step3 投标响应文件生成     | 大模型   | ERNIE 4.0 Turbo | 0.3  | 4000      | 根据决策结论生成完整的投标响应文件草稿                       | 否           |
| 11   | Step3 响应文件最终审核     | 大模型   | ERNIE 4.0 Turbo | 0.2  | 3000      | 对响应文件草稿进行最终审核，逐项打分，输出修改建议           | 否           |
| 12   | Step3审核确认              | 交互确认 | -               | -    | -         | 将Step3的审核结果返回给用户，用户确认是否通过，可补充信息后重新生成 | 是           |
| 13   | Step3终止输出              | 结束     | -               | -    | -         | Step3审核不通过且超过最大重试次数时，输出终止报告            | 否           |
| 14   | Step4 投标决策报告输出     | 大模型   | ERNIE 4.0 Turbo | 0.2  | 2000      | 整合所有信息生成完整投标决策报告，给出明确行动建议           | 否           |
| 15   | 输出最终报告               | 结束     | -               | -    | -         | 将最终报告返回给用户，流程结束                               | 否           |

## 节点2 Step0 GO NO-GO决策

| 配置项       | 值                                                           |
| ------------ | ------------------------------------------------------------ |
| 节点名称     | Step0 GO NO-GO决策                                           |
| 节点类型     | 大模型（LLM）                                                |
| 模型         | ERNIE 4.0 Turbo                                              |
| 温度         | 0.1                                                          |
| Max Token    | 2000                                                         |
| 描述说明     | 快速初筛，判断是否值得继续投标，不值得的直接终止，节省后续计算成本 |
| 是否可以跳过 | 否                                                           |

| 关联关系 | 说明 |
|----------|
| 前向节点 | 开始节点 |
| 后向节点 | Step0结果确认、Step0终止输出 |

> **改进说明：Max Token 从 1000 提升到 2000，避免因文件过大导致误判。**

### 输入

| 参数名       | 类型 | 值                      | 说明                 |
| ------------ | ---- | ----------------------- | -------------------- |
| bid_document | 引用 | 开始节点的 bid_document | 快速判断是否值得继续 |
| company_info | 引用 | 开始节点的 company_info | 快速判断是否值得继续 |

### 系统提示词

```
你是投标初筛专家。根据招标文件和公司信息，快速给出 GO / NO-GO 初步结论。 快速判断规则（30秒内能决定的）： 1. 资质完全不满足 → NO-GO 2. 预算太低 / 工期不可能 → NO-GO 3. 资质基本满足 + 利润合理 → GO 4. 拿不准 → GO（交给后续节点详细判断） 输出格式： 【Step0 决策】GO / NO-GO 【理由】：一句话 
```

### 用户提示词

```
请快速判断是否值得投标： 招标文件：{{bid_document}} 公司信息：{{company_info}} 请输出 GO 或 NO-GO。 
```

### 输出

| 参数名          | 类型   | 说明                                                 |
| --------------- | ------ | ---------------------------------------------------- |
| go_no_go_result | String | GO / NO-GO + 理由，传入 Step0结果确认、Step0终止输出 |

### 系统提示词

```

```

| 参数名             | 类型 | 说明                                                         |

