# 评标方法详解

> 本文件为 `pm-bid-proposal` 的参考资源，系统梳理《招标投标法》《政府采购法》及各行业规范中规定的评标方法，帮助投标人员精准对标评分规则。

---

## 一、评标方法总览

| 方法 | 法律依据 | 适用场景 | 核心逻辑 |
|------|---------|---------|---------|
| 综合评估法 | 《招标投标法》第41条 | 技术+商务+价格均重要的复杂项目 | 加权总分最高者中标 |
| 最低评标价法 | 《招标投标法》第41条 | 标准/通用货物、简单服务 | 满足技术要求后最低价中标 |
| 经评审的最低投标价法 | 《招标投标法实施条例》第55条 | 具有通用技术标准的工程 | 技术合格后按评标价排序 |
| 性价比法 | 《政府采购法》体系 | 政府采购中的非标货物/服务 | 商务/技术得分÷报价 |
| 竞争性磋商 | 《政府采购竞争性磋商采购方式管理暂行办法》 | 复杂、不确定需求 | 磋商→最终报价→综合评分 |

## 二、综合评估法（最常见，重点掌握）

### 2.1 基本框架

```
综合得分 = 技术分 × W_t + 商务分 × W_b + 价格分 × W_p

其中：
- W_t + W_b + W_p = 100%
- 通常：技术 40%-60%，商务 10%-30%，价格 20%-40%
- 政府采购项目：价格分权重一般不低于10%
```

### 2.2 技术分评分细则（典型模型）

| 评分项 | 分值 | 评分标准 | 得分要点 |
|--------|------|---------|---------|
| 技术方案完整性 | 10-20分 | 缺1章扣X分，方案不合理扣X分 | 逐章覆盖招标文件所有技术要求 |
| 技术方案先进性 | 5-10分 | 有创新/正偏离加分 | 做好正偏离表，标注技术优势 |
| 项目团队 | 5-15分 | 项目经理资质+经验、核心人员配置 | PM一建/PMP加分，团队配置超标加分 |
| 企业业绩 | 5-15分 | 同类项目数量+规模 | 业绩从大到小排列，标注金额和业主 |
| 售后服务 | 5-10分 | 响应时间、质保期、培训 | 超出招标要求的服务承诺加分 |
| 实施方案 | 5-10分 | 进度合理性、质量管理 | 甘特图+关键路径+质量检查点 |

### 2.3 价格分计算公式（3种常见模型）

**模型A：基准价法（最常见）**

```
价格分 = 满分 × (1 - |报价 - 基准价| / 基准价 × 偏差系数)

基准价确定方式：
  方式1：所有有效报价的算术平均值
  方式2：所有有效报价去掉最高最低后的算术平均值
  方式3：招标控制价 × 系数（如0.85-0.95）
  
偏差系数：通常为 1-3（系数越大，偏离扣分越重）
```

**模型B：最低价法**

```
价格分 = 最低有效报价 / 本报价 × 满分

特点：报价越低，价格分越高
适用：技术标准统一的货物采购
风险：可能引发恶性低价竞争
```

**模型C：性价比法**

```
价格分 = (技术分 + 商务分) / 报价 × 系数

特点：综合考虑性价比
适用：非标定制化服务采购
```

### 2.4 投标策略适配

| 评分模型 | 我方技术强 | 我方价格优 | 我方均衡 |
|---------|-----------|-----------|---------|
| 综合评估法（技术权重高） | 放大技术分优势，适度拉高报价 | 技术分是短板，需弥补 | 稳健报价，不激进 |
| 综合评估法（价格权重高） | 技术分保底，报价须有竞争力 | 价格优势明显，可适当提高技术投入 | 找到技术-价格平衡点 |
| 最低评标价法 | 技术仅须满足门槛，全力压价 | 天然优势 | 严格控制成本 |

## 三、最低评标价法

### 3.1 适用条件

- 具有通用技术标准的货物
- 规格/性能统一的标准化产品
- 技术规格明确、性能指标可量化的项目

### 3.2 评标程序

```
1. 资格审查 → 不合格者淘汰
2. 符合性审查 → 不响应者淘汰  
3. 技术评审 → 仅判"满足/不满足"（不打分）
4. 价格评审 → 满足技术要求者中最低价中标
5. 价格修正 → 算术性错误修正后排序
```

### 3.3 投标注意事项

- 技术方案只需"满足"，不需"超越"
- 报价是唯一竞争维度
- 严禁低于成本价投标（法律风险）
- 算术性错误修正规则须了解

## 四、经评审的最低投标价法

### 4.1 与最低评标价法的区别

| 对比项 | 最低评标价法 | 经评审的最低投标价法 |
|--------|------------|-------------------|
| 适用对象 | 货物 | 工程 |
| 技术评审 | 满足/不满足 | 量化评审+价格调整 |
| 价格处理 | 直接比价 | 评审价=报价+调整因素 |
| 调整因素 | 无 | 工期、质量、付款等商务条件折算 |

### 4.2 评审价计算

```
评审价 = 投标报价 + 调整因素
       = 投标报价 + 工期调整 + 质量调整 + 付款调整 + ...

其中调整因素按招标文件给定的折算公式计算
```

## 五、竞争性磋商

### 5.1 适用场景

- 技术复杂、需求不确定
- 艺术品采购、科研服务等
- 市场竞争不充分的项目

### 5.2 流程

```
1. 发布磋商公告/邀请
2. 提交首次响应文件
3. 磋商（多轮）：明确需求、讨论方案
4. 最终报价（一次性）
5. 综合评分排序
6. 确定成交供应商
```

### 5.3 与公开招标的区别

| 对比项 | 公开招标 | 竞争性磋商 |
|--------|---------|-----------|
| 需求明确度 | 必须明确 | 可逐步明确 |
| 报价次数 | 1次 | 多轮磋商后1次最终报价 |
| 评审方式 | 严格按照评标标准 | 磋商后综合评估 |
| 灵活性 | 低 | 高 |
| 时间 | 长（法定20天以上） | 较短 |

## 六、评标中的常见陷阱

### 6.1 投标方常犯错误

| 错误 | 后果 | 预防 |
|------|------|------|
| 只关注总分，忽略分项最低分要求 | 某项0分导致总分不够 | 逐项核对评分标准 |
| 技术方案写太多，但未对评分项 | 不得分 | 按评分标准逐条对应写 |
| 业绩展示无重点 | 满分项未拿到 | 对照评分标准选最匹配业绩 |
| 忽略废标条款中的"实质性响应" | 废标 | 关键条款逐条正/负偏离 |
| 报价低于成本 | 被判废标或后续亏损 | 报价不低于成本底线 |

### 6.2 评标委员会的工作逻辑

1. **先审资格** → 不合格直接淘汰
2. **再审符合性** → 实质性响应检查
3. **然后打分** → 按评分标准逐项
4. **最后排序** → 综合得分排名

> **关键洞察**：投标文件编制顺序应与评标委员会审阅顺序一致——先过"准入关"（资格/符合性），再争"得分关"（技术/商务/价格分）。

## 七、快速参考卡

| 评标方法 | 胜率最大化策略 |
|---------|-------------|
| 综合评估法（技术50%+） | 技术方案对标评分标准逐条响应，正偏离突出，方案亮点可视化 |
| 综合评估法（价格50%+） | 成本控制极值化，报价接近预估基准价 |
| 最低评标价法 | 技术方案"刚好满足"，成本压缩到极致 |
| 性价比法 | 提升技术分同时控制报价，追求高比值 |
| 竞争性磋商 | 磋商阶段充分理解需求，最终报价精准 |
