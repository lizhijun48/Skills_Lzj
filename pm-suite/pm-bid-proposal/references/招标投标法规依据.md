# 招标投标法规依据

> 本文件为 pm-bid-proposal 技能的法规参考背景，编制投标方案时须遵循以下法规。

---

## 法律层级

| 层级 | 文件 | 核心条款 |
|------|------|---------|
| 法律 | **《中华人民共和国招标投标法》**（2017年修订） | 第3条：强制招标范围；第4章：开标评标中标 |
| 法律 | **《中华人民共和国政府采购法》**（2014年修订） | 第26条：采购方式（公开招标/邀请招标/竞争性谈判/竞争性磋商/单一来源/询价） |
| 行政法规 | **《招标投标法实施条例》**（2019年修订） | 第2章：招标程序；第3章：投标要求；第6章：法律责任 |
| 行政法规 | **《政府采购法实施条例》** | 第7章：政府采购程序 |

---

## 强制招标范围（招标投标法第3条）

以下项目必须招标：

1. **大型基础设施、公用事业**等关系社会公共利益、公众安全的项目
2. **全部或部分使用国有资金投资**或者国家融资的项目
3. **使用国际组织或外国政府贷款**、援助资金的项目

**规模标准**（发改委16号令）：
- 施工单项合同估算价 ≥ 400万元
- 重要设备材料采购 ≥ 200万元
- 勘察设计监理服务 ≥ 100万元

---

## 招标方式

| 方式 | 适用条件 | 特点 |
|------|---------|------|
| 公开招标 | 默认方式 | 公告发布，不特定投标人 |
| 邀请招标 | 技术复杂、有特殊要求、涉及国家安全/秘密、公开招标费用占比过大 | ≥3家特定投标人 |
| 竞争性磋商 | 政府购买服务、技术复杂、不能确定详细规格、市场竞争不充分 | 磋商+综合评分 |
| 单一来源 | 只能从唯一供应商处采购、紧急情况、一致性要求 | 特殊情况 |

---

## 投标文件组成（标准结构）

### 商务标

- 投标函及投标函附录
- 法定代表人身份证明及授权委托书
- 投标保证金
- 资格审查资料（营业执照、资质证书、业绩证明、财务报表）
- 项目管理机构（项目经理简历、证书、社保）
- 拟分包项目情况表
- 其他材料（获奖、专利、标准参编证明、客户推荐信）

### 技术标

- 项目理解与需求分析
- 总体设计方案
- 详细技术方案（按建设内容分章）
- 实施方案（组织、进度、质量、风险）
- 售后服务与培训

### 报价

- 投标总价
- 分项报价表
- 价格构成说明

---

## 评标方法

| 方法 | 计算方式 | 适用场景 |
|------|---------|---------|
| 综合评分法 | 技术分 + 商务分 + 价格分（加权） | 复杂项目，技术权重高 |
| 经评审的最低投标价法 | 满足要求的前提下价格最低 | 标准化产品或服务 |
| 性价比法 | 技术得分/价格 | 部分政府采购 |

---

## 关键红线

| 红线 | 后果 | 预防措施 |
|------|------|---------|
| 资质不满足 | **废标**（资格审查不通过） | 投标前逐项核对资质门槛 |
| 投标文件不完整 | **废标** | 编制投标文件清单，逐项打勾 |
| 未按要求盖章签字 | **废标** | 独立复核人制度 |
| 报价超过控制价 | **废标** | 提前核算，留安全边际 |
| 串通投标 | **取消资格 + 罚款 + 刑事** | 绝对红线 |
| 虚假材料 | **取消资格 + 列入黑名单** | 绝对红线，所有业绩必须真实 |

## 招投标时间约束标准库

> 依据：《招标投标法》《政府采购法》及其实施条例、《政府采购非招标采购方式管理办法》、《政府采购竞争性磋商采购方式管理暂行办法》、《经营性公路建设项目投资人招标投标管理规定》

### 一、项目分类与等标期下限

在进行时间合规性判断前，必须首先确认项目类型：

| 项目类型 | 法律依据 | 等标期下限 |
|---------|---------|----------|
| 依法必须招标的工程建设项目（公开招标） | 《招标投标法》第24条 | **≥20日** |
| 非依法必须招标的工程建设项目 | 《招标投标法》第24条 | 无固定下限，需满足"合理时间" |
| 经营性公路建设项目投资人招标 | 《经营性公路建设项目投资人招标投标管理规定》第16条 | **≥45个工作日** |
| 政府采购货物/服务（公开招标） | 《政府采购法》第35条 | **≥20日** |
| 政府采购（竞争性谈判） | 《政府采购非招标采购方式管理办法》第29条 | **≥3个工作日** |
| 政府采购（询价采购） | 《政府采购非招标采购方式管理办法》第45条 | **≥3个工作日** |
| 政府采购（竞争性磋商） | 《政府采购竞争性磋商采购方式管理暂行办法》第10条 | **≥10日** |
| 政府采购（单一来源采购） | — | 无等标期要求 |

### 二、等标期判定规则

#### 2.1 依法必须招标的工程建设项目
- 等标期**必须≥20日**
- **不存在任何可合法缩短的情形**（"工作需要、时间紧急"不构成合法缩短理由）

#### 2.2 非依法必须招标的工程建设项目
- 法律未规定具体天数
- 以"合理时间"为标准，即潜在投标人编制投标文件所需的正常周期

#### 2.3 政府采购项目
- 公开招标：**≥20日**
- 竞争性谈判：**≥3个工作日**
- 询价：**≥3个工作日**
- 竞争性磋商：**≥10日**
- 单一来源：无等标期要求

### 三、全流程关键时间节点对照表

| 时间节点 | 《招标投标法》（工程建设） | 《政府采购法》（货物/服务） |
|---------|----------------------|------------------------|
| 招标文件发售期 | **≥5日**（《招标投标法实施条例》第16条） | 同 |
| 等标期（公开招标） | **≥20日** | **≥20日** |
| 投标人对文件提出异议截止 | **投标截止时间前10日** | — |
| 招标人答复异议时间 | **收到异议之日起3日内** | — |
| 供应商提出质疑时间 | — | **知道或应知其权益受损之日起7个工作日内** |
| 采购人答复质疑时间 | — | **收到书面质疑后7个工作日内** |
| 中标候选人公示期 | **≥3日**（《招标投标法实施条例》第54条） | — |
| 中标通知书发出后签约 | **≤30日**（《招标投标法》第46条） | **≤30日** |
| 退还投标保证金 | **合同签订后≤5日** | **合同签订后≤5个工作日** |

### 四、时间约束速查表

| 时间事项 | 强制要求 | 违规后果 |
|---------|---------|---------|
| 依法必须招标项目等标期 | ≥20日 | 招标无效 |
| 招标文件发售期 | ≥5日 | 招标无效 |
| 中标候选人公示期 | ≥3日 | 招标无效 |
| 签约时间 | ≤30日 | 承担缔约过失责任 |
| 退还投标保证金（工程） | ≤5日 | 承担违约责任 |
| 退还投标保证金（政采） | ≤5个工作日 | 承担违约责任 |

### 五、合规判定三步法（实操工具）

```
Step 1：确定项目类型
  → 工程建设项目（依法必须招标 / 非依法必须招标）
  → 政府采购项目（货物/服务/工程）
  → 经营性公路建设项目

Step 2：确定采购方式
  → 公开招标 / 邀请招标 / 竞争性谈判 / 询价 / 竞争性磋商 / 单一来源

Step 3：对照上表判定时间是否合规
  → 等标期是否满足下限？
  → 各节点时间是否在法定范围内？
```

**核心口诀**：工程施工二十硬，政采货物二十同；非标方式三五起，公路投资四十五。

### 六、常见违法违规行为速判表

| 序号 | 违法违规行为 | 违反条款 |
|-----|------------|---------|
| 1 | 依法必须招标项目等标期少于20日 | 《招标投标法》第24条 |
| 2 | 政府采购公开招标等标期少于20日 | 《政府采购法》第35条 |
| 3 | 招标文件发售期少于5日 | 《招标投标法实施条例》第16条 |
| 4 | 中标候选人公示期少于3日 | 《招标投标法实施条例》第54条 |
| 5 | 以"工作需要、时间紧急"为由缩短等标期 | 《招标投标法》第24条（无豁免条款） |
| 6 | 中标通知书发出后超过30日未签约 | 《招标投标法》第46条 |
