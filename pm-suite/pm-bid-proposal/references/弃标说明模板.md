# 弃标说明模板

> 适用场景：Go/No-Go 决策结果为 No-Go 或 Defer（暂缓）时，向投标委员会或管理层说明原因，并明确后续跟进计划。

---

## 一、弃标说明（标准格式）

| 字段 | 内容 |
|:---|:---|
| **项目名称** | |
| **招标编号** | |
| **采购人/招标人** | |
| **决策日期** | |
| **决策结果** | ☐ No-Go（放弃） ☐ Defer（暂缓，定期复审） |
| **决策依据** | ☐ 第零步量化评估 ☐ 一票否决项触发 ☐ 投标委员会决议 |

---

### 1. 弃标原因（按优先级填写，最多3条）

| 优先级 | 原因分类 | 具体说明 |
|:---:|:---|:---|
| P0 | ☐ 资质不满足 ☐ 一票否决项触发 | |
| P1 | ☐ 技术可行性不足 ☐ 商务可行性不足 | |
| P2 | ☐ 成本不可控 ☐ 工期不可达 ☐ 竞争对手优势明显 | |

> **填写说明**：原因必须引用第零步的评估结论，不可泛泛而谈。示例：「对手A在近3次同类项目中均报价下浮>10%，我方成本底线无法跟进，报价策略模拟中标概率<20%」

---

### 2. 决策过程记录

| 步骤 | 结论 | 依据 |
|:---|:---|:---|
| Go/No-Go 量化评估 | 总分 __ / 100，结论：No-Go | 详见第零步评估表 |
| 一票否决项检查 | ☐ 未触发 ☐ **触发**：______ | ______ |
| 投标委员会审议 | ☐ 无需上会 ☐ 已上会，决议：No-Go | 会议纪要编号：______ |

---

### 3. 后续跟进计划（Defer 项目必填）

| 跟进动作 | 负责人 | 完成时限 | 输出物 |
|:---|:---|:---|:---|
| 补齐资质/业绩短板 | | 复审前 | 资质/案例补充证明 |
| 跟踪对手动态（报价偏好变化） | | 每月 | 对手画像更新记录 |
| 跟踪政策/法规变化 | | 每季度 | 合规性评估报告 |
| 定期复审（Defer 项目） | | 每 __ 个月 | 复审决策记录 |

> **Defer 项目复审触发条件**（满足任一即重新评估）：
> - 项目重新招标（新招标公告发布）
> - 我方资质/案例已补齐
> - 对手情况发生重大变化（并购/退出/报价策略改变）
> - 距离上次评估超过 6 个月

---

## 二、归档检查清单

弃标说明填写完成后，按以下清单归档：

- [ ] 弃标说明已填写完整（含原因、决策过程、后续计划）
- [ ] 第零步 Go/No-Go 评估表已作为附件归档
- [ ] 投标委员会会议纪要（如需上会）已作为附件归档
- [ ] 文件已存入 `弃标项目档案/` 目录，命名格式：`弃标说明_{项目名称}_{日期}.md`
- [ ] Defer 项目已登记到 `弃标项目跟踪表.md`（含复审日期）
