# 软件技术方案模板库

> **用途**：投标技术方案编制时，根据项目类型选取对应架构模板，快速生成符合软件工程规范的技术方案章节。
> **核心原则**：每种架构模板包含标准章节结构 + 核心架构图描述 + 关键技术选型建议 + 差异化亮点锚点。

---

## 模板一：云原生架构（微服务 + K8s）

### 适用场景

- 政务云平台 / 混合云部署
- 高并发、高可用要求的信息化系统
- 需要弹性伸缩的互联网+政务服务平台
- 数字化监管平台 / 一网通办类系统

### 标准章节结构

```
X.1 云原生总体架构
  X.1.1 架构设计原则（弹性伸缩、高可用、灰度发布、可观测性）
  X.1.2 分层架构：接入层（API Gateway）→ 业务服务层（微服务集群）→ 数据层
  X.1.3 服务网格（Service Mesh）方案（如 Istio/Linkerd）
  X.1.4 API 网关选型与流量治理策略

X.2 容器编排与部署
  X.2.1 Kubernetes 集群规划（Master/Worker 节点配置、高可用拓扑）
  X.2.2 容器镜像管理策略（Harbor/阿里云ACR）
  X.2.3 CI/CD 流水线设计（代码提交 → 构建 → 测试 → 部署）
  X.2.4 灰度发布与 A/B 测试方案

X.3 服务治理
  X.3.1 服务注册与发现（Nacos/Consul/Eureka）
  X.3.2 配置中心（Nacos/Apollo）
  X.3.3 分布式链路追踪（SkyWalking/Jaeger）
  X.3.4 熔断降级与限流策略（Sentinel/Hystrix）

X.4 数据架构
  X.4.1 关系型数据库（MySQL/PostgreSQL/PolarDB）+ 读写分离
  X.4.2 缓存架构（Redis Cluster）
  X.4.3 消息队列（RocketMQ/Kafka）
  X.4.4 分布式事务方案（Seata/最终一致性）
```

### 架构图描述

```
┌──────────────────────────────────────────────────────┐
│                   接入层（API Gateway）                 │
│     认证鉴权 | 流量控制 | 协议转换 | 日志采集           │
├──────────┬──────────┬──────────┬──────────────────────┤
│ 业务服务A │ 业务服务B │ 业务服务C │  公共服务层          │
│ (用户中心) │ (流程引擎) │ (数据分析) │  消息 | 文件 | 短信  │
├──────────┴──────────┴──────────┴──────────────────────┤
│                  基础设施层（K8s Cluster）              │
│    Pod | Service | Ingress | ConfigMap | Secret       │
├──────────────────────────────────────────────────────┤
│                      数据层                           │
│  MySQL Cluster | Redis Cluster | RocketMQ | MinIO     │
└──────────────────────────────────────────────────────┘
         ↓ 可观测性（SkyWalking + Prometheus + ELK）
```

### 关键技术选型矩阵

| 组件 | 首选 | 备选 | 选择依据 |
|------|------|------|---------|
| 容器编排 | K8s 1.28+ | K3s（边缘场景） | 政务云标配 |
| 服务注册 | Nacos | Consul | 国产化适配要求 |
| API网关 | Shenyu/APISIX | Spring Cloud Gateway | 性能与扩展性 |
| 配置中心 | Nacos | Apollo | 与服务注册统一 |
| 链路追踪 | SkyWalking | Jaeger | Apache 社区活跃度 |
| 消息队列 | RocketMQ | Kafka | 事务消息支持 |
| 缓存 | Redis Cluster | — | 标准方案 |

### 差异化亮点锚点

1. **自研服务治理平台**（如有）：展示可视化服务拓扑、自动熔断策略配置
2. **信创适配经验**：列出已适配的国产数据库/中间件清单
3. **弹性伸缩实测数据**：展示某项目从100到10000 QPS的自动扩容曲线
4. **CI/CD实践**：展示代码提交到上线的时间从X天缩短到Y小时的案例

## 模板二：AIoT 平台架构

### 适用场景

- 智慧城市物联网平台
- 智慧园区/智慧楼宇
- 工业物联网（IIoT）
- 智慧监测（桥梁/地灾/环保/水利）

### 标准章节结构

```
X.1 AIoT 总体架构
  X.1.1 架构设计原则（云边协同、协议兼容、安全可靠、弹性扩展）
  X.1.2 五层架构：感知层 → 接入层 → 边缘层 → 平台层 → 应用层
  X.1.3 云边协同策略（边缘自治 + 云端统一管理）

X.2 感知与接入层
  X.2.1 多协议兼容方案（MQTT/Modbus/CoAP/HTTP/WebSocket/LoRaWAN/NB-IoT）
  X.2.2 设备接入网关设计（连接管理、协议转换、设备影子）
  X.2.3 设备认证与安全（一机一密、X.509证书、TLS加密）
  X.2.4 已适配设备协议清单（根据项目实际列出）

X.3 边缘计算层
  X.3.1 边缘网关架构（ARM/x86异构支持）
  X.3.2 边缘计算能力（本地规则引擎、数据预处理、断网续传）
  X.3.3 边缘AI推理（模型量化、NPU/TPU适配）
  X.3.4 边缘OTA升级方案

X.4 平台层
  X.4.1 设备管理（生命周期管理、分组管理、固件管理）
  X.4.2 数据中台（时序数据存储TDengine/InfluxDB、数据清洗ETL）
  X.4.3 规则引擎（Cron定时/设备触发/数据阈值/复合条件）
  X.4.4 AI/大数据分析（异常检测、预测性维护、能耗优化）

X.5 应用层
  X.5.1 可视化大屏（3D数字孪生/WebGL）
  X.5.2 移动端App/小程序
  X.5.3 告警通知（短信/微信/钉钉/邮件）
  X.5.4 北向API开放平台
```

### 架构图描述

```
感知层          接入层           边缘层          平台层          应用层
┌────┐         ┌──────┐       ┌──────┐       ┌──────┐       ┌──────┐
│传感器│──MQTT──→│      │       │规则引擎│       │设备管理│       │大屏展示│
│摄像头│──RTSP──→│ 设备  │──────→│数据过滤│──────→│数据中台│──────→│移动App│
│PLC   │──Modbus→│ 接入  │       │边缘AI │       │告警引擎│       │API开放│
│网关  │──HTTP──→│ 网关  │       │OTA管理│       │消息推送│       │报表分析│
└────┘  LoRaWAN └──────┘       └──────┘       └──────┘       └──────┘
                      ↑            ↑              ↑
                 云边管理通道    断网续传      ┌──────────┐
                                              │ 安全体系   │
                                              │ 设备认证   │
                                              │ 通信加密   │
                                              │ 数据安全   │
                                              └──────────┘
```

### 关键技术选型矩阵

| 组件 | 首选 | 备选 | 选择依据 |
|------|------|------|---------|
| 设备接入 | EMQX | ThingsBoard | 百万级并发连接支持 |
| 时序数据库 | TDengine | InfluxDB | 国产化 + 10x性能优势 |
| 边缘计算框架 | EdgeX Foundry | KubeEdge | 开源生态成熟度 |
| 规则引擎 | Node-RED | 自研轻量引擎 | 可视化编排 |
| AI推理框架 | ONNX Runtime | TensorRT | 跨平台兼容 |
| 消息中间件 | EMQX Broker | RabbitMQ | MQTT原生支持 |

### 差异化亮点锚点

1. **已连接设备规模**：展示"X万+设备、Y千/秒数据点"的实测数据
2. **边缘AI案例**：展示在某工厂/工地部署的边缘推理，延迟从Xms降低到Yms
3. **协议适配广度**：列出已支持的全部协议清单（尤其标注自研的协议适配器）
4. **数字孪生演示**：现场演示3D场景 + 实时数据叠加
5. **国产化适配**：展示在国产CPU（飞腾/鲲鹏）+ 国产OS（麒麟/统信）上的部署案例

## 模板三：大数据/数据中台架构

### 适用场景

- 政务数据中台/数据共享交换平台
- 企业数据仓库/BI分析平台
- 大数据分析/数据治理项目
- 数据要素市场化平台

### 标准章节结构

```
X.1 数据架构总体设计
  X.1.1 架构设计原则（数据驱动、标准先行、安全可控、开放共享）
  X.1.2 全链路架构：数据源 → 采集 → 存储 → 计算 → 服务 → 应用
  X.1.3 数据分层模型：ODS → DWD → DWS → ADS

X.2 数据采集与集成
  X.2.1 多源异构数据接入方案（关系库/文件/API/IoT/日志）
  X.2.2 实时采集（CDC/Kafka Connect/Flume）
  X.2.3 批量采集（DataX/Sqoop/自定义ETL）
  X.2.4 数据质量校验规则（完整性/一致性/准确性/及时性）

X.3 数据存储与计算
  X.3.1 数据湖方案（Hudi/Iceberg/Delta Lake）
  X.3.2 离线计算（Spark/Hive/MapReduce）
  X.3.3 实时计算（Flink/Spark Streaming）
  X.3.4 OLAP分析引擎（ClickHouse/Doris/StarRocks）

X.4 数据治理
  X.4.1 数据标准管理（参考国标/行业标准体系）
  X.4.2 数据资产管理（元数据管理/数据血缘/数据地图）
  X.4.3 数据质量管理（质量规则配置/质量报告/问题追踪）
  X.4.4 数据安全管理（分类分级/脱敏/访问控制/审计）

X.5 数据服务
  X.5.1 数据API服务（RESTful API/数据网关）
  X.5.2 数据可视化（BI仪表盘/自助分析）
  X.5.3 数据共享交换（数据沙箱/隐私计算）
```

### 关键技术选型矩阵

| 组件 | 首选 | 备选 | 选择依据 |
|------|------|------|---------|
| 数据湖格式 | Apache Hudi | Iceberg | 增量更新 + CDC友好 |
| 实时计算 | Flink 1.18 | Spark Streaming | 真正流处理语义 |
| OLAP引擎 | ClickHouse | StarRocks/Doris | 查询性能 + 社区规模 |
| 数据集成 | DataX + Flink CDC | Seatunnel | 阿里系生态兼容性 |
| 元数据管理 | Atlas（定制） | DataHub | 血缘分析成熟度 |
| 任务调度 | DolphinScheduler | Airflow | 可视化 + 中文社区 |

### 差异化亮点锚点

1. **数据治理方法论**：展示自研/DAMA定制化的数据治理框架
2. **数据迁移案例**：展示某项目从X TB数据中迁移并清洗的指标（准确率99.9%+）
3. **实时处理能力**：展示毫秒级实时计算 + 大屏实时刷新的案例
4. **标准参编经验**：列出参与制定的数据标准/规范

- 中小企业信息化快速交付
- 政府部门内部管理系统（OA/人事/财务）

### 标准章节结构

```
X.1 低代码平台架构
  X.1.1 平台设计理念（模型驱动、组件化、可扩展）
  X.1.2 核心能力：表单设计器 + 流程引擎 + 报表设计器 + 权限管理

X.2 可视化开发能力
  X.2.1 拖拽式页面搭建（PC端 + 移动端）
  X.2.2 可视化流程编排（BPMN 2.0兼容）
  X.2.3 数据模型设计器（ER图可视化建表）
  X.2.4 自定义组件开发SDK

X.3 集成与扩展
  X.3.1 第三方系统集成能力（API编排、Webhook、消息队列）
  X.3.2 自定义代码扩展（Java/Python脚本节点）
  X.3.3 多租户数据隔离策略
```

### 差异化亮点锚点

1. **交付速度**：展示"X个工作日完成Y个模块搭建"的案例
2. **自主可控**：核心引擎自研（非OEM其他产品）
3. **信创适配**：支持的国产数据库/中间件列表
4. **二次开发能力**：展示源码级定制案例
