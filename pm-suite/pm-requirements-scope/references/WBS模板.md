# WBS模板

> 适用于政府/国企信息化项目，对标PMBOK第5章创建WBS + 100%原则 + 8/80小时规则

---

## 一、WBS编码规范

| 规则 | 说明 |
|------|------|
| 编码体系 | 每层用`.`分隔，如1.4.2.1 |
| 唯一性 | 每个WBS编码唯一对应一个工作包 |
| 不可跳号 | 同级编号连续，中间不跳号 |
| 层级深度 | 建议3-4层，最深不超过5层 |
| 工作包粒度 | 8-80小时工作量 |

## 三、WBS词典模板

| 字段 | 内容 |
|------|------|
| WBS编码 | 1.4.2.1 |
| 工作包名称 | 传感器数据采集接口开发 |
| 工作描述 | 开发传感器数据采集RESTful API，支持Modbus/MQTT协议，实现数据解析、清洗、入库 |
| 负责人 | 张XX |
| 前置工作包 | 1.4.1 基础平台 |
| 可交付成果 | API接口代码+接口文档+单元测试报告 |
| 验收标准 | 1.支持3种以上传感器协议 2.数据延迟<500ms 3.单元测试覆盖率≥80% |
| 估算工时 | 120人时 |
| 估算成本 | 48,000元 |
| 关联需求 | REQ-003, REQ-008 |
| 关联风险 | RSK-005(协议兼容性) |

## 四、WBS完整性自检清单

- [ ] 100%原则：WBS覆盖范围说明书全部工作
- [ ] 互斥原则：各工作包之间无重叠
- [ ] 工作包粒度：8-80小时
- [ ] 每个工作包有明确的可交付成果
- [ ] 每个工作包有验收标准
- [ ] WBS词典填写完整
- [ ] 需求→WBS→测试用例全链路可追踪（RTM一致性）
- [ ] 排除项已在范围说明书中明确
