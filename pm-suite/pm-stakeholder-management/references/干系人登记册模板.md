## Salience 模型辅助表

当权力-利益矩阵无法区分时使用：

| 编号 | Power(Y/N) | Legitimacy(Y/N) | Urgency(Y/N) | 类型 | 关注度 |
|------|-----------|-----------------|-------------|------|--------|
| S01 | | | | 潜伏/裁量/要求/支配/危险/依赖/确定 | |
| S02 | | | | | |

**类型判定**：
- P only → 潜伏型（有能力但无正当理由不紧迫）
- L only → 裁量型（有正当理由但无能力不紧迫）
- U only → 要求型（紧迫但无能力无正当理由）
- P+L → 支配型（有能力和正当理由）
- P+U → 危险型（有能力且紧迫）
- L+U → 依赖型（有正当理由且紧迫）
- P+L+U → 确定型（最需关注，三者兼备）
