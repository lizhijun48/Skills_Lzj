# 挣值管理 EVM 详解

> 本文件为 `pm-project-delivery` 的参考资源，系统梳理挣值管理（Earned Value Management）的核心公式、计算方法和实战应用，帮助项目经理用数据驱动项目绩效分析。

---

## 一、EVM 基本概念

### 1.1 三大核心变量

| 变量 | 全称 | 含义 | 计算方式 |
|------|------|------|---------|
| **PV** | Planned Value（计划价值） | 截至某时点应完成工作的预算成本 | 计划工作量 × 预算单价 |
| **EV** | Earned Value（挣值） | 截至某时点实际完成工作的预算价值 | 实际完成工作量 × 预算单价 |
| **AC** | Actual Cost（实际成本） | 截至某时点实际发生的成本 | 财务实际支出 |

### 1.2 图解理解

```
         预算
          │
    BAC ──┤──────────────────────
          │         ╱ EV
          │       ╱
    PV ──┤─────╱────────────────
          │   ╱
          │ ╱ AC
          │╱
          └────────────────────── 时间
              ↑ 当前时点

理想状态：EV = PV = AC（按计划、不超支）
典型问题：EV < PV（滞后），EV < AC（超支）
```

## 二、核心公式

### 2.1 偏差分析

| 公式 | 名称 | 含义 | 判读 |
|------|------|------|------|
| CV = EV - AC | 成本偏差 | 赚的vs花的 | >0 节约，<0 超支 |
| SV = EV - PV | 进度偏差 | 赚的vs该赚的 | >0 超前，<0 滞后 |

### 2.2 绩效指数

| 公式 | 名称 | 含义 | 判读 |
|------|------|------|------|
| CPI = EV / AC | 成本绩效指数 | 每花1元赚多少 | >1 节约，<1 超支，=1 正常 |
| SPI = EV / PV | 进度绩效指数 | 实际速度vs计划速度 | >1 超前，<1 滞后，=1 正常 |

### 2.3 预测公式

| 公式 | 名称 | 含义 |
|------|------|------|
| BAC | 完工预算 | 项目总预算（不含管理储备） |
| EAC = BAC / CPI | 完工估算（典型偏差） | 假设当前偏差持续到项目结束 |
| EAC = AC + (BAC - EV) | 完工估算（非典型偏差） | 假设当前偏差是一次性的 |
| EAC = AC + [(BAC - EV) / (CPI × SPI)] | 完工估算（综合考虑） | 同时考虑成本和进度偏差 |
| ETC = EAC - AC | 完工尚需估算 | 还需要花多少钱 |
| VAC = BAC - EAC | 完工偏差 | 预计最终偏差金额 |
| TCPI = (BAC - EV) / (BAC - AC) | 完工尚需绩效指数 | 剩余工作须达到的成本效率 |

### 2.4 公式速记卡

```
核心记忆：
  CV → C(成本) V(偏差) = EV - AC   → 赚的 - 花的
  SV → S(进度) V(偏差) = EV - PV   → 赚的 - 该赚的
  CPI → C(成本) PI(绩效) = EV / AC  → 赚的 / 花的
  SPI → S(进度) PI(绩效) = EV / PV  → 赚的 / 该赚的

关键规律：
  - 所有偏差：EV 在前（"赚的"是基准）
  - 所有指数：EV 在分子（"赚的"是基准）
  - 偏差用减法，指数用除法
  - 偏差看正负，指数看大小
```

## 三、实战计算示例

### 3.1 项目背景

```
某市智慧交通项目：
- 合同价：1200万元
- 工期：12个月
- 当前：第4个月末
- 计划完成：40%（按时间均匀分布）
- 实际完成：35%
- 实际支出：450万元
```

### 3.2 计算过程

```
步骤1：确定PV
  PV = BAC × 计划完成比例 = 1200 × 40% = 480万元

步骤2：确定EV
  EV = BAC × 实际完成比例 = 1200 × 35% = 420万元

步骤3：已知AC
  AC = 450万元

步骤4：计算偏差
  CV = EV - AC = 420 - 450 = -30万元（超支30万）
  SV = EV - PV = 420 - 480 = -60万元（滞后60万的工作量）

步骤5：计算绩效指数
  CPI = EV / AC = 420 / 450 = 0.933（黄色预警区）
  SPI = EV / PV = 420 / 480 = 0.875（接近红色预警）

步骤6：预测完工
  EAC(典型) = BAC / CPI = 1200 / 0.933 = 1286万元
  EAC(非典型) = AC + (BAC - EV) = 450 + (1200 - 420) = 1230万元
  ETC = EAC - AC = 1286 - 450 = 836万元（还需836万）
  VAC = BAC - EAC = 1200 - 1286 = -86万元（预计最终超支86万）

步骤7：TCPI分析
  TCPI = (BAC - EV) / (BAC - AC) = (1200 - 420) / (1200 - 450) = 780 / 750 = 1.04
  → 剩余工作须以1.04的成本效率执行才能不超BAC
```

### 3.3 预警判断

| 指标 | 数值 | 预警级别 | 判断依据 |
|------|------|---------|---------|
| CPI | 0.933 | 🟡 黄色 | 0.9 < CPI < 0.95 |
| SPI | 0.875 | 🔴 红色 | SPI < 0.85 |
| TCPI | 1.04 | 🟢 绿色 | TCPI < 1.1 可实现 |

**综合判断**：进度严重滞后是首要问题，成本虽有超支但可控。建议：赶工加速进度，同时控制成本不进一步恶化。

## 四、EV 测量方法

### 4.1 常用测量方法

| 方法 | 适用场景 | 精度 | 操作 |
|------|---------|------|------|
| 完成百分比法 | 可量化工作包 | 高 | 每周填报完成百分比 |
| 0/100法则 | 短期工作包 | 低 | 未完成=0%，完成=100% |
| 50/50法则 | 中期工作包 | 中 | 开始=50%，完成=100% |
| 加权里程碑 | 里程碑明确的阶段 | 中 | 每个里程碑赋予EV权重 |
| 固定公式法 | 均匀进度的工作包 | 中 | 按时间线性分配EV |

### 4.2 方法选择建议

```
项目阶段建议：
- 需求/设计阶段 → 加权里程碑法（按交付物节点）
- 开发阶段 → 完成百分比法（按功能模块完成度）
- 测试阶段 → 0/100法则（按测试用例通过率）
- 部署阶段 → 加权里程碑法（按部署节点）
```

## 五、EVM 报告模板

### 5.1 月度EVM报告结构

```
1. 基本数据
   - 报告月份：____年__月
   - BAC：____万元
   - 当前PV/EV/AC：____/____/____万元

2. 绩效指标
   - CPI：____（趋势：↑/→/↓）
   - SPI：____（趋势：↑/→/↓）
   - 预警级别：🔴红色/🟡黄色/🟢绿色

3. 偏差分析
   - CV：____万元（超支/节约原因：____）
   - SV：____万元（滞后/超前原因：____）

4. 完工预测
   - EAC：____万元
   - VAC：____万元（预计超支/节约）
   - 预计完工日期：____

5. 纠偏措施
   - 进度纠偏：____
   - 成本纠偏：____
   - 需要升级的事项：____

6. 趋势图（CPI/SPI走势）
```

### 5.2 CPI/SPI 趋势判断

| 趋势模式 | 含义 | 建议 |
|---------|------|------|
| CPI持续下降 | 成本恶化加速 | 紧急纠偏，必要时重新评估项目可行性 |
| CPI先降后升 | 纠偏措施生效 | 继续执行纠偏，密切监控 |
| CPI稳定<0.9 | 成本持续超支 | 评估是否需要缩减范围或追加预算 |
| SPI持续下降 | 进度恶化加速 | 增加资源或调整范围 |
| SPI先降后升 | 赶工见效 | 继续执行赶工计划 |
| SPI稳定<0.85 | 进度持续滞后 | 评估是否需要调整工期或范围 |

## 六、常见误用与纠正

| 误用 | 正确做法 |
|------|---------|
| 用AC代替EV计算进度 | 进度用EV vs PV，成本用EV vs AC |
| CPI<1就立即升级 | CPI 0.9-0.95为黄色，先分析原因再决策 |
| 只看单月数据 | 须看趋势（至少3个月）才能判断方向 |
| EV测量过于乐观 | 工作包"90%完成"往往意味着还有50%未做 |
| 忽略TCPI | TCPI>1.2意味着几乎不可能不超BAC |
| 只看CPI不看SPI | 进度滞后会导致后期赶工，间接增加成本 |
