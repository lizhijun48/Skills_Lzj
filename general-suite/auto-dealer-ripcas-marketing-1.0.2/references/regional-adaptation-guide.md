# 中国汽车经销商区域适配指南

本指南用于把 RIPCAS 营销增长方案适配到中国大陆、香港、澳门不同市场。除非用户明确指定区域，否则输出方案应先确认目标城市/区域；若用户要求快速生成，应显式声明区域假设。

## 1. 区域适配总原则

| 维度 | 中国大陆 | 香港 | 澳门 |
|---|---|---|---|
| 市场结构 | 城市层级差异大，品牌直营、经销商集团、区域门店并存 | 城市密度高，停车/牌照/进口政策影响强，豪华与新能源细分明显 | 市场半径小，熟人推荐、跨境生活、旅游服务与本地圈层影响强 |
| 主流触点 | 抖音、视频号、小红书、懂车帝、汽车之家、企微、社群、本地生活平台 | Facebook、Instagram、YouTube、WhatsApp、Google、本地论坛/媒体、线下商圈 | Facebook、Instagram、WhatsApp、微信/朋友圈、本地媒体、社群与转介绍 |
| 线索运营 | CRM/企微私域、直播线索、平台询价、到店邀约 | 表单、WhatsApp 咨询、电话预约、门店试驾 | WhatsApp/微信咨询、熟人转介、门店预约 |
| 成交关键 | 价格政策、金融置换、交付周期、竞品对比、售后网络 | 牌照、停车、保险、进口/保养成本、试驾便利 | 停车、跨境使用、售后便利、熟人信任、家庭决策 |
| 内容风格 | 明确权益、场景化测评、对比导购、直播转化 | 简洁可信、成本透明、生活方式与身份表达 | 熟人信任、本地场景、家庭/商务接待、真实车主证言 |
| 合规提示 | 遵守广告法、个人信息保护、金融宣传与平台规则 | 注意本地广告、隐私、消费者保障及金融宣传要求 | 注意本地广告、隐私、消费者保障及金融宣传要求 |

## 2. 区域参数卡

执行技能前优先补齐以下参数：

```text
目标区域：大陆/香港/澳门/跨区域
城市或商圈：
品牌与车型：
价格带：
销售模式：经销商/代理/直营/集团多店
可用渠道：
客户沟通工具：企微/微信/WhatsApp/电话/平台私信/其他
主要增长问题：线索少/到店低/试驾低/成交低/复购转介绍弱/流程混乱
预算与周期：
合规限制：广告、隐私、金融、平台规则等
```

## 3. 按区域调整 RIPCAS

### R - Reach 触达

- 大陆：优先组合公域平台、本地生活、直播/短视频、线索平台与企微私域。
- 香港：优先组合社媒、搜索、本地媒体、WhatsApp 咨询入口与高密度商圈触点。
- 澳门：优先组合本地社群、熟人推荐、线下门店、WhatsApp/微信与车主转介绍。

### I - Interest 兴趣

- 大陆：强调车型卖点、价格权益、金融置换、竞品对比与直播互动。
- 香港：强调用车成本、停车便利、保养透明、品牌质感与生活方式。
- 澳门：强调短半径通勤、家庭/商务接待、跨境场景、售后便利与真实口碑。

### P - Preference 偏好

- 大陆：用权益包、限时政策、车型对比、置换补贴增强偏好。
- 香港：用总拥有成本、保险/保养、车位与牌照相关解释降低顾虑。
- 澳门：用熟人车主案例、门店服务承诺、家庭决策材料增强信任。

### C - Conversion 转化

- 大陆：建立平台线索到企微/CRM、邀约、试驾、报价、订金的闭环。
- 香港：缩短咨询到试驾路径，强化预约确认、到店便利与报价透明。
- 澳门：强化顾问个人信任、熟人背书、门店接待与家庭共同决策跟进。

### A - Advocacy 口碑

- 大陆：车主社群、交车短视频、转介绍权益、售后活动。
- 香港：高质量车主故事、生活方式内容、WhatsApp 车主群与线下聚会。
- 澳门：熟人圈层转介绍、家庭/企业客户案例、本地车主口碑活动。

### S - System 系统

- 大陆：渠道成本、线索质量、企微跟进、试驾和成交数据必须日/周复盘。
- 香港/澳门：样本量可能较小，应看重单客质量、跟进及时性、转介绍链路和服务口碑。

## 4. 输出要求

任何涉及执行方案的输出，都应至少包含：

1. 区域假设或已确认区域。
2. 适配后的渠道组合。
3. 区域化客户痛点与内容角度。
4. 合规与隐私边界提醒。
5. 与用户问题对应的最小可执行动作，而不是默认输出全套流程。
