# RIPCAS 汽车经销商营销增长框架

RIPCAS 是本技能用于汽车经销商增长诊断与方案设计的六段式框架：Reach 触达、Interest 兴趣、Preference 偏好、Conversion 转化、Advocacy 口碑、System 系统。

## 1. Reach 触达

目标是让正确客群在正确渠道看到经销商、车型与活动信息。

常见动作：

- 本地生活平台、短视频、朋友圈、社群、商圈广告与异业合作。
- 围绕车型、价格带、家庭场景、通勤场景、置换需求制定人群包。
- 将内容分为品牌背书、车型卖点、活动权益、门店服务四类。

关键指标：曝光量、点击率、咨询量、线索成本、渠道线索占比。

## 2. Interest 兴趣

目标是让潜客形成进一步了解车型、价格、金融和到店试驾的兴趣。

常见动作：

- 场景化短视频、车型亮点图文、真实车主故事。
- 针对家庭、商务、年轻首购、置换增购等分层表达卖点。
- 用限时试驾、到店礼、金融测算吸引留下联系方式。

关键指标：咨询率、留资率、内容互动率、车型页访问深度。

## 3. Preference 偏好

目标是让潜客在品牌、门店、价格与服务上产生偏好。

常见动作：

- 竞品对比、金融方案、置换补贴、售后承诺、库存优势。
- 通过销售顾问一对一跟进，澄清预算、用途、决策人和购车周期。
- 对高意向客户提供个性化试驾与报价方案。

关键指标：有效线索率、邀约成功率、试驾预约率、报价率。

## 4. Conversion 转化

目标是提升到店、试驾、报价、订金和成交效率。

常见动作：

- 设置线索首响、二次触达、邀约、到店接待、试驾、报价、逼单 SOP。
- 对活动期客户设置权益截止时间和备选车型方案。
- 每日复盘未到店、未试驾、未成交客户的阻碍原因。

关键指标：到店率、试驾率、成交率、单车毛利、销售周期。

## 5. Advocacy 口碑

目标是让成交客户带来内容、评价、复购与转介绍。

常见动作：

- 交车仪式、车主采访、用车社群、售后关怀、转介绍激励。
- 邀请车主参与周末试驾、露营、自驾游和车友会活动。
- 将真实口碑素材反哺触达和兴趣阶段内容。

关键指标：转介绍线索数、车主内容数、好评率、复购/增购线索。

## 6. System 系统

目标是形成数据驱动、跨部门协同和持续复盘的增长系统。

常见动作：

- 建立渠道、线索、销售跟进、成交与复盘看板。
- 明确市场部、销售部、客服、售后之间的责任边界。
- 每周复盘渠道 ROI、漏斗转化、销售执行与客户反馈。

关键指标：渠道 ROI、线索跟进及时率、SOP 执行率、复盘闭环率。

## 使用原则

1. 先诊断瓶颈，再设计动作，避免只堆活动创意。
2. 每个建议必须绑定目标客群、渠道、话术、责任人、时间与指标。
3. 不承诺销量结果，不提供虚假优惠、夸大宣传或违规金融承诺。
4. 当用户数据不足时，先给出可执行假设，并标明需要补充的数据。
