# 中国汽车经销商区域市场示例案例

> 本文件提供四类可直接套用的市场案例：大陆一线城市、大陆下沉城市、香港、澳门。案例均为虚构示例，仅用于说明 RIPCAS 问题导向流程和区域适配方式；涉及价格、金融、补贴、保险、牌费、置换政策等内容时，必须以当地法规、平台规则、品牌/门店正式政策及合同文本为准。

## 案例 1：大陆一线城市｜上海豪华新能源门店到店率低

### 1. 业务背景

- 市场区域：中国大陆
- 城市类型：一线城市，新能源竞争激烈，用户信息透明度高
- 门店类型：豪华新能源品牌直营/授权门店
- 主推车型：30–45 万元纯电 SUV
- 当前情况：月均线索 1,200 条，线索量不低，但到店率从 18% 降至 10%，试驾后成交率约 17%
- 主要渠道：抖音、小红书、汽车垂媒、微信私域、商场展厅

### 2. 用户提出的问题

> “我们上海门店线索不少，但到店率持续下降，客户加微信后就去比价或消失。请帮我判断主要问题，并给 7 天行动方案。”

### 3. 区域适配判断

- 上海用户信息获取渠道多，价格、权益、交付周期、补能体验和智能化配置对比充分。
- 一线城市客户更依赖内容搜索和口碑验证，单纯销售邀约容易被视为打扰。
- 到店理由需要从“来看车”升级为“带着明确收益来体验”，例如城市通勤补能测算、家庭使用场景体验、置换残值评估。

### 4. 触发的问题导向流程

- 问题类型：线索到店率低
- 推荐流程：`问题导向模式 → 线索漏斗诊断 → 客户分层 → 到店理由设计 → 7 天行动计划`
- 可引用模板：
  - `templates/problem-routing-template.md`
  - `templates/customer-interview-template.md`
  - `templates/sales-follow-up-sop-template.md`
  - `templates/content-calendar-template.md`

### 5. RIPCAS 诊断摘要

| 模块 | 诊断 |
| --- | --- |
| R 现状 | 线索量充足，但渠道线索质量和销售跟进节奏不稳定，到店承诺价值弱。 |
| I 洞察 | 客户不是没有兴趣，而是在多品牌比较中缺少“必须到店”的差异化理由。 |
| P 优先级 | 优先解决高意向线索识别、48 小时跟进节奏、到店体验钩子。 |
| C 转化 | 设计“智能化体验 + 补能成本测算 + 置换评估”的组合邀约。 |
| A 行动 | 重构邀约话术、内容种草、私域跟进、试驾预约权益。 |
| S 指标 | 7 天看有效邀约率、预约到店率；30 天看到店率、试驾率和线索成本。 |

### 6. 7 天行动计划

| 天数 | 行动 | 负责人 | 输出 |
| --- | --- | --- | --- |
| D1 | 按预算、购车周期、置换情况、家庭/通勤场景重分线索 | 销售经理 | A/B/C 线索池 |
| D2 | 为 A 类线索设计 3 套到店钩子：智能泊车体验、补能成本测算、置换残值评估 | 市场+销售 | 邀约权益清单 |
| D3 | 更新微信跟进 SOP，首触达不报价轰炸，先确认核心场景 | 销售主管 | 新话术与质检表 |
| D4 | 发布 3 条本地化内容：通勤补能、家庭露营、上海停车/充电场景 | 市场 | 内容排期 |
| D5 | 对 72 小时内未到店高意向线索进行二次邀约 | 销售顾问 | 二次邀约记录 |
| D6 | 设置周末“城市智能驾驶体验专场” | 门店经理 | 活动 Brief |
| D7 | 复盘渠道来源、话术版本、预约到店转化 | 市场+销售 | 复盘表 |

### 7. 30 天指标

- 高意向线索识别率：≥ 35%
- 有效邀约率：提升 20%
- 预约到店率：从 10% 提升至 13%–15% 区间作为阶段目标
- 到店后试驾率：≥ 60%
- 单渠道有效到店成本：下降 10%–15%

### 8. 注意事项

- 不承诺“最低价”“保证补贴”“必然成交”。
- 金融、置换、补贴、保险等信息必须以正式政策为准。
- 客户跟进记录需脱敏，不应上传姓名、手机号、微信号、车牌号、VIN 等个人信息。

## 案例 2：大陆下沉城市｜地级市新能源 SUV 线索少、活动无效

### 1. 业务背景

- 市场区域：中国大陆
- 城市类型：三四线/地级市，熟人推荐和线下口碑影响大
- 门店类型：综合汽车经销商，兼营燃油车和新能源车型
- 主推车型：15–22 万元新能源 SUV
- 当前情况：月均线索 220 条，到店率 25%，但线索总量不足；周末活动多为静态展示，留资少
- 主要渠道：微信朋友圈、短视频同城号、本地生活号、老客户介绍、商超外展

### 2. 用户提出的问题

> “我们在地级市做新能源 SUV，线上线索少，活动也不热闹。预算有限，怎么把本地客户拉起来？”

### 3. 区域适配判断

- 下沉市场客户更重视熟人背书、售后便利、真实用车成本和保值顾虑。
- 预算有限时，不宜先铺大投放，应先做“本地口碑 + 老客推荐 + 场景试驾”。
- 活动要从“看车展”改成“解决家庭用车、置换、用电成本、售后保障”的本地化体验。

### 4. 触发的问题导向流程

- 问题类型：线索量不足 + 活动效果差
- 推荐流程：`问题导向模式 → 区域获客诊断 → 本地客户分层 → 战役选择 → 内容/活动排期`
- 可引用模板：
  - `templates/campaign-brief-template.md`
  - `templates/referral-program-template.md`
  - `templates/trade-in-template.md`
  - `templates/content-calendar-template.md`

### 5. RIPCAS 诊断摘要

| 模块 | 诊断 |
| --- | --- |
| R 现状 | 预算有限、线上内容弱、活动缺少明确客户收益。 |
| I 洞察 | 下沉市场不缺潜在客户，缺可信任的本地样板和熟人传播机制。 |
| P 优先级 | 优先建立老车主推荐、置换评估、家庭场景试驾三件事。 |
| C 转化 | 用“老客带新 + 真实用车成本 + 本地售后承诺”降低新能源顾虑。 |
| A 行动 | 设计低成本社区/商超外展和短视频同城内容。 |
| S 指标 | 看新增留资、老客推荐量、试驾预约、活动到店成交。 |

### 6. 7 天行动计划

| 天数 | 行动 | 负责人 | 输出 |
| --- | --- | --- | --- |
| D1 | 盘点近 12 个月成交老客户，筛选 30 位愿意推荐/出镜车主 | 销售经理 | 老客推荐池 |
| D2 | 设计“家庭 SUV 用车成本测算”表，比较油费、电费、保养、保险 | 市场 | 成本测算模板 |
| D3 | 拍摄 5 条本地车主真实用车短视频 | 市场+销售 | 同城内容素材 |
| D4 | 设置商超/社区外展，主题为“周末家庭试乘试驾 + 置换评估” | 门店经理 | 活动 Brief |
| D5 | 启动老客推荐权益，明确推荐、到店、成交三个节点权益 | 销售主管 | 推荐规则 |
| D6 | 对旧车置换客户进行电话/微信邀约，强调免费评估和用车成本 | 销售顾问 | 邀约清单 |
| D7 | 复盘活动来源、留资质量、试驾预约和推荐转化 | 市场+销售 | 复盘报告 |

### 7. 30 天指标

- 新增本地有效线索：提升 25%–35%
- 老客户推荐线索占比：达到 15% 以上
- 外展活动留资成本：下降 10% 以上
- 试驾预约数：提升 20%
- 新能源异议处理完成率：≥ 80%

### 8. 注意事项

- 所有推荐权益需公开、清晰、可兑现，不得设置误导性门槛。
- 置换估值不得虚高诱导，应以实际车况和评估流程为准。
- 老客户素材使用前需获得授权。

## 案例 3：香港市场｜高持有成本下的汽车零售增长诊断

### 1. 业务背景

- 市场区域：香港
- 城市特点：车辆持有成本高，停车、牌费、保险、道路使用和售后预约是核心顾虑
- 门店类型：进口/豪华品牌经销商
- 主推车型：豪华插混/纯电车型
- 当前情况：线上咨询较多，但客户反复询问总拥有成本，试驾预约率低
- 主要渠道：WhatsApp、Instagram、Facebook、Google 搜索、官网表单、车主社群

### 2. 用户提出的问题

> “香港客户咨询很多，但一直问停车、牌费、保险和售后，试驾预约率低。如何设计更适合香港市场的转化方案？”

### 3. 区域适配判断

- 香港客户关注的不只是车价，而是总拥有成本与日常使用便利性。
- 沟通需要支持繁体中文/英文，跟进工具以 WhatsApp 为主。
- 到店/试驾通常需要更强预约制和效率感，避免冗长流程。

### 4. 触发的问题导向流程

- 问题类型：咨询多但试驾预约低
- 推荐流程：`问题导向模式 → 异议归因 → TCO 信息包 → WhatsApp 跟进 SOP → 预约制试驾`
- 可引用模板：
  - `templates/ev-objection-handling-template.md`
  - `templates/sales-follow-up-sop-template.md`
  - `templates/customer-interview-template.md`

### 5. RIPCAS 诊断摘要

| 模块 | 诊断 |
| --- | --- |
| R 现状 | 咨询量高但客户关键顾虑未被结构化回应。 |
| I 洞察 | 香港客户需要先确认总拥有成本和使用便利，才愿意进入试驾。 |
| P 优先级 | 优先制作 TCO 说明、预约制试驾流程、WhatsApp 跟进话术。 |
| C 转化 | 用“成本透明 + 时间效率 + 售后确定性”推动预约。 |
| A 行动 | 建立繁中/英文信息包、快速 FAQ、预约提醒机制。 |
| S 指标 | 看 WhatsApp 回复率、试驾预约率、爽约率、预约到店率。 |

### 6. 7 天行动计划

| 天数 | 行动 | 负责人 | 输出 |
| --- | --- | --- | --- |
| D1 | 汇总客户高频问题：停车、牌费、保险、充电、售后预约 | 销售主管 | FAQ 清单 |
| D2 | 制作繁体中文/英文 TCO 信息包 | 市场 | TCO PDF/图文 |
| D3 | 重写 WhatsApp 首轮回复，先回答成本和使用便利，再邀约 | 销售经理 | 话术模板 |
| D4 | 设置 30 分钟预约制试驾流程，减少等待和冗余讲解 | 门店经理 | 试驾流程表 |
| D5 | Instagram/Facebook 发布“香港日常用车成本解释”内容 | 市场 | 内容排期 |
| D6 | 对已咨询未预约客户发送个性化 TCO 摘要和可选时段 | 销售顾问 | 二次触达清单 |
| D7 | 复盘咨询来源、回复速度、预约率、爽约率 | 市场+销售 | 复盘表 |

### 7. 30 天指标

- WhatsApp 首响时间：≤ 10 分钟
- 试驾预约率：提升 15%–25%
- 预约爽约率：下降 10%
- TCO 信息包发送后回复率：≥ 35%
- 试驾后跟进完成率：≥ 90%

### 8. 注意事项

- 涉及牌费、保险、税费、金融方案时，需以香港当地法规、机构报价和正式文件为准。
- 英文/繁体中文内容需保持一致，不得出现优惠条件差异或误导。
- WhatsApp 跟进需尊重客户授权和退订意愿。

## 案例 4：澳门市场｜熟人推荐与企业客户驱动的增长诊断

### 1. 业务背景

- 市场区域：澳门
- 城市特点：城市半径小、客户圈层紧密，熟人推荐、本地服务口碑和企业客户影响显著
- 门店类型：多品牌经销商/区域门店
- 主推车型：商务 MPV、新能源 SUV、企业用车
- 当前情况：自然客流稳定但增长乏力，老客户转介绍缺少机制，企业客户线索分散
- 主要渠道：车主社群、朋友圈/视频号、老客户推荐、企业拜访、本地线下活动

### 2. 用户提出的问题

> “澳门门店老客户很多，但转介绍做不起来，企业客户也没有系统跟进。请帮我设计一个轻量增长方案。”

### 3. 区域适配判断

- 澳门市场信任链条短，老客户口碑对成交影响大。
- 酒店、旅游、餐饮、会展、跨境业务相关企业可作为重点场景。
- 大湾区跨境用车、售后便利和本地响应速度是可被强化的价值点。

### 4. 触发的问题导向流程

- 问题类型：老客户转介绍少 + 企业客户跟进弱
- 推荐流程：`问题导向模式 → 客户资产盘点 → 推荐机制设计 → 企业客户分层 → 30 天跟进行动`
- 可引用模板：
  - `templates/referral-program-template.md`
  - `templates/enterprise-client-template.md`
  - `templates/sales-follow-up-sop-template.md`

### 5. RIPCAS 诊断摘要

| 模块 | 诊断 |
| --- | --- |
| R 现状 | 有客户资产但缺少系统化激活；企业线索没有分层和节奏。 |
| I 洞察 | 澳门客户更看重可信推荐和本地服务确定性，企业客户更关注效率和总成本。 |
| P 优先级 | 优先建立老客户推荐节点和企业客户名单分层。 |
| C 转化 | 用“老客背书 + 本地服务 + 企业用车成本方案”提升信任。 |
| A 行动 | 设置推荐官计划、企业客户拜访包、跨境用车说明。 |
| S 指标 | 看推荐线索数、企业拜访数、试驾预约、成交周期。 |

### 6. 7 天行动计划

| 天数 | 行动 | 负责人 | 输出 |
| --- | --- | --- | --- |
| D1 | 盘点近 24 个月老客户，按满意度、车型、行业、人脉资源分层 | 销售经理 | 老客资产表 |
| D2 | 设计“老车主推荐官计划”，明确推荐、到店、成交节点权益 | 市场+销售 | 推荐机制 |
| D3 | 梳理 50 家潜在企业客户，按酒店旅游、餐饮会展、跨境业务分类 | 大客户经理 | 企业客户池 |
| D4 | 准备企业用车方案：成本、维保、交付、跨境使用、售后响应 | 门店经理 | 企业方案包 |
| D5 | 邀请 10 位老客户参与小型试驾/交流会 | 市场 | 活动名单 |
| D6 | 对 A 类企业客户进行预约拜访 | 大客户经理 | 拜访记录 |
| D7 | 复盘推荐线索、企业反馈、试驾预约和下周跟进计划 | 销售主管 | 复盘表 |

### 7. 30 天指标

- 老客户推荐线索：≥ 30 条
- 推荐线索到店率：≥ 35%
- 企业客户有效拜访：≥ 20 家
- 企业客户试驾/方案沟通：≥ 8 家
- 推荐成交贡献占比：阶段性提升至 10%–15%

### 8. 注意事项

- 推荐权益需要真实、明确，不得诱导虚假推荐或刷单。
- 企业客户报价和服务承诺必须经门店授权确认。
- 跨境用车、保险、牌照、通关等问题需以官方政策和专业机构意见为准。
