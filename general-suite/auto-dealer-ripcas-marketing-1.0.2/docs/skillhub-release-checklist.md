# SkillHub 发布前检查清单

## 1. 元数据

- [x] `SKILL.md` 包含 YAML front matter。
- [x] `name` 使用小写短横线命名。
- [x] `display_name` 清晰表达技能用途。
- [x] `description` 能说明适用对象、核心能力和边界。
- [x] `version` 使用语义化版本号。
- [x] `tags` 覆盖行业、职能和任务类型。

## 2. 内容结构

- [x] 主技能说明包含触发场景、输入信息、工作流、输出格式、质量标准。
- [x] `references/` 提供方法论、客群、漏斗、战役、销售 SOP 等支撑资料。
- [x] `templates/` 提供可复用交付模板。
- [x] `examples/` 提供典型输出样例。
- [x] `README.md` 说明安装、验证、使用方式。
- [x] `docs/skillhub-store-listing.md` 提供技能商店展示文案。
- [x] `docs/input-data-schema.md` 提供真实业务落地所需输入字段规范。

## 3. 可执行性

- [x] 用户信息不足时有补充问题与默认假设策略。
- [x] 输出必须绑定目标、客群、渠道、责任人、时间节奏、指标。
- [x] 支持营销诊断、月度计划、战役 Brief、内容排期、销售话术和复盘建议。
- [x] 提供最小可用输入与结构化 YAML 输入样例，便于真实团队复用。

## 4. 合规与风险

- [x] 不承诺销量、成交率、金融收益或补贴结果。
- [x] 不生成虚假优惠、虚假口碑或误导性宣传。
- [x] 涉及价格、库存、补贴、金融政策时要求以门店正式政策为准。
- [x] 不处理敏感个人信息明细，使用汇总数据即可。

## 5. 发布验证

- [x] 可通过 `docs/validation-report.md` 的测试用例进行安装后验证。
- [x] 可通过 `CHANGELOG.md` 追踪版本变化。
- [x] 可通过 `docs/rollback.md` 查看回退与停用方式。
