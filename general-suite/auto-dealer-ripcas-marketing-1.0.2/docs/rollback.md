# 回退与停用说明

## 1. 回退场景

- 安装后无法触发或触发错误。
- 输出不符合汽车经销商营销场景。
- 版本升级后出现内容缺失、格式错误或合规风险。

## 2. 回退方式

1. 停用当前版本技能。
2. 恢复上一版本 `auto-dealer-ripcas-marketing` 技能目录。
3. 执行安装验证提示词，确认输出恢复正常。
4. 在 `CHANGELOG.md` 或团队发布记录中登记回退原因。

## 3. 停用方式

如暂不使用，可从 SkillHub 管理端停用该技能，或从用户技能目录中移除该技能目录。

## 4. 风险提示

停用本技能不会影响用户原始业务数据；但依赖本技能生成的模板、话术和计划需要自行保存归档。
