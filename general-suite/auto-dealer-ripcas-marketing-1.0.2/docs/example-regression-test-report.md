# 示例输入输出回归测试报告

## 1. 测试结论

本轮对汽车经销商 RIPCAS 中国市场营销增长技能进行了 5 组回归测试：

1. 大陆一线城市：上海豪华新能源门店，到店率下降。
2. 大陆下沉城市：地级市新能源 SUV 门店，线索少、活动弱、预算有限。
3. 香港市场：咨询多但试驾预约低，客户关注停车、牌费、保险、售后。
4. 澳门市场：老客户多但转介绍弱，企业客户线索分散。
5. 触发词与边界：营销增长相关问题应触发，合同/股票等非技能范围问题不应触发。

综合结论：**回归测试通过。**

技能能够基于用户提出的具体问题进入问题导向模式，并稳定产出区域适配判断、RIPCAS 诊断摘要、7 天行动计划、30 天指标和合规/隐私提醒。

## 4. TC-01 大陆一线城市回归测试

### 输入

> 上海豪华新能源门店，月线索 1200，到店率从 18% 降至 10%，客户加微信后比价或消失；希望诊断并给 7 天行动方案。

### 预期能力

- 识别为中国大陆一线城市市场。
- 不跑完整冗长流程，优先进入“线索到店率低”的问题导向流程。
- 输出区域适配判断、RIPCAS 诊断、7 天行动计划、30 天指标。
- 提醒价格、金融、补贴、个人信息使用等合规事项。

### 模拟输出摘要

- 区域适配：上海用户信息透明，竞争强，需用内容搜索、智能化体验、补能成本和置换评估制造到店理由。
- 问题导向流程：线索漏斗诊断 → 客户分层 → 到店理由设计 → 销售跟进 SOP → 7 天行动。
- RIPCAS 主矛盾：线索不是主要瓶颈，核心瓶颈在高意向线索识别和到店价值不足。
- 7 天行动：重分线索、设置到店钩子、更新微信话术、发布本地化内容、二次邀约、周末体验专场、复盘渠道转化。
- 30 天指标：到店率、试驾率、有效邀约率、单渠道有效到店成本。

### 结果

通过。

## 5. TC-02 大陆下沉城市回归测试

### 输入

> 地级市经销商做 15–22 万新能源 SUV，线上线索少，活动留资差，预算有限；希望找到低成本获客方案。

### 预期能力

- 识别为中国大陆下沉城市市场。
- 优先推荐低成本、本地化、熟人信任驱动的获客路径。
- 输出老客推荐、置换评估、同城短视频、社区/商超外展等动作。

### 模拟输出摘要

- 区域适配：下沉市场重视熟人背书、真实用车成本、售后便利和保值顾虑。
- 问题导向流程：区域获客诊断 → 本地客户分层 → 战役选择 → 内容/活动排期。
- RIPCAS 主矛盾：不是简单投放不足，而是本地可信样板和活动转化钩子不足。
- 7 天行动：盘点老客户、制作用车成本测算、拍摄本地车主内容、商超/社区外展、启动推荐权益、邀约置换客户、复盘。
- 30 天指标：新增有效线索、老客推荐线索占比、外展留资成本、试驾预约数。

### 结果

通过。

## 6. TC-03 香港市场回归测试

### 输入

> 香港进口/豪华品牌经销商，咨询多但客户反复问停车、牌费、保险和售后，试驾预约低；渠道包括 WhatsApp、Instagram、Facebook。

### 预期能力

- 识别为香港市场。
- 关注停车、牌费、保险、售后预约、繁体中文/英文沟通。
- 输出 WhatsApp 跟进 SOP、TCO 信息包、预约制试驾方案。

### 模拟输出摘要

- 区域适配：香港客户核心顾虑是总拥有成本和日常使用便利，而非单一车价。
- 问题导向流程：异议归因 → TCO 信息包 → WhatsApp 跟进 SOP → 预约制试驾。
- RIPCAS 主矛盾：咨询转试驾低的原因是成本与便利性问题没有被结构化回应。
- 7 天行动：汇总 FAQ、制作繁中/英文 TCO 信息包、重写 WhatsApp 话术、设置 30 分钟预约试驾、发布社媒内容、二次触达、复盘。
- 30 天指标：WhatsApp 首响时间、试驾预约率、爽约率、TCO 信息包发送后回复率。

### 结果

通过。

## 7. TC-04 澳门市场回归测试

### 输入

> 澳门多品牌经销商，老客户多但转介绍弱，企业客户线索分散，关注酒店旅游企业、大湾区跨境用车、本地服务口碑。

### 预期能力

- 识别为澳门市场。
- 保留澳门熟人关系、企业客户、旅游酒店、大湾区跨境用车等差异。
- 输出推荐机制和企业客户分层方案。

### 模拟输出摘要

- 区域适配：澳门市场信任链条短，老客户口碑、本地服务确定性和企业客户关系影响大。
- 问题导向流程：客户资产盘点 → 推荐机制设计 → 企业客户分层 → 30 天跟进行动。
- RIPCAS 主矛盾：客户资产存在但没有系统激活，企业客户没有分层和节奏。
- 7 天行动：老客户分层、推荐官计划、企业客户池、企业用车方案、小型交流会、企业拜访、复盘。
- 30 天指标：推荐线索、推荐线索到店率、企业拜访数、方案沟通数、推荐成交贡献占比。

### 结果

通过。
