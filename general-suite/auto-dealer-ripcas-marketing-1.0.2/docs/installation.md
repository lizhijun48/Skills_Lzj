# 安装与启用说明

## 1. 安装位置

将 `auto-dealer-ripcas-marketing` 目录作为完整技能包导入 SkillHub 或放入用户技能目录。

## 2. 启用后验证

安装后可使用以下提示词测试：

> 帮我为本地城市/区域一家汽车经销商制定下月营销计划，主推家庭 SUV，目标提升到店和试驾转化。

预期表现：

- 技能能识别汽车经销商营销增长任务。
- 输出应使用 RIPCAS 框架。
- 输出包含目标、客群、渠道、战役、销售承接、指标与风险提醒。

## 3. 依赖说明

本技能为纯文本方法论技能，无外部 API、脚本或第三方依赖。

## 4. 升级方式

替换整个技能目录，并保留旧版本归档；升级后执行 `docs/validation-report.md` 中的验证用例。
