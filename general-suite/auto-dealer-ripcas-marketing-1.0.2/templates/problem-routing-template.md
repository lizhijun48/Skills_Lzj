# 问题导向流程路由模板

> 用途：当用户不想完整跑一遍 RIPCAS 全流程时，先明确当前要解决的问题，再选择最短闭环流程。

## 1. 用户问题输入

请用户用 1-3 句话描述当前最想解决的问题：

- 当前城市/区域：中国大陆（城市：____）/ 香港 / 澳门 / 多区域
- 当前车型/品牌：____
- 目标客群：____
- 当前卡点：____
- 希望产出：诊断 / 活动方案 / 话术 / 内容排期 / 销售 SOP / 数据看板 / 复盘建议

## 2. 问题分类

| 用户问题类型 | 识别信号 | 推荐流程 | 可跳过内容 |
| --- | --- | --- | --- |
| 不知道问题在哪 | 只说销量差、线索少、转化低 | 轻量诊断流程 | 暂不生成完整战役 |
| 缺线索 | 到店少、咨询少、广告没效果 | Lead Generation 增量线索流程 | 可跳过销售 SOP 细化 |
| 转化差 | 线索有但试驾/成交低 | Conversion 转化提升流程 | 可跳过内容月历 |
| 想做活动 | 节点促销、新车上市、团购 | Campaign 快速战役流程 | 可跳过完整经营诊断 |
| 销售不会跟 | 跟进断层、异议多、话术弱 | Sales Enablement 销售赋能流程 | 可跳过投放策略 |
| 老客不活跃 | 转介绍少、复购少、售后沉默 | Advocacy 老客裂变流程 | 可跳过获客广告 |
| 区域不适配 | 大陆/香港/澳门渠道、法规、语言不同 | Regional Adaptation 区域适配流程 | 可跳过全国通用假设 |

## 3. 区域适配校准

在输出方案前，必须先确认：

- 大陆：是否涉及懂车帝、汽车之家、抖音、小红书、微信私域、本地生活平台、车展/商超外展？
- 香港：是否涉及繁体中文/英文表达、右舵车、牌费/停车成本、WhatsApp/Instagram/Facebook/小红书等触点？
- 澳门：是否涉及本地社群、跨境用车、停车/充电半径、葡语/繁中物料、转介绍关系链？
- 多区域：是否需要输出“全国框架 + 城市差异化执行清单”？
