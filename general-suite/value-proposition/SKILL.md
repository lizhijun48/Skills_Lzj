# 价值主张 (Value Proposition)

价值主张回答的核心问题："用户为什么选你？你能给用户带来什么不可替代的价值？"

## 核心原则

- **用户视角**：价值主张不是"我觉得产品好在哪里"，而是"用户觉得产品对他有什么用"。
- **战略层级意识**：不同层级的价值主张服务于不同决策者——企业级面向投资人/合作方，产品线级面向渠道/采购，单品级面向终端用户。
- **功能+情感双轮**：好的价值主张同时满足功能需求和情感需求，缺一不可。
- **可信度是底线**：每个价值承诺都必须有可验证的证据支撑。

## 一、战略层级内部分层

| 战略层级 | 价值主张对象 | 核心问题 | 输出用途 |
|---------|------------|---------|---------|
| **企业级** | 投资者、合作伙伴 | "投资/合作这家企业能获得什么回报？" | 融资、战略合作、政府关系 |
| **产品线级** | 渠道商、B端客户 | "这条产品线能帮我的业务解决什么问题？" | 渠道拓展、B端销售 |
| **单品级** | 终端用户 | "这个产品能帮我解决什么具体问题？" | 产品页面、广告、包装 |

## 二、四大关键考量

### 2.1 核心优势识别

```
诊断问题：
1. 产品最突出的3个能力是什么？
2. 这3个能力中，哪个是竞品短期内无法复制的？
3. 这个能力的技术壁垒/资源壁垒是什么？
4. 用户最容易感知到的优势是哪个？
```

### 2.2 痛点解决映射

```
诊断问题：
1. 目标用户当前面临的前3个痛点是什么？
2. 产品分别如何解决这些痛点？
3. 解决前后的对比有多强烈？（能量化吗？）
4. 有没有用户自己都没意识到的痛点？
```

### 2.3 情感-功能平衡

```
诊断问题：
1. 产品的功能价值是什么？（解决什么问题/省什么/提升什么）
2. 产品的情感价值是什么？（让用户感觉如何）
3. 功能价值和情感价值之间是否有因果联系？
4. 如果只能保留一个，用户更在意哪个？
```

**平衡原则**：功能价值是"入场券"（必须有），情感价值是"加分项"（让用户选你）。在价格敏感的市场，功能价值权重更高；在同质化市场，情感价值是差异化的关键。

### 2.4 可信度建设

```
诊断问题：
1. 每个价值主张有什么证据支撑？（数据/认证/案例）
2. 有没有第三方背书？（权威机构/媒体/KOL）
3. 有没有用户可感知的验证方式？（免费试用/效果对比）
4. 承诺是否可兑现？（过度承诺=信任崩塌）
```

## 三、完整模板（10组件）

```
价值主张画布：

1. 目标用户：[具体用户画像]
2. 用户任务：[用户试图完成什么任务]
3. 用户痛点：[当前遇到的3个核心痛点]
4. 用户期望收益：[用户期望获得什么]
5. 产品/服务：[你的产品是什么]
6. 痛点解决方案：[产品如何解决每个痛点]
7. 收益创造者：[产品如何创造期望收益]
8. 功能价值：[具体的、可量化的功能收益]
9. 情感价值：[用户使用时的感受]
10. 可信度证据：[数据/认证/案例/背书]
```

**示例**（智能门锁）：
> 1. 目标用户：25-40岁城市家庭用户
> 2. 用户任务：安全便捷地管理家庭出入
> 3. 用户痛点：①忘带钥匙被锁门外 ②保姆/快递临时进门不方便 ③担心老人小孩安全
> 4. 期望收益：不用带钥匙、远程控制、安全记录
> 5. 产品：XX智能门锁
> 6. 痛点解决：①指纹/人脸开锁→永远忘带钥匙 ②远程临时密码→保姆快递自由进出 ③开门记录推送→随时知道谁回家了
> 7. 收益创造：从"带钥匙"到"刷脸回家"的体验升级
> 8. 功能价值：开锁速度<0.5秒，续航12个月，C级锁芯
> 9. 情感价值：每次回家都轻松自在，出差时也安心
> 10. 可信度：3项国家专利、10万+用户、公安部C级认证

## 四、常见陷阱

| 陷阱 | 症状 | 应对 |
|------|------|------|
| 功能堆砌 | 列了20个功能但没说清核心价值 | 强制聚焦：最重要的1-3个价值点 |
| 自说自话 | 价值主张用户听不懂（技术术语） | 用"奶奶测试"：奶奶能听懂吗？ |
| 情感缺失 | 只说功能不说感受 → 冷冰冰 | 加入"使用场景+情感描述" |
| 过度承诺 | "最好""第一""革命性" → 无证据 | 每个形容词都要有数据支撑 |

## 五、评估标准

| 维度 | 评估问题 | 达标标准 |
|------|---------|---------|
| 用户共鸣 | 目标用户看完会说"这说的就是我"吗？ | 80%以上用户认同 |
| 差异化 | 换成竞品的产品名还成立吗？ | 不成立=通过 |
| 可验证 | 每个承诺都能找到证据吗？ | 100%有支撑 |
| 简洁度 | 能否在30秒内说清？ | 电梯演讲测试通过 |
| 情感连接 | 用户看完有感觉吗？什么感觉？ | 至少有1个情感触发点 |

## 调用关系

- **被调用**：`copywriting`（文案撰写获取价值输入）、`marketing-planning`（营销策划获取核心卖点）、`future-vision`（未来愿景基于价值主张延伸）、`channel-content-strategy`（渠道内容策略获取战略输入）
- **调用**：`brand-positioning`（价值主张需要品牌定位作为输入）
