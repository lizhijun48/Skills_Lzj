# 品牌定位 (Brand Positioning)

品牌定位回答的核心问题："你是谁？对谁说？你和别人有什么不同？"

## 核心原则

- **定位先于传播**：在写任何文案、做任何营销之前，先想清楚品牌定位。
- **战略层级意识**：不同层级的定位服务于不同对象——企业级面向投资者/合作伙伴，产品线级面向渠道/细分市场，单品级面向终端用户。
- **差异化是核心**：定位的本质是在用户心智中占据一个独特位置。
- **可插拔调用**：本Skill输出的品牌定位结果，可被 `copywriting`、`marketing-planning`、`value-proposition`、`future-vision` 等Skill调用。

## 一、战略层级内部分层

同一套定位框架，在不同战略层级应用时，关注点不同：

| 战略层级 | 定位对象 | 核心问题 | 输出用途 |
|---------|---------|---------|---------|
| **企业级** | 投资者、合作伙伴、政府 | "这家企业为什么存在？创造什么独特价值？" | 融资BP、企业官网、战略合作 |
| **产品线级** | 渠道商、细分市场 | "这条产品线解决哪类用户的什么问题？" | 产品线规划、渠道策略 |
| **单品级** | 终端用户 | "这个产品凭什么选你而不选竞品？" | 产品文案、营销推广、包装设计 |

**使用方法**：先确定当前任务对应的战略层级，再按该层级的关注点执行定位。

## 二、四大关键考量

### 2.1 目标市场分析

```
诊断问题：
1. 你的用户是谁？（人口统计+行为特征+心理特征）
2. 他们的核心需求是什么？（功能需求+情感需求+社交需求）
3. 市场的规模和增长趋势如何？
4. 哪些细分segment最值得进入？
```

### 2.2 竞争对手分析

```
诊断问题：
1. 直接竞品是谁？他们的定位是什么？
2. 间接替代品有哪些？
3. 竞品的优势和劣势分别是什么？
4. 市场上有没有未被满足的需求空白？
```

### 2.3 品牌个性塑造

```
诊断问题：
1. 如果品牌是一个人，TA的性格是什么？（5个性格关键词）
2. 品牌的语调是什么？（专业/亲切/幽默/权威/叛逆）
3. 品牌的视觉识别是什么？（色彩/字体/图像风格）
4. 品牌绝对不会是什么？（反面定义同样重要）
```

### 2.4 情感连接点

```
诊断问题：
1. 用户在使用产品时最强烈的情感是什么？
2. 品牌能在什么时刻给用户带来情感满足？
3. 用户为什么会主动向朋友推荐这个品牌？
4. 品牌代表的价值观/生活态度是什么？
```

## 三、完整模板（8组件）

```
品牌定位声明：

1. 目标用户：对于[目标用户描述]
2. 品类框架：[产品属于什么品类/市场]
3. 核心利益：[产品提供的最核心利益点]
4. 差异化理由：[为什么选你而不选竞品]
5. 信任支撑：[支撑差异化理由的证据]
6. 品牌个性：[如果用3-5个词描述品牌性格]
7. 情感连接：[品牌与用户之间的情感纽带]
8. 品牌承诺：[品牌始终如一地兑现什么]
```

**示例**：
> 对于**注重安全的年轻家庭**（目标用户），在**智能门锁市场**（品类框架），**XX门锁提供"忘带钥匙也不怕"的自由体验**（核心利益），**因为它是唯一同时支持指纹+人脸+远程开锁且通过C级锁芯认证的品牌**（差异化理由），**拥有3项国家专利和10万+用户验证**（信任支撑）。品牌个性是**安全、温暖、智能**（品牌个性），让每次回家都感到**安心和自在**（情感连接），**承诺"让每个家庭都能享受无钥匙的自由"**（品牌承诺）。

## 四、常见陷阱

| 陷阱 | 症状 | 应对 |
|------|------|------|
| 定位过宽 | "我们面向所有用户" → 等于没有定位 | 强制缩小范围：先服务一个核心群体 |
| 定位趋同 | 和竞品说的几乎一样 → 没有差异化 | 用"竞品也会说这句话吗"测试 |
| 定位空洞 | 说了很多但没有信任支撑 → 像自吹自擂 | 每个主张都必须有证据支撑 |
| 定位摇摆 | 频繁改变定位 → 用户认知混乱 | 定位确定后至少坚持1-2年 |

## 五、评估标准

| 维度 | 评估问题 | 达标标准 |
|------|---------|---------|
| 清晰性 | 一句话能否说清"你是谁"？ | 非行业人士也能听懂 |
| 差异化 | 换成竞品名字还成立吗？ | 不成立=通过 |
| 可信度 | 每个主张都有证据吗？ | 100%有支撑 |
| 一致性 | 定位与产品/渠道/体验是否一致？ | 用户触点不矛盾 |
| 持久性 | 这个定位能坚持2年以上吗？ | 不依赖短期热点 |

## 调用关系

- **被调用**：`value-proposition`（价值主张基于品牌定位提炼）、`copywriting`（品牌故事模板调用品牌定位）、`marketing-planning`（营销策划获取战略输入）、`future-vision`（愿景与定位一致性检验）、`channel-content-strategy`（渠道内容策略获取战略输入）
- **调用**：无（品牌定位是最底层的战略输入，不依赖其他品牌模块）
