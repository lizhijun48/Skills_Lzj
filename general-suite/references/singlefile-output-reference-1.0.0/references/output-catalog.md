# 产出类型清单与依赖拓扑

### S5 子命令串联示例

```
# 示例：分析日志中的错误IP并生成报告
python cli.py log parse --file app.log --level ERROR \
  | python cli.py csv filter --col ip --unique \
  | python cli.py csv sort --col count --desc \
  > error_report.txt

# 示例：扫描目录→筛选图片→批量加水印→重命名
python cli.py dir scan ./photos \
  | python cli.py img resize --max-width 1920 \
  | python cli.py img watermark --text "Copyright" \
  | python cli.py file rename --pattern "photo_{n:04d}.jpg"
```

## 依赖拓扑摘要

**基础工具链**: S3-01~S3-08（全部无依赖，可作为其他产出的基础设施）
**数据流水链**: S5-02 → S5-04 → S4-01 → S1-06 （目录扫描→数据处理→图表→报告）
**可视化增强链**: S3-06 → S6-04 / S3-05 → S6-08 / S3-04 → S6-07 （基础工具→高级版本）
**教学复合链**: S7-03 → S7-04 / S6-01 → S7-05 / S4-04 → S7-06 （基础可视化→教学化包装）
**游戏→教学迁移**: S2-01/S2-03 → S7-04（游戏逻辑复用为算法教学）
**Python工具串联**: S5域内部任意串联（管道/子进程），形成自定义工具链
**全栈演示链**: S5-06(HTTP) → S3-05(JSON格式化) → S4-01(图表) → S1-01(PPT) （API调用→数据处理→可视化→演示）

更多组合由UTOS根据具体任务动态推导。
