# 使用示例

## 示例 1：把观点扩写成商业短文

### 输入

```text
请用刘润写作助手，把这个观点扩写成一篇 800 字短文：
企业增长的关键，不是做更多事情，而是找到真正约束增长的瓶颈。
```

### 输出格式

- 3 个标题备选；
- 一篇 800 字左右文章；
- 结尾给出 3 条行动建议。

---

## 示例 2：改写文章开头

### 输入

```text
下面这段开头太平了，请改成更有问题意识、更有商业洞察感的开头：
现在很多公司都很重视客户体验，但是客户体验并不容易做好。
```

### 输出格式

- 原问题诊断；
- 改写版本 3 个；
- 推荐版本与理由。

---

## 示例 3：生成文章大纲

### 输入

```text
我想写一篇文章，主题是“为什么中层管理者越来越难”。请帮我设计一篇公众号文章大纲。
```

### 输出格式

- 标题 5 个；
- 文章主线；
- 5 个一级章节；
- 每章核心观点；
- 可用案例方向；
- 结尾金句。

---

## 示例 4：标题优化

### 输入

```text
请优化以下标题，使它更像一篇商业洞察文章：
如何提高员工积极性
```

### 输出格式

- 10 个标题；
- 分为：问题型、反常识型、洞察型、行动型；
- 每类说明适用场景。

---

## 示例 5：把复杂概念讲清楚

### 输入

```text
请解释“交易成本”这个概念，面向非经济学背景的管理者，用商业文章的方式讲清楚。
```

### 输出格式

- 一个生活化开头；
- 概念定义；
- 商业案例；
- 管理启发；
- 结尾行动建议。

---

## 示例 6：文章审校

### 输入

```text
请审校下面这篇文章，看它是否符合刘润式商业写作方法，并提出修改建议。
```

### 输出格式

1. 总体评价；
2. 结构问题；
3. 语言问题；
4. 洞察问题；
5. 可直接替换的修改稿。
