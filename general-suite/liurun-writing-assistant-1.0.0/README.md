# 刘润写作助手 Skill

这是一个面向商业写作、管理表达和公众号文章创作的写作辅助 Skill。

它基于用户提供的《刘润详细写作风格清单.docx》进行结构化蒸馏，帮助使用者形成一种：

- 先提出问题；
- 再定义概念；
- 然后用商业案例解释；
- 最后给出洞察和行动建议的写作方式。

> 注意：本 Skill 是“写作方法辅助器”，不是对任何现实人物的身份模拟，也不应声称文章由某位现实人物本人创作。

## 适用任务

- 写商业评论文章；
- 写管理、组织、战略、增长主题文章；
- 将普通文章改写得更有商业洞察；
- 生成公众号文章大纲；
- 优化标题、开头和结尾；
- 把复杂观点讲得更清楚、更有层次；
- 对已有文章做结构和表达诊断。

## 推荐使用方式

你可以这样调用：

```text
请用刘润写作助手，帮我把下面这段内容改写成一篇商业洞察短文：
……
```

```text
请用刘润写作助手，围绕“酒店行业的会员增长”写一篇公众号文章大纲。
```

```text
请用刘润写作助手，帮我优化这篇文章的开头，让它更有问题意识和传播感。
```

## 使用边界

- 可以学习结构、节奏、论证方法和商业表达风格；
- 不复制具体文章段落；
- 不伪造现实人物身份；
- 不承诺“完全等同本人写作”；
- 输出应服务于用户自己的观点和业务目标。

## 安装检查

安装前请确认 `SKILL.md` 文件开头包含 YAML frontmatter：

```yaml
---
name: liurun-writing-assistant
description: ...
---
```

如果缺少 `name` 字段，Skill 管理器可能会提示技能没有写全或无法安装。
