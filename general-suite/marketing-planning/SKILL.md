# 营销策划 (Marketing Planning)

面向产品经理/营销人员的结构化营销策划技能。涵盖从创意概念到执行落地的完整链路。

## 核心原则

- **战略驱动**：营销策划不是"想个创意"，而是从品牌定位和价值主张出发，确保每个动作都在积累品牌资产。
- **三模块闭环**：创意概念（说什么）→ 传播策略（怎么说/在哪说）→ 执行方案（怎么做/何时做），三者缺一不可。
- **效果可衡量**：每个营销活动都必须预设可量化的评估指标，不做"做了就算"的营销。
- **可插拔调用**：文案撰写调用 `copywriting` 技能，战略输入调用 `brand-positioning`/`value-proposition` 技能。

## 一、营销策划三模块模型

```
创意概念（说什么）→ 传播策略（在哪说/怎么说）→ 执行方案（何时做/谁来做/花多少）
     ↑                                                              ↓
     └──────────── 效果评估 → 反馈优化 ←──────────────────────────┘
```

| 模块 | 核心问题 | 关键产出 |
|------|---------|---------|
| **创意概念** | "我们要传递什么核心信息？" | 营销主题、核心卖点、创意表达 |
| **传播策略** | "通过什么渠道、用什么方式触达目标用户？" | 渠道组合、内容矩阵、传播节奏 |
| **执行方案** | "具体怎么落地？需要什么资源？" | 时间表、预算分配、责任分工、风险预案 |

## 二、诊断式工作流

```
用户提出营销需求
       ↓
  ┌──────────────┐
  │ 诊断：什么阶段？│ ← 判断产品生命周期+营销目标
  └──────┬───────┘
         ↓
  ┌──────────────┐
  │ 战略输入获取   │ ← 调用brand-positioning/value-proposition
  └──────┬───────┘
         ↓
  ┌──────────────┐
  │ 创意概念生成   │ ← 确定营销主题和核心信息
  └──────┬───────┘
         ↓
  ┌──────────────┐
  │ 传播策略设计   │ ← 选择渠道组合和传播节奏
  └──────┬───────┘
         ↓
  ┌──────────────┐
  │ 执行方案编制   │ ← 时间表+预算+分工+风险
  └──────┬───────┘
         ↓
  ┌──────────────┐
  │ 效果评估框架   │ ← 预设KPI和评估节点
  └──────────────┘
```

### 诊断引导问题

| 诊断问题 | 答案指向 | 影响 |
|---------|---------|------|
| "产品处于什么阶段？" | 预热期/上线期/成长期/成熟期 | 决定营销重心 |
| "核心营销目标是什么？" | 品牌认知/用户获取/用户激活/营收增长 | 决定KPI和策略 |
| "目标用户在哪里？" | 线上/线下渠道偏好 | 决定渠道组合 |
| "预算和时间约束？" | 资源边界 | 决定执行方案粒度 |

## 三、模块一：创意概念

### 3.1 营销主题提炼

从价值主张出发，提炼出一个能在目标用户心中留下印记的营销主题。

**提炼路径**：
```
价值主张（产品能做什么）→ 用户利益（对用户有什么用）→ 情感价值（让用户感觉如何）→ 营销主题（一句话表达）
```

**示例**：
- 价值主张："智能门锁支持指纹+密码+NFC三种开锁方式"
- 用户利益："再也不用担心忘带钥匙"
- 情感价值："出门自由、回家安心"
- 营销主题："一把锁的自由"

### 3.2 创意概念生成

使用 `creative-prompt-techniques` 技能中的框架生成创意：

| 创意需求 | 推荐框架 | 用法 |
|---------|---------|------|
| 需要差异化定位 | CGS（概念嫁接）+ BRIDGE（跨界） | 将其他行业的营销创意迁移到本产品 |
| 需要突破常规 | EHS（极端假设）+ RCM（随机组合） | 打破"营销就该这样做"的思维定式 |
| 需要在约束中创新 | MCS（多重约束） | 在预算/时间/渠道约束下找最优解 |
| 需要大量创意选项 | IDEA（发散） | 从多角度生成创意方案 |

### 3.3 创意评估矩阵

| 评估维度 | 评估问题 | 权重 |
|---------|---------|------|
| 相关性 | 创意是否与目标用户的痛点相关？ | 30% |
| 差异化 | 创意是否与竞品营销形成差异？ | 25% |
| 可执行性 | 创意在现有资源下能否落地？ | 20% |
| 传播性 | 创意是否具备自传播潜力（用户愿意分享）？ | 15% |
| 品牌一致性 | 创意是否与品牌调性一致？ | 10% |

## 四、模块二：传播策略

### 4.1 渠道选择矩阵

| 渠道类型 | 适用场景 | 优势 | 劣势 | 关键指标 |
|---------|---------|------|------|---------|
| 社交媒体（微信/微博/小红书） | 品牌认知、口碑传播 | 覆盖面广、互动性强 | 信息噪音大、转化链路长 | 曝光量、互动率、分享率 |
| 内容营销（公众号/知乎/B站） | 深度教育、信任建立 | 长尾效应、SEO价值 | 见效慢、需要持续投入 | 阅读量、转化率、留存率 |
| KOL/KOC合作 | 快速建立信任、种草 | 借力信任背书 | 成本高、效果不可控 | ROI、种草转化率 |
| 线下活动/展会 | 深度体验、B端获客 | 体验感强、信任度高 | 成本高、覆盖面有限 | 线索数量、转化率 |
| SEM/信息流广告 | 精准获客、效果转化 | 精准定向、效果可量化 | 成本持续上升 | CPC、CPA、ROAS |
| 邮件/短信/推送 | 用户激活、留存召回 | 成本低、触达直接 | 打开率低、易引起反感 | 打开率、点击率、退订率 |

### 4.2 传播节奏设计

```
预热期（1-2周）    → 制造悬念/期待，小范围种草
     ↓
引爆期（3-5天）    → 集中资源引爆关注，多渠道同步
     ↓
持续期（2-4周）    → 持续内容输出，深度转化
     ↓
长尾期（持续）     → SEO/口碑维护，用户自发传播
```

### 4.3 内容矩阵

不同渠道需要不同的内容形式，调用 `copywriting` 技能生成对应文案：

| 渠道 | 内容形式 | 调用模板 | 语言风格侧重 |
|------|---------|---------|------------|
| 朋友圈 | 短文案+图片 | 社交媒体文案 | RSM：个人化；EIS：真实感 |
| 公众号 | 长文 | 长文营销 | RSM：专业；RTA：故事+数据 |
| 小红书 | 种草笔记 | 社交媒体文案 | RSM：生活化；EIS：种草感 |
| 官网 | 产品说明 | 产品说明文案 | RSM：专业权威；信息为主 |
| 广告 | 广告语 | 广告语/Slogan | RTA：修辞加工；简洁有力 |
| 邮件 | 推广邮件 | 邮件营销 | 行动导向；CTA明确 |

## 五、模块三：执行方案

### 5.1 时间表模板

```
第1周：预热期
  - [ ] 确定营销主题和核心信息
  - [ ] 制作核心物料（文案/图片/视频）
  - [ ] KOL/KOC沟通，寄送样品
  - [ ] 社交媒体预热内容发布

第2周：引爆期
  - [ ] 产品正式发布/活动上线
  - [ ] 多渠道同步发布（社交媒体+广告+PR）
  - [ ] KOL/KOC内容集中发布
  - [ ] 监控数据，实时调整

第3-4周：持续期
  - [ ] 持续内容输出（用户故事/使用教程/对比评测）
  - [ ] 用户UGC激励活动
  - [ ] 效果数据分析，优化投放策略

第5周+：长尾期
  - [ ] SEO内容优化
  - [ ] 用户口碑收集与传播
  - [ ] 营销复盘报告
```

### 5.2 预算分配框架

| 预算项 | 占比建议 | 说明 |
|-------|---------|------|
| 内容制作 | 20-30% | 文案/设计/视频/物料 |
| 渠道投放 | 40-50% | 广告/KOL/活动 |
| 人力成本 | 15-20% | 策划/执行/监控 |
| 应急储备 | 5-10% | 应对突发情况/追加投放 |

### 5.3 风险预案

| 风险类型 | 预警信号 | 应对方案 |
|---------|---------|---------|
| 传播效果不及预期 | 首日曝光量<目标的50% | 追加投放/调整创意/更换渠道 |
| 负面舆情 | 出现集中负面评价 | 快速响应/真诚沟通/解决问题 |
| 预算超支 | 实际花费>计划的120% | 砍掉ROI最低渠道/集中资源 |
| 竞品拦截 | 竞品同期推出类似活动 | 差异化应对/避免正面价格战 |

## 六、营销效果评估框架

### 6.1 分阶段KPI

| 阶段 | 核心KPI | 评估方法 |
|------|--------|---------|
| 预热期 | 话题热度、预约/关注数 | 社交媒体数据监控 |
| 引爆期 | 曝光量、互动量、首日转化 | 实时数据看板 |
| 持续期 | 获客成本(CAC)、转化率 | 渠道ROI分析 |
| 长尾期 | 留存率、NPS、口碑指数 | 用户调研+数据分析 |

### 6.2 复盘模板

```
1. 目标回顾：原定目标是什么？实际达成多少？
2. 亮点总结：哪些做得好？为什么好？能否复制？
3. 不足分析：哪些没达到预期？根因是什么？
4. 经验沉淀：下次应该继续做什么？停止做什么？开始做什么？
```

## 使用建议

1. **独立使用**：按"诊断→创意概念→传播策略→执行方案"流程完成营销策划。
2. **联动调用**：
   - 需要品牌战略输入 → 调用 `brand-positioning`/`value-proposition`
   - 需要撰写各类文案 → 调用 `copywriting`
   - 需要创意激发 → 调用 `creative-prompt-techniques`
3. **效果导向**：每个营销活动开始前，先确定KPI和评估节点，不做"凭感觉"的营销。
