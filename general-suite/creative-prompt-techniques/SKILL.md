# 创意提示语技术 (Creative Prompt Techniques)

基于清华大学《DeepSeek：从入门到精通》提炼的创意思维提示语框架与实操方法。

## 核心原则

- **框架引导创意**：用结构化框架引导AI的创造性思维，而非放任自由发散。
- **约束激发创新**：适当的限制条件反而能激发更强的创造力。
- **跨界产生突破**：将不同领域的概念强制关联，往往产生最具创新性的结果。
- **先发散后聚合**：创意过程应先生成大量可能性，再筛选和优化。

## 一、九大创意思维框架

### 1. IDEA框架——发散思维

用于从多角度探索可能性，生成大量创意选项。

| 步骤 | 英文 | 操作 | 提示语示例 |
|------|------|------|-----------|
| I | Imagine（想象） | 鼓励超越常规的思考 | "假设[限制条件]不存在，会怎样？" |
| D | Diverge（发散） | 探索多个可能性 | "从技术/商业/用户三个角度分别思考解决方案" |
| E | Expand（扩展） | 深化和拓展初始想法 | "在这个想法基础上，进一步延伸出3个变体" |
| A | Alternate（替代） | 寻找替代方案 | "如果换一种完全不同的思路，会怎么做？" |

### 2. FOCUS框架——聚合思维

用于从大量想法中筛选、优化和形成最终方案。

| 步骤 | 英文 | 操作 | 提示语示例 |
|------|------|------|-----------|
| F | Filter（筛选） | 评估和选择最佳想法 | "用以下标准评估这些方案：可行性、创新性、成本" |
| O | Optimize（优化） | 改进选定的想法 | "如何在不增加成本的前提下提升这个方案的效果？" |
| C | Combine（组合） | 整合多个想法 | "将方案A的[特点]和方案B的[特点]结合起来" |
| U | Unify（统一） | 创建一致的叙述或方案 | "将整合后的方案形成统一完整的描述" |
| S | Synthesize（综合） | 形成最终结论 | "综合以上所有分析，输出最终方案" |

### 3. BRIDGE框架——跨界思维

用于将不同领域的概念和方法进行跨界融合。

| 步骤 | 英文 | 操作 | 提示语示例 |
|------|------|------|-----------|
| B | Blend（混合） | 融合不同领域的概念 | "将[领域A]和[领域B]的核心方法结合" |
| R | Reframe（重构） | 用新视角看待问题 | "如果从[某行业]的角度来看这个问题..." |
| I | Interconnect（互联） | 建立领域间的联系 | "找出这两个领域之间3个结构性相似点" |
| D | Decontextualize（去情境化） | 将概念从原始环境中抽离 | "剥离[概念]的行业背景，提取核心原理" |
| G | Generalize（泛化） | 寻找普适原则 | "这个原理可以推广到哪些其他场景？" |
| E | Extrapolate（推演） | 将原理应用到新领域 | "将[原理]应用到[新领域]，设计具体方案" |

### 4. CMM——跨域映射机制

用于通过类比推理激发创新思维。

**实施步骤**：
1. **源域选择**：根据任务选择合适的类比源域
2. **映射点识别**：确定源域和目标域间的关键对应点
3. **类比生成**：创造性地将源域概念应用于目标域
4. **类比细化**：调整和优化类比，确保恰当性和新颖性

**提示语模板**：
```
请将[源领域]的运作机制类比到[目标领域]：
1. 找出两个领域之间5个结构性相似点
2. 逐层展开类比，每个类比都要有具体的对应关系
3. 深入探讨类比对目标领域的启示
4. 提出至少2个基于类比的创新思路
5. 分析类比的局限性，指出关键差异
```

### 5. CGS——概念嫁接策略

用于将两个看似不相关的概念进行创造性融合。

**实施步骤**：
1. **输入空间定义**：明确要融合的两个概念领域
2. **通用空间识别**：找出共同特征
3. **选择性投射**：从每个概念中选择相关元素进行融合
4. **涌现结构构建**：在融合空间中创造新结构

**提示语模板**：
```
将[概念A]和[概念B]进行嫁接，设计创新方案：
1. 分别列出两个概念的核心特征（各5个）
2. 找出它们之间的共同点和互补点
3. 设计3个创新性连接点
4. 基于连接点构建融合方案
5. 评估融合方案的可行性和创新性
```

### 6. EHS——极端假设策略

用于突破思维界限，从极端角度激发创新。

**实施步骤**：
1. **常规假设识别**：列出当前领域被广泛接受的假设
2. **极端反转**：将这些假设推向极端或完全颠覆
3. **后果探索**：深入探讨极端假设带来的影响和机会
4. **创新洞察提取**：从极端假设中提取可能的创新点

**提示语模板**：
```
对[领域/问题]进行极端假设思考：
1. 列出5个该领域被广泛接受的常规假设
2. 将每个假设推向极端或完全反转
3. 对每个极端假设，描述如果成真的具体场景
4. 从极端场景中提炼3个可落地的创新机会
5. 评估哪些创新点在当前条件下可以部分实现
```

### 7. MCS——多重约束策略

用于在有限条件下激发创造性问题解决。

**实施步骤**：
1. **约束条件设定**：制定多个具有挑战性的限制条件
2. **约束间矛盾分析**：识别约束之间的潜在冲突
3. **创造性妥协探索**：寻找满足所有约束的创新方案
4. **约束突破思考**：探索创造性地绕过或重新定义约束

**提示语模板**：
```
在以下多重约束下设计[产品/方案]：
约束条件：
- [约束1：如成本不超过X元]
- [约束2：如体积不超过Y]
- [约束3：如必须满足Z功能]
- [约束4：如使用环保材料]

请：
1. 分析约束之间的潜在冲突
2. 在每个约束下提出可行方案
3. 寻找同时满足所有约束的创新方案
4. 如果存在不可调和的矛盾，提出约束重构建议
```

### 8. KTT——知识转移技术

用于将一个领域已验证的知识/方法系统性地迁移到另一个领域。与BRIDGE的区别：BRIDGE强调"跨界联想"（发散），KTT强调"知识迁移的可靠性"（收敛——源知识必须经过验证）。

**理论基础**：迁移学习理论（Transfer of Learning, Perkins & Salomon 1992）——近迁移（相似领域间）和远迁移（差异大的领域间）是两种不同的认知过程。KTT通过结构化的映射步骤，降低远迁移的失败风险。

**实施步骤**：
1. **源知识识别**：明确要迁移的知识/方法，确认其在原始领域的验证程度
2. **结构抽象**：剥离源知识的领域细节，提取其核心机制/原理
3. **目标域适配**：分析目标域的约束条件和差异点，调整知识的应用方式
4. **迁移验证**：在目标域小规模测试迁移效果，收集反馈并修正

**提示语模板**：
```
将[源领域]中已验证的[方法/知识]迁移到[目标领域]：
1. 描述[方法]在源领域的核心机制（剥离行业细节，提取底层原理）
2. 分析目标领域与源领域的3个结构性相似点（确保迁移有基础）
3. 分析目标领域与源领域的3个关键差异点（确保适配调整）
4. 设计迁移方案，明确哪些部分可以直接复用、哪些需要调整
5. 提出迁移可能的风险点和验证方法
```

### 9. RCM——随机组合机制

用于通过强制性的随机元素组合，打破思维惯性，产生意想不到的创意。

**理论基础**：强制联系理论（Forced Connections, De Bono 1992）——当两个原本无关的概念被强制关联时，大脑会自动寻找它们之间的联系，这个过程本身就是创意的来源。与CGS（概念嫁接）的区别：CGS是有意识地选择两个相关概念进行融合，RCM是引入随机性来打破选择偏见。

**实施步骤**：
1. **问题定义**：明确需要创意的目标问题
2. **随机元素引入**：随机选择一个与问题无关的概念/物体/场景
3. **强制联系**：强制找出随机元素与目标问题之间的3个联系
4. **创意转化**：将联系转化为可执行的创意方案

**提示语模板**：
```
目标问题：[需要创意解决的问题]

请执行随机组合创意思考：
1. 随机选择一个与问题完全无关的概念（可以是动物、建筑、食物、运动等）
2. 描述这个随机概念的核心特征（3-5个）
3. 强制找出每个特征与目标问题之间的潜在联系
4. 从联系中提炼至少2个创意方案
5. 评估这些方案的可行性和创新度
```

## 二、语言风格优化三件套（RSM+EIS+RTA）

三个专注于"怎么说"的语言风格优化框架，可独立使用，更推荐整合使用。

### 10. RSM——语体模拟机制

用于让AI模仿特定的语言风格或文体，实现精准的表达调性控制。

**理论基础**：语域理论（Register Theory, Halliday 1978）——语言风格由三个维度决定：语场（讨论什么话题）、语旨（和谁说话、关系如何）、语式（通过什么媒介）。RSM通过明确这三个维度，让AI精准匹配目标语体。

**实施步骤**：
1. **目标语体识别**：确定要模仿的语言风格（如学术论文、朋友圈文案、政府公文）
2. **语域三维度定义**：明确语场（话题范围）、语旨（作者与读者关系）、语式（表达媒介）
3. **风格特征提取**：列出目标语体的5-8个关键特征（句式、用词、语气等）
4. **风格应用与校验**：生成内容后，对照特征清单检查是否达标

**提示语模板**：
```
请用[目标语体]风格撰写[内容]：

语域设定：
- 语场（话题）：[讨论什么]
- 语旨（关系）：[作者身份]对[读者身份]，[正式/非正式/亲切/权威]
- 语式（媒介）：[书面/口头/社交媒体/邮件]

风格特征要求：
- 句式：[如：短句为主/长句嵌套/口语化]
- 用词：[如：专业术语多/日常用语/网络用语]
- 语气：[如：客观冷静/热情洋溢/幽默讽刺]
- 其他：[如：善用比喻/数据驱动/故事开头]
```

### 11. EIS——情感融入策略

用于在AI生成内容中有策略地融入情感元素，增强感染力和共鸣度。

**理论基础**：情感语言学（Affective Linguistics）——语言不仅是信息载体，也是情感载体。情感融入不是"加几句感叹号"，而是通过词汇选择、叙事节奏、共情锚点等策略，在认知层面激活读者的情感反应。

**实施步骤**：
1. **目标情感识别**：确定希望读者产生的情感（如紧迫感、信任感、好奇心、归属感）
2. **情感锚点设计**：找到能触发该情感的具体元素（场景、故事、数据对比）
3. **情感节奏编排**：安排情感的起伏节奏，避免全程高亢或全程平淡
4. **情感-理性平衡**：确保情感元素服务于论证，而非替代理性

**提示语模板**：
```
撰写关于[主题]的内容，需要融入以下情感策略：

目标情感：[如：紧迫感+希望感]
情感锚点：
- 触发[紧迫感]：用[具体场景/数据对比]让读者感受到"不能再等了"
- 触发[希望感]：用[成功案例/未来愿景]让读者感受到"可以做到"

情感节奏：
- 开头：用[场景/故事]引发共鸣
- 中间：用[数据/事实]建立理性信任
- 结尾：用[愿景/号召]激发行动

注意：情感元素必须服务于核心论点，不要为了感动而感动。
```

### 12. RTA——修辞技巧应用

用于在AI生成内容中系统性地运用修辞手法，增强表达效果。

**理论基础**：修辞学（Rhetoric, Aristotle）——亚里士多德提出的三大修辞手段：Ethos（信誉/权威）、Pathos（情感）、Logos（逻辑）。RTA将古典修辞学转化为AI可执行的提示语策略，让内容不仅"说得对"，还"说得好"。

**常用修辞手法与提示语映射**：

| 修辞手法 | 效果 | 提示语设计 |
|---------|------|-----------|
| 比喻/类比 | 将抽象概念具象化 | "用日常生活中的比喻解释这个技术概念" |
| 排比 | 增强节奏感和气势 | "用3个结构相同的句式强调核心观点" |
| 反问 | 引发读者思考 | "在关键论点前用反问句引发读者共鸣" |
| 对比 | 突出差异和变化 | "用'过去vs现在''我们vs竞品'的对比结构" |
| 层递 | 逐步加强说服力 | "从个人→团队→组织→社会，逐层扩大影响范围" |
| 引用/权威 | 增强可信度 | "引用2-3个权威来源的数据或观点支撑论点" |

**提示语模板**：
```
在撰写[内容]时，请运用以下修辞策略：

核心修辞：
- [手法1]：用于[具体位置/目的]
- [手法2]：用于[具体位置/目的]
- [手法3]：用于[具体位置/目的]

修辞节奏：
- 开头用[如：反问]吸引注意力
- 论证用[如：数据+类比]增强说服力
- 结尾用[如：排比+层递]强化行动号召
```

### 语言风格三件套整合模式

RSM、EIS、RTA三者不是孤立的，而是形成"语体→情感→修辞"的层级关系：

```
RSM（语体模拟）—— 确定"用什么调性说话"
    ↓ 语体确定后
EIS（情感融入）—— 确定"传递什么情感"
    ↓ 情感确定后
RTA（修辞技巧）—— 确定"用什么手法实现"
```

**整合使用提示语模板**：
```
请用以下语言风格策略撰写[内容]：

第一层·语体（RSM）：
- 语场：[话题]  语旨：[身份关系]  语式：[媒介]
- 整体调性：[如：专业但不枯燥、权威但有温度]

第二层·情感（EIS）：
- 主情感：[如：信任感]  辅情感：[如：紧迫感]
- 情感锚点：[具体触发元素]
- 情感节奏：开头[共鸣]→中间[理性]→结尾[行动]

第三层·修辞（RTA）：
- 核心手法：[如：类比+数据对比+排比]
- 开头用[手法]吸引注意力
- 论证用[手法]增强说服力
- 结尾用[手法]强化号召
```

## 三、元叙事提示框架

通过构建叙事结构来引导AI生成更具吸引力和说服力的内容。核心理念：人类天生通过"故事"理解世界——好的内容不是信息的堆砌，而是一个有结构的故事。

### 子技巧1：叙事弧线设计

用经典的"起承转合"或"英雄之旅"结构组织内容。

```
请用以下叙事弧线组织内容：
- 起（引入）：用一个具体场景/问题/冲突开场，抓住注意力
- 承（发展）：展开背景信息，建立读者对问题的理解
- 转（转折）：引入关键洞察/解决方案/反转，制造"顿悟时刻"
- 合（收束）：总结启示，给出行动方向
```

### 子技巧2：角色代入法

让AI从特定角色的视角叙述，增强代入感。

```
请以[角色身份]的第一人称视角撰写[内容]：
- 角色特征：[年龄/职业/性格/经历]
- 角色处境：[面临什么问题/挑战]
- 角色情感：[焦虑/期待/困惑/兴奋]
- 叙述目的：[分享经验/寻求帮助/记录成长]
```

### 子技巧3：冲突-解决叙事

通过制造和解决冲突来构建内容张力。

```
请用"冲突→解决"的叙事结构撰写[内容]：
- 核心冲突：[A vs B，如"效率vs安全""短期vs长期"]
- 冲突升级：描述冲突如何加剧，让读者感受到张力
- 转折点：什么因素改变了局面
- 解决方案：如何化解冲突（或找到平衡点）
- 启示：这个冲突-解决过程给我们的教训
```

### 子技巧4：多声部叙事

用多个视角/声音叙述同一事件，呈现复杂性。

```
请用多声部叙事方式呈现[主题]：
- 声音1：[角色A]的视角——关注[什么]，语气[如何]
- 声音2：[角色B]的视角——关注[什么]，语气[如何]
- 声音3：[角色C]的视角——关注[什么]，语气[如何]
- 综合：在多个视角的基础上，提炼出全面的结论
```

## 四、三大创意激发方法

### 方法一：抽象-具体循环法

在不同抽象层次间灵活切换：
1. **抽象化问题**：将具体问题提升到抽象层面
2. **具体化反馈**：将抽象思考落地为具体方案
3. **迭代优化**：在抽象和具体之间反复切换，逐步精炼

### 方法二：矛盾思维法

利用对立促进创新：
1. 引入对立概念
2. 提出冲突性任务要求
3. 融合批判性思维与创新推理
4. 多方论证与批判结合

### 方法三：反向设计思维

从期望结果倒推提示语：
1. 从期望的最终结果开始
2. 倒推实现该结果需要的中间步骤
3. 设计对应的提示语结构
4. 灵活调整细节

## 五、创意提示语设计检查清单

- [ ] 是否给AI留出了足够的探索空间？
- [ ] 是否设置了适度的约束条件（不过多也不过少）？
- [ ] 是否引导AI从多个角度思考？
- [ ] 是否包含跨领域联想的引导？
- [ ] 是否有"先发散后聚合"的节奏设计？
- [ ] 是否要求AI挑战常规观点？
- [ ] 是否包含评估和筛选机制？
- [ ] 是否避免了过度限制AI的创造力？

## 使用建议

1. **产品创意**：优先使用MCS（多重约束）+ CGS（概念嫁接），在约束中激发创新。
2. **方案优化**：使用IDEA发散 + FOCUS聚合的组合，先生成后筛选。
3. **突破瓶颈**：使用EHS（极端假设）+ BRIDGE（跨界思维），打破思维定式。
4. **技术迁移**：使用CMM（跨域映射）+ KTT（知识转移），实现跨领域应用。

## 六、PM产品创新场景映射

九大创意思维框架与产品经理日常创新场景的对应关系——同一个认知机制，在不同业务场景中的应用：

| 创意框架 | 认知机制 | PM 产品创新场景 | 典型用法 | 提示语切入示例 |
|---------|---------|----------------|---------|-------------|
| **IDEA** | 发散→收敛交替 | 用户洞察与需求探索 | 等同于设计思维（Design Thinking）的五步法：同理心→定义→构思→原型→测试 | "从用户/技术/商业三个角度发散，然后收敛到最有价值的3个需求" |
| **FOCUS** | 聚合筛选 | 方案评估与优先级排序 | 从大量需求/方案中筛选出MVP范围 | "用RICE评分模型（Reach/Impact/Confidence/Effort）对这些方案排序" |
| **BRIDGE** | 类比迁移 | 竞品创新与跨界借鉴 | 从其他行业找产品灵感，如"把滴滴的模式用到XX领域" | "将游戏行业的'成就系统'迁移到我们的教育产品中" |
| **CMM** | 视角切换 | 用户画像与干系人分析 | 从不同角色视角审视同一产品——用户/开发/运营/老板各看到什么 | "分别从新手用户、重度用户、产品经理、开发者的视角评价这个功能" |
| **CGS** | 概念融合 | 功能组合与产品创新 | 把两个看似无关的功能融合成新产品特性 | "将'社交分享'和'任务管理'融合，设计一个协作型Todo产品" |
| **EHS** | 反事实思维 | 极端场景分析与风险探索 | 分析极端用户场景（残障用户/断网环境/海量数据）发现隐藏需求 | "如果用户只有单手操作能力，这个产品该怎么设计？" |
| **MCS** | 约束驱动创造力 | MVP设计与资源约束创新 | 在有限资源下找到最优解——"只有2周、3个人、0预算，怎么做？" | "在以下约束下设计MVP：2周开发周期、1个前端+1个后端、零推广预算" |
| **KTT** | 迁移学习 | 最佳实践引入与跨团队复用 | 将其他团队/行业已验证的方法迁移到自己的产品中 | "将Spotify的Squad模式迁移到我们的产品团队组织，分析适配点" |
| **RCM** | 强制联系 | 创意突破与差异化定位 | 引入随机元素打破思维惯性，发现被忽视的可能性 | "随机选一个自然界的生物，分析它的生存策略如何启发我们的产品竞争策略" |

### PM创新工作流：框架组合推荐

不同创新阶段推荐不同的框架组合：

```
发现机会 → CMM（多角色视角洞察痛点）+ EHS（极端场景发现隐藏需求）
    ↓
构思方案 → IDEA（发散生成大量方案）+ BRIDGE（跨界借鉴找灵感）
    ↓
评估筛选 → FOCUS（聚合筛选最优方案）+ CGS（功能融合创造差异化）
    ↓
落地执行 → MCS（约束条件下设计MVP）
```

### 实战案例：用创意框架做产品创新

**场景**：为一款B端SaaS产品寻找新的增长点

**发现机会（CMM + EHS）**：
> CMM："分别从以下角色视角审视我们的产品痛点：①一线使用者 ②部门管理者 ③IT管理员 ④采购决策者。每个角色最在意什么？当前产品在哪里让他们不满意？"
>
> EHS："假设极端场景：①如果用户完全不懂技术怎么用？②如果数据量增长100倍会怎样？③如果竞品完全免费怎么办？从这些极端场景中能发现什么隐藏需求？"

**构思方案（IDEA + BRIDGE）**：
> IDEA："基于发现的机会点，从技术可行性/商业价值/用户体验三个维度发散，生成至少10个产品创新方向。"
>
> BRIDGE："看看Notion/Figma/Slack是怎么解决类似问题的？它们的产品模式中有哪些可以迁移到我们的B端场景？"

**评估筛选（FOCUS + CGS）**：
> FOCUS："用以下标准评估10个方案：用户价值(1-10)、开发成本(1-10)、竞争壁垒(1-10)、上线速度(1-10)。选出综合得分最高的3个。"
>
> CGS："能否将排名第1的方案和排名第3的方案的核心特性融合，形成一个更有差异化的方案？"

**落地执行（MCS）**：
> MCS："在以下约束下设计MVP：开发周期4周、团队2人、预算0元。核心验证假设是[XX]。请设计最小可验证的产品形态。"

## 七、认知理论基础参考

> 本节为辅助阅读资料，帮助理解各框架背后的认知科学原理。

| 框架 | 认知机制 | 理论来源 | 核心原理 | 一句话理解 |
|------|---------|---------|---------|-----------|
| **IDEA** | 发散思维+聚合思维 | Guilford智力结构理论 | 创造力=发散生成可能性+聚合筛选最优解 | "先打开水龙头放满池子，再拔掉塞子找到最合适的出口" |
| **FOCUS** | 执行功能+抑制控制 | 认知控制理论 | 创造力的关键不仅是产生想法，更是抑制无关想法 | "好创意不是想得越多越好，而是知道该放弃什么" |
| **BRIDGE** | 类比迁移 | Gentner结构映射理论 | 创新往往来自将一个领域的结构映射到另一个领域 | "最好的点子不是凭空想出来的，是从别的地方'借'来的" |
| **CMM** | 心理理论+视角采择 | 认知灵活性理论 | 能同时持有多个视角的人，解决问题的创造力更高 | "同一件事，换个角色看就完全不一样——创新就藏在这个'不一样'里" |
| **CGS** | 概念整合 | Fauconnier概念融合理论 | 两个概念空间的 selective projection 产生新的涌现结构 | "把'电话'和'相机'融合→智能手机，整体大于部分之和" |
| **EHS** | 反事实思维 | 反事实推理理论 | 通过想象"如果不是这样"来打破功能固着和思维定式 | "如果规则不存在，你会怎么做？——答案往往就是创新的起点" |
| **MCS** | 约束满足 | Newell & Simon问题空间理论 | 约束不是创造力的敌人，而是创造力的催化剂 | "限制越多，反而越逼着你想出别人没想到的方案" |
| **KTT** | 迁移学习 | Perkins & Salomon迁移学习理论 | 远迁移需要结构抽象而非表面相似性，验证降低迁移风险 | "不是照搬别人的做法，而是提取做法背后的原理，在自己的场景里验证" |
| **RCM** | 强制联系 | De Bono侧向思维理论 | 随机元素打破选择偏见，强制联系激活隐性知识 | "随机翻开字典指一个词，然后把它和你的问题联系起来——创意就藏在这个'硬凑'里" |
| **RSM** | 语域匹配 | Halliday语域理论 | 语言风格由语场/语旨/语式三维度决定，明确维度才能精准模仿 | "写朋友圈和写论文用的是同一套语言系统，只是三个维度的参数不同" |
| **EIS** | 情感激活 | 情感语言学+镜像神经元理论 | 读者通过语言中的情感线索激活自身的情感体验 | "不是告诉读者'这很感人'，而是用细节让读者自己感动" |
| **RTA** | 修辞说服 | Aristotle修辞学（Ethos/Pathos/Logos） | 说服力=信誉×情感×逻辑，三者缺一不可 | "数据让人点头，故事让人心动，权威让人信服——三个一起用才让人行动" |

### 三大创意激发方法的认知基础

| 方法 | 认知机制 | 原理 |
|------|---------|------|
| **抽象-具体循环法** | 抽象化与具象化交替 | 在高层次看到"为什么"（方向），在低层次解决"怎么做"（落地），反复切换避免"只想不做"或"只做不想" |
| **矛盾思维法** | 辩证思维+认知冲突 | 引入矛盾制造认知冲突，迫使大脑跳出原有框架寻找更高层次的整合方案 |
| **反向设计思维** | 目的性倒推推理 | 从结果倒推过程，利用"终点锚定"效应避免被起点条件限制思路 |
