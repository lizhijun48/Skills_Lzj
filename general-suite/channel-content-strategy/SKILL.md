# 渠道内容策略 (Channel Content Strategy)

渠道内容策略回答的核心问题："内容发在哪里？怎么发？为什么发在那里？"

核心理念：**平台只是工具，目标才是目的。** 文案/视频都是适配最终目标的手段，而非目标本身。

## 核心原则

- **目标驱动，而非平台驱动**：先明确"要达成什么"，再选"用什么渠道"。不被平台特性绑架，而是让平台特性为战略目标服务。
- **双路径灵活切换**：定位清晰时走"直达匹配"路径；定位模糊时走"多渠测试→数据收敛"路径。两条路径可以并行，也可以先后衔接。
- **内容是手段，不是目的**：文案、视频、图文都是适配最终目标的工具。同一核心信息在不同渠道需要不同的表达形式，但战略内核不变。
- **方案A：知识库模式**：四大渠道的特性、模板、策略作为本Skill的内部知识库，而非拆分为独立Skill。调用方传入渠道参数，本Skill返回渠道适配方案。
- **可插拔调用**：战略输入调用 `brand-positioning`/`value-proposition`，文案执行调用 `copywriting`，提示语技巧调用 `creative-prompt-techniques`。

## 一、定位与适用场景

### 1.1 本Skill解决什么问题

| 问题 | 说明 |
|------|------|
| "我该发在哪个平台？" | 渠道选择决策——基于产品定位、目标用户、内容目标匹配最优渠道 |
| "同一内容怎么适配不同平台？" | 内容适配——将核心信息转化为各平台原生化内容 |
| "多平台怎么协同？" | 渠道组合——设计主次渠道搭配、内容分发节奏 |
| "发了没效果怎么办？" | 数据反馈——建立渠道效果评估与优化闭环 |

### 1.2 适用场景

- 新产品/新品牌首次进入市场，需要确定内容渠道
- 已有渠道但效果不佳，需要诊断和优化
- 多渠道运营但缺乏协同，需要整合策略
- 需要评估新渠道是否值得投入
- 需要将同一核心信息适配到多个渠道

### 1.3 不适用场景

- 纯粹的品牌战略定位（→ 调用 `brand-positioning`）
- 单一文案的撰写（→ 调用 `copywriting`）
- 营销活动的整体策划（→ 调用 `marketing-planning`）

## 二、诊断式工作流

```
用户提出渠道/内容需求
       ↓
  ┌──────────────────┐
  │ 诊断：四个关键变量 │ ← 产品定位清晰度 / 目标用户 / 内容目标 / 资源约束
  └────────┬─────────┘
           ↓
  ┌──────────────────┐
  │ 判断：走哪条路径？ │ ← 定位清晰 → 路径1 / 定位模糊 → 路径2
  └────────┬─────────┘
           ↓
  ┌──────────────────┐
  │ 渠道选择/测试方案  │ ← 路径1: 直接匹配 / 路径2: 多渠测试计划
  └────────┬─────────┘
           ↓
  ┌──────────────────┐
  │ 内容适配与执行     │ ← 调用渠道知识库 + copywriting
  └────────┬─────────┘
           ↓
  ┌──────────────────┐
  │ 传播策略与反馈闭环 │ ← 发布节奏 + 互动设计 + 数据评估
  └──────────────────┘
```

### 诊断引导问题

| 诊断问题 | 答案指向 | 影响 |
|---------|---------|------|
| "你的产品/品牌定位是否已经明确？" | 定位清晰度 | 决定走路径1还是路径2 |
| "目标用户是谁？他们在哪里？" | 用户画像+渠道偏好 | 决定渠道优先级 |
| "内容目标是什么？" | 品牌认知/种草转化/深度教育/即时转化 | 决定内容形式和渠道匹配 |
| "可投入的资源和时间约束？" | 人力/预算/时间 | 决定渠道数量和投入深度 |
| "是否已有渠道运营经验？" | 历史数据 | 路径2中决定测试起点 |

### 路径判断规则

```
定位是否清晰？
├── 是 → 目标用户是否明确集中在某一渠道？
│        ├── 是 → 路径1：直接匹配最优渠道
│        └── 否 → 路径1：匹配1-2个主力渠道 + 辅助渠道
└── 否 → 是否有资源做多渠道测试？
         ├── 是 → 路径2：设计多渠测试方案 → 数据收敛 → 聚焦
         └── 否 → 先完成品牌定位（调用brand-positioning），再回到此流程
```

## 三、渠道选择决策

### 路径1：定位清晰 → 直接渠道匹配

当产品定位和目标用户已经明确时，直接基于"用户-渠道匹配矩阵"选择最优渠道。

**渠道匹配矩阵：**

| 产品/内容特征 | 最优渠道 | 次优渠道 | 匹配理由 |
|-------------|---------|---------|---------|
| 专业深度内容、行业分析 | 微信公众号 | 知乎 | 私域深度阅读，适合长文逻辑输出 |
| 热点评论、观点表达、快速传播 | 微博 | 微信公众号 | 实时性强，话题传播速度快 |
| 消费决策、种草推荐、生活方式 | 小红书 | 抖音 | 种草生态成熟，用户主动搜索决策 |
| 视觉冲击、情感共鸣、年轻用户 | 抖音 | 小红书 | 短视频感染力，算法推荐破圈 |
| 品牌故事、深度教育 | 微信公众号 | 小红书 | 沉浸式阅读，建立深度信任 |
| 事件营销、话题引爆 | 微博 | 抖音 | 话题广场属性，适合快速引爆 |
| 产品评测、使用教程 | 小红书 | 抖音 | 图文+视频结合，决策参考价值高 |
| 娱乐化内容、病毒传播 | 抖音 | 微博 | 算法推荐机制，爆款潜力大 |

**路径1执行步骤：**
1. 根据匹配矩阵确定主力渠道（1-2个）
2. 深入研究该渠道的特性知识库（第四节）
3. 使用对应渠道的内容执行模板（第五节）
4. 制定传播策略（第六节）

### 路径2：定位模糊 → 多渠测试 → 数据收敛

当产品定位或目标用户尚不明确时，通过多渠道小规模测试获取数据，逐步收敛到最优渠道。

**测试方案设计原则：**
- **控制变量**：每次只测试一个变量（渠道/内容类型/发布时间）
- **最小可行测试**：每个渠道至少发布3-5条内容再做判断
- **统一评估标准**：所有渠道使用同一套评估指标体系
- **快速迭代**：测试周期建议2-4周，避免战线过长

**多渠测试流程：**
```
第1周：选择3个候选渠道，各发布3条不同类型内容
       ↓
第2周：分析数据，淘汰表现最差的1个渠道
       ↓
第3周：剩余2个渠道加大投入，测试不同内容形式
       ↓
第4周：数据收敛，确定1个主力渠道 + 1个辅助渠道
       ↓
转入路径1：按定位清晰模式深耕
```

**测试评估指标：**

| 指标维度 | 具体指标 | 权重 | 判断标准 |
|---------|---------|------|---------|
| 触达效率 | 曝光量/播放量 | 20% | 单位成本触达人数 |
| 内容吸引力 | 点击率/完播率 | 25% | 内容是否吸引人看下去 |
| 用户 engagement | 互动率（点赞+评论+收藏+转发） | 25% | 内容是否引发用户行动 |
| 转化效果 | 关注转化率/链接点击率 | 20% | 内容是否推动用户向下一步移动 |
| 内容生产效率 | 单条内容制作时间/成本 | 10% | 团队能否持续产出 |

## 四、渠道特性知识库

> 以下为四大渠道的内部知识库，供内容执行时快速查阅。每个渠道从五个维度描述：平台特性、内容形式、用户行为、算法逻辑、关键指标。

### 4.1 微信公众号

**平台特性：**
| 维度 | 特征 | 对内容策略的影响 |
|------|------|----------------|
| 私域流量 | 精准用户群体 / 高粘性互动 / 品牌化运营 | 保持稳定调性，建立品牌认知 |
| 深度阅读 | 完整阅读体验 / 沉浸式内容消费 | 内容结构层次分明，重视逻辑传递 |
| 规范体系 | 内容审核机制 / 发布流程标准 / 运营规则明确 | 符合平台规则，避免触碰敏感词 |
| 互动机制 | 评论与点赞 / 赞赏支持 / 转发分享 | 互动数据为内容优化提供反馈 |

**内容形式：**
- 长文（2000-5000字深度文章）
- 图文混排（重视排版美感）
- 系列专栏（建立内容体系）
- 短内容（公众号短文/图片消息）

**用户行为：**
- 订阅制阅读，粉丝关系链为核心分发路径
- 阅读场景：通勤/午休/晚间深度阅读
- 用户预期：获取深度信息、专业见解、实用方法
- 分享动机：内容代表个人品味/对他人有价值/情感共鸣

**算法逻辑：**
- 分发路径：粉丝订阅推送 → 社交分享传播 → 看一看推荐 → 搜一搜发现
- 关键信号：打开率、完读率、分享率、收藏率
- 推荐机制：基于社交关系链的二次传播权重高

**关键指标：**
| 指标 | 含义 | 健康范围 |
|------|------|---------|
| 打开率 | 阅读人数/粉丝数 | 1-5%（取决于粉丝基数） |
| 完读率 | 读完全文人数/阅读人数 | 20-40% |
| 分享率 | 分享人数/阅读人数 | 3-8% |
| 收藏率 | 收藏人数/阅读人数 | 1-5% |
| 净增关注 | 新增关注-取消关注 | 持续正增长 |

### 4.2 微博

**平台特性：**
| 维度 | 特征 | 对内容策略的影响 |
|------|------|----------------|
| 实时性 | 热点反应速度 / 时效性内容 | 快速响应能力，支持热点跟进与创作 |
| 社交属性 | 互动传播 / 意见引导 | 内容需具备较强互动性和对话感 |
| 话题引导 | 话题策略 / 议题设置 | 把握议题设置技巧，引导讨论方向 |
| 多媒体融合 | 图文设计 / 视频融合 | 协调处理文字、图片、视频等多种形式 |

**内容形式：**
- 短文案（140字以内核心信息前置）
- 图文微博（9宫格/长图）
- 话题微博（#话题#格式）
- 短视频（1-3分钟）
- 头条文章（长文，但传播力弱于短微博）

**用户行为：**
- 广场式浏览，信息流刷新速度快
- 阅读场景：碎片化时间、热点事件追踪
- 用户预期：快速获取信息、参与热点讨论、娱乐消遣
- 转发动机：表达立场/分享热点/参与话题

**算法逻辑：**
- 分发路径：粉丝关注流 → 热门话题广场 → 兴趣推荐 → 热搜榜单
- 关键信号：转评赞速度（前30分钟互动量）、话题参与度、热搜关联
- 推荐机制：时效性权重高，热点窗口期短（通常2-6小时）

**关键指标：**
| 指标 | 含义 | 健康范围 |
|------|------|---------|
| 互动率 | (转+评+赞)/曝光量 | 1-3% |
| 转发率 | 转发数/曝光量 | 0.5-2% |
| 话题阅读量 | 话题页累计阅读 | 取决于话题热度 |
| 粉丝增长 | 日均净增粉丝 | 持续正增长 |
| 热搜上榜 | 是否进入热搜榜 | 事件驱动，非日常指标 |

### 4.3 小红书

**平台特性：**
| 维度 | 特征 | 对内容策略的影响 |
|------|------|----------------|
| 种草生态 | 消费决策平台 / 真实分享 / 口碑传播 | 内容需注重实用性和真实感 |
| 社区氛围 | 用户生成内容 / 互助分享 / 生活指南 | 社区化表达，避免硬广感 |
| 垂直专业 | 细分领域深耕 / 专业知识 / 经验沉淀 | 垂直内容深度输出，建立专业信任 |

**内容形式：**
- 图文笔记（首图+多图+文案）
- 视频笔记（短视频种草）
- 合集/清单类内容
- 测评/对比类内容

**用户行为：**
- 主动搜索型用户占比高（"遇事不决小红书"）
- 阅读场景：消费决策前、生活方式参考、灵感收集
- 用户预期：获取真实使用体验、找到购买依据、学习生活方式
- 收藏动机：实用参考/购买决策依据/以后用得上

**算法逻辑：**
- 分发三层面：关注推荐流 / 兴趣标签推荐 / 搜索发现
- 推荐流：首图和标题决定点击率 → 内容质量决定互动率 → 互动数据反推更多曝光
- 搜索场景：关键词布局和专业信息完整性决定搜索排名
- 关键信号：点击率、互动率（收藏权重高）、完播率、搜索关键词匹配度

**关键指标：**
| 指标 | 含义 | 健康范围 |
|------|------|---------|
| 笔记点击率 | 点击数/曝光数 | 5-12% |
| 互动率 | (赞+藏+评+转)/曝光量 | 3-8% |
| 收藏率 | 收藏数/阅读量 | 5-15%（小红书特色高权重指标） |
| 搜索排名 | 关键词搜索结果排名 | 前10位有实际流量 |
| 涨粉率 | 新增关注/曝光量 | 1-3% |

### 4.4 抖音

**平台特性：**
| 维度 | 特征 | 对内容策略的影响 |
|------|------|----------------|
| 高度视觉化 | 短时吸引力 / 画面冲击力 | 突出场景描述和情绪表达 |
| 情绪饱满 | 娱乐性 / 情感张力 | 内容需富有感染力，情绪驱动 |
| 强互动性 | 挑战性 / 模仿传播 | 通过设问、挑战吸引用户参与 |
| 剧情故事性 | 叙事驱动 / 反转吸引 | 内容需有故事线和节奏感 |

**内容形式：**
- 短视频（15秒-3分钟，黄金时长60秒）
- 直播（实时互动、带货）
- 图文（抖音图文计划，流量扶持中）
- 合集/系列（建立内容体系）

**用户行为：**
- 沉浸式刷取，算法推荐主导
- 阅读场景：碎片化娱乐时间、睡前、通勤
- 用户预期：娱乐消遣、获取新知、情感共鸣、灵感激发
- 互动动机：被触动/想参与挑战/认同观点/被逗乐

**算法逻辑：**
- 分发路径：初始流量池（300-500播放）→ 数据达标进入更大流量池 → 逐级放大
- 流量池晋级机制：完播率 → 点赞率 → 评论率 → 转发率 → 关注转化率
- 关键信号：前3秒留存率（决定完播率）、互动率、关注转化率
- 推荐机制：内容标签匹配用户兴趣标签，去中心化分发

**关键指标：**
| 指标 | 含义 | 健康范围 |
|------|------|---------|
| 完播率 | 完整观看人数/播放人数 | 30-50%（短视频更高） |
| 点赞率 | 点赞数/播放量 | 3-5% |
| 评论率 | 评论数/播放量 | 0.5-1.5% |
| 转发率 | 转发数/播放量 | 0.5-2% |
| 关注转化率 | 新增关注/播放量 | 1-3% |
| 3秒留存率 | 观看超过3秒人数/总播放 | 60-80% |

## 五、内容执行模板

> 每个渠道的内容创作提示语模板。使用时先确定渠道，再选择对应模板，最后根据具体需求填充参数。
> 详细原始素材参见 `references/source-material.md`。

### 5.1 微信公众号内容模板

#### 选题规划模板
```
任务目标：生成[具体领域]的选题规划
背景信息：
- 账号定位：[填写定位]
- 目标读者：[读者画像]
- 核心诉求：[读者需求]
要求：
（1）生成10个选题方向
（2）每个选题包含：主标题 / 副标题 / 核心观点 / 价值主张
（3）考虑时效性与持久性的平衡
输出格式：表格呈现
```

#### 标题创作模板
```
请基于以下要素生成文章标题：
主题：[主题]
核心观点：[观点]
目标读者：[读者群体]
价值类型：分析型/方法型/经验型
表达基调：专业/犀利/温和
必要元素：数据点/行业洞察/专家引用
差异化要求：
- 竞品分析：[3-5个同主题标题]
- 创新角度：[具体说明]
生成要求：
- 提供3个方案
- 每个方案说明亮点
```

标题四原则：
1. 明确价值维度：指明文章提供的具体价值类型（解决方案/深度分析/经验分享）
2. 设定语气基调：严谨专业型/观点鲜明型/温和建议型
3. 限定结构要素：规定标题需包含的核心要素（热点词/数据点/专家观点）
4. 平衡吸引力与专业性：避免过于营销化或过于学术化

```

（1）开篇模块（800字以内）

（2）主体互动：每个论点后设置观点讨论区
（3）结尾互动：邀请读者分享经验与观点

- 开篇：以叙事为主，重在引发兴趣

- 重点论述段：250-300字
- 案例描述段：200-250字
- 数据分析段：150-200字
- 过渡段落：100字左右

（1）逻辑展开：论点之间递进/并列/转折关系明确

（3）风格把控：语言基调专业中立；专业术语解释到位
注意事项：1.避免观点过于绝对 2.确保数据来源可靠 3.案例选择需具有代表性 4.互动设计要自然融入文脉
```

- 基于战略输入，完成渠道选择和内容适配

## 质量评估标准

### 五维评估体系

| 维度 | 评估问题 | 达标标准 | 权重 |
|------|---------|---------|------|
| **渠道匹配度** | 渠道选择是否基于用户画像和目标？ | 能说出"选这个渠道是因为[具体理由]"而非"因为流行" | 25% |
| **内容适配度** | 内容是否符合渠道原生风格？ | 去掉品牌名后，看起来像该渠道的原生内容 | 25% |
| **战略一致性** | 内容是否服务于品牌定位和目标？ | 每条内容都能追溯到品牌定位中的某个要素 | 20% |
| **传播效率** | 单位投入的触达和互动是否达标？ | 达到渠道关键指标的健康范围 | 15% |
| **可持续性** | 内容生产节奏团队能否长期维持？ | 3个月内不会因产能不足而降质 | 15% |

### 评估检查清单
- [ ] 渠道选择有明确的用户数据或逻辑支撑
- [ ] 内容形式符合渠道原生风格（不是"一稿多发"）
- [ ] 核心信息与品牌定位一致
- [ ] 标题/封面针对渠道特性做了专门优化
- [ ] 互动设计自然融入内容，不生硬
- [ ] 发布节奏在团队产能范围内
- [ ] 数据反馈机制已建立，有明确的优化触发条件

## 常见陷阱

| 陷阱 | 症状 | 应对 |
|------|------|------|
| **全平台撒网** | "所有平台都要做" → 每个平台都浅尝辄止，资源分散 | 先聚焦1-2个主力渠道做到达标，再考虑扩展。用"如果只能选一个渠道，选哪个"强制聚焦 |
| **一稿多发** | 同一内容原封不动发所有平台 → 水土不服，数据差 | 核心信息一致，表达形式必须适配渠道。用"这条内容像不像这个平台的原生内容"检验 |
| **追平台不追用户** | "这个平台火所以要做" → 用户不在那里，流量再大也无效 | 先确认目标用户在哪个平台活跃，再决定渠道。用"你的用户每天花最多时间在哪个App"验证 |
| **只看曝光不看转化** | "阅读量/播放量很高" → 但没有带来关注/转化/留存 | 建立完整的指标链条：曝光→点击→互动→关注→转化。每个环节都有健康值参考 |
