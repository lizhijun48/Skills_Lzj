# 文案写作 (Copywriting)

面向产品经理/营销人员的结构化文案写作技能。遵循"诊断→选路→执行"模式，根据场景自动匹配最优模板。

## 核心原则

- **三要素平衡**：每篇文案都包含信息传递、情感共鸣、行动引导三个要素，只是比例因场景而异。
- **场景驱动模板**：不同场景需要不同的文案结构，先诊断场景再选模板，而非一个模板打天下。
- **语言风格可调**：通过调用语言风格三件套（RSM+EIS+RTA），同一模板可以呈现不同的语言调性。
- **可插拔调用**：本Skill作为独立单元，被营销策划、品牌定位等Skill调用时，调用方无需了解内部模板细节。

## 一、文案三要素模型

所有文案都由三个核心要素构成，不同场景的要素配比不同：

| 要素 | 定义 | 作用 | 核心问题 |
|------|------|------|---------|
| **信息传递** | 向读者传达产品/服务的关键信息 | 让读者"知道" | "读者需要知道什么才能做决策？" |
| **情感共鸣** | 触发读者的情感反应，建立心理连接 | 让读者"感受到" | "读者在什么情感状态下会行动？" |
| **行动引导** | 明确告诉读者下一步该做什么 | 让读者"行动" | "读者看完后应该做什么？" |

### 场景-要素配比矩阵

| 文案类型 | 信息传递 | 情感共鸣 | 行动引导 | 说明 |
|---------|---------|---------|---------|------|
| 产品说明文案 | ★★★★★ | ★★ | ★★★ | 信息为主，功能参数必须准确 |
| 品牌故事 | ★★ | ★★★★★ | ★ | 情感为主，建立品牌认同 |
| 广告语/Slogan | ★★ | ★★★★ | ★★★ | 短小精悍，情感+行动并重 |
| 社交媒体文案 | ★★★ | ★★★★ | ★★ | 情感驱动传播，信息嵌入其中 |
| 长文营销（软文） | ★★★★ | ★★★ | ★★★ | 三要素均衡，用内容建立信任 |
| 邮件营销 | ★★★ | ★★★ | ★★★★★ | 行动导向，转化率为第一目标 |

## 二、诊断式工作流

```
用户提出文案需求
       ↓
  ┌──────────────┐
  │ 诊断：什么场景？│ ← 通过2-3个问题确定文案类型
  └──────┬───────┘
         ↓
  ┌──────────────┐
  │ 选路：匹配模板 │ ← 根据场景选择对应文案模板
  └──────┬───────┘
         ↓
  ┌──────────────┐
  │ 定调：语言风格 │ ← 调用RSM+EIS+RTA确定语言调性
  └──────┬───────┘
         ↓
  ┌──────────────┐
  │ 执行：撰写文案 │ ← 按模板结构生成文案
  └──────┬───────┘
         ↓
  ┌──────────────┐
  │ 检验：三要素检查│ ← 检查三要素是否齐全、配比是否合理
  └──────────────┘
```

### 诊断引导问题

当用户提出文案需求时，通过以下问题确定场景：

| 诊断问题 | 答案指向 | 对应模板 |
|---------|---------|---------|
| "这篇文案用在哪里？" | 渠道/平台 | 初步判断文案类型 |
| "核心目标是什么？" | 信息传达/情感连接/转化行动 | 确定三要素配比 |
| "目标受众是谁？" | 用户画像 | 调整语言风格和内容深度 |

**快速选路规则**：
- 用在哪里 + 核心目标 → 确定文案类型（对照场景-要素配比矩阵）
- 文案类型 → 自动匹配对应模板（见第三节）

## 三、六大文案模板

### 模板1：产品说明文案

适用场景：产品详情页、功能介绍、产品手册

```
结构：
1. 一句话价值主张（这个产品解决什么问题）
2. 核心痛点（用户当前面临什么困扰）
3. 解决方案（产品如何解决——3个核心功能点）
4. 功能细节（每个功能的具体说明+数据支撑）
5. 社会证明（用户评价/数据/认证）
6. 行动号召（下一步操作）

三要素配比：信息★★★★★ 情感★★ 行动★★★
```

### 模板2：品牌故事

适用场景：品牌官网"关于我们"、品牌手册、融资BP

```
结构：
1. 起源故事（为什么创立——创始人的个人经历/洞察）
2. 核心冲突（发现了什么别人没看到的问题/矛盾）
3. 使命宣言（我们要解决什么问题/创造什么价值）
4. 关键转折（从0到1的关键节点/里程碑）
5. 未来愿景（我们要去哪里/成为什么）
6. 情感锚点（一句浓缩品牌精神的话）

三要素配比：信息★★ 情感★★★★★ 行动★
```

> 品牌故事的战略输入：如需品牌定位/价值主张/未来愿景的战略层级支撑，调用 `brand-positioning`、`value-proposition`、`future-vision` 技能获取对应层级的内容。

### 模板3：广告语/Slogan

适用场景：产品Slogan、广告标题、活动标语

```
结构：
1. 核心信息提炼（一句话说清"你是谁/你能做什么"）
2. 情感触发词（选择一个情感锚点：信任/自由/力量/温暖/创新）
3. 修辞加工（运用比喻/对比/排比/押韵等手法）
4. 简洁度检验（能否在5秒内记住？）

好Slogan的检查标准：
- 记得住：5秒内能复述
- 分得清：换成竞品名字就不成立
- 有感觉：读完有情感反应

三要素配比：信息★★ 情感★★★★ 行动★★★
```

### 模板4：社交媒体文案

适用场景：微信朋友圈、微博、小红书、抖音文案

```
结构：
1. 钩子开头（前3秒/前2行抓住注意力——用提问/冲突/悬念/数据）
2. 故事/场景（用一个具体场景让读者代入）
3. 价值输出（传递核心信息——嵌入而非堆砌）
4. 互动引导（引导评论/转发/收藏——提问/投票/挑战）

平台适配：
- 朋友圈：个人化+真实感，200字以内
- 微博：话题化+传播性，140字以内（核心信息前置）
- 小红书：种草感+实用性，标题党+干货
- 抖音：视觉化+节奏感，配合画面节奏

三要素配比：信息★★★ 情感★★★★ 行动★★
```

### 模板5：长文营销（软文）

适用场景：公众号文章、知乎回答、行业报告引言

```
结构（用AIDA框架）：
1. Attention（注意力）：用故事/数据/问题开场，制造阅读动力
2. Interest（兴趣）：展开问题/痛点分析，让读者产生"这说的就是我"的感觉
3. Desire（欲望）：引入解决方案，用案例/数据证明效果
4. Action（行动）：明确的行动号召+限时/限量等紧迫感

写作要点：
- 标题决定80%的阅读量——用数字/疑问/对比/悬念
- 前3段决定读者是否继续——快速建立"和我有关"的感觉
- 信息嵌入而非堆砌——让产品信息成为故事的一部分

三要素配比：信息★★★★ 情感★★★ 行动★★★
```

### 模板6：邮件营销

适用场景：产品推广邮件、用户激活邮件、会员营销

```
结构：
1. 主题行（决定打开率——个性化+好奇心+紧迫感）
2. 开头（1-2句话说明"这封邮件对你有什么用"）
3. 核心价值（1个核心卖点+1个证据/案例）
4. 行动号召（1个明确的CTA按钮/链接，不要多个）
5. 补充信息（FAQ/社会证明/退订选项）

优化要点：
- 主题行A/B测试：准备2-3个版本，选择打开率最高的
- CTA按钮用动词开头："立即领取""免费试用""马上加入"
- 移动端优先：60%以上用户在手机上阅读

三要素配比：信息★★★ 情感★★★ 行动★★★★★
```

## 四、语言风格调用

文案的语言风格通过调用 `creative-prompt-techniques` 技能中的"语言风格优化三件套"实现：

| 调用层 | 对应框架 | 在文案中的作用 |
|-------|---------|-------------|
| 语体层 | RSM（语体模拟） | 确定文案的整体调性——专业/亲切/幽默/权威 |
| 情感层 | EIS（情感融入） | 设计文案的情感节奏——开头共鸣→中间理性→结尾行动 |
| 修辞层 | RTA（修辞技巧） | 选择文案的修辞手法——比喻/对比/排比/反问 |

**调用方式**：在选定文案模板后，根据目标受众和渠道特征，用RSM确定语体、EIS设计情感节奏、RTA选择修辞手法，然后按模板结构执行写作。

## 五、文案质量评估清单

### 三要素检查
- [ ] **信息传递**：核心信息是否清晰？读者看完能回答"这个产品/服务是什么"吗？
- [ ] **情感共鸣**：是否有情感触发点？读者读完有感觉吗？是什么感觉？
- [ ] **行动引导**：读者看完知道下一步该做什么吗？CTA是否明确？

### 基础质量检查
- [ ] **目标受众**：文案的语气和内容深度是否匹配目标受众？
- [ ] **渠道适配**：文案长度和格式是否适合发布渠道？
- [ ] **差异化**：把品牌名遮住，这篇文案还能区分出是谁的吗？
- [ ] **真实性**：文案中的承诺是否都能兑现？有无夸大或虚假？
- [ ] **简洁度**：有没有可以删掉但不影响表达的废话？

### 高级检查（可选）
- [ ] **钩子强度**：前3秒/前2行是否足够吸引人继续看下去？
- [ ] **社会证明**：是否有数据/案例/评价支撑核心主张？
- [ ] **紧迫感**：是否有"现在就行动"的理由？

## 使用建议

1. **独立使用**：直接按"诊断→选路→执行"流程撰写文案。
2. **被其他Skill调用**：营销策划Skill在需要撰写推广文案时调用本Skill，品牌定位Skill在需要撰写品牌故事时调用本Skill——调用方传入场景参数（文案类型+目标受众+核心信息），本Skill返回成品文案。
3. **优化已有文案**：用"文案质量评估清单"诊断现有文案的薄弱环节，针对性修改。
4. **与语言风格联动**：需要特定调性时，先调用语言风格三件套（RSM+EIS+RTA）确定风格参数，再按模板执行。
