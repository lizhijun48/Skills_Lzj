# AI 腔词表与替换建议库

> 供 `general-suite/expression-purifier`（S-070）Step 2 第 1 遍扫描使用。
> **使用前提**：词表是"嫌疑清单"不是"删除清单"。命中后先判断该词是否承载实义——承载则保留（记入"保留说明"），纯形式则替换。

---

## 一、空泛动词与黑话名词

AI 高频、但多数情况下可被具体动作替换的词。

| 词 | 典型症状 | 替换为 |
|----|----------|--------|
| 赋能 | "为业务赋能"（没说怎么赋能） | 直接写具体动作：提升 XX 效率 / 减少 XX 环节 |
| 抓手 | "找到抓手" | 切入点 / 具体措施 |
| 闭环 | "形成闭环" | 说明从 A 到 B 的完整流程，或删 |
| 对齐 / 拉通 | "对齐目标" | 统一口径 / 确认一致 / 明确为 |
| 沉淀 | "沉淀方法论" | 总结 / 整理成 / 归档 |
| 落地 | "推动落地" | 实施 / 上线 / 执行 |
| 打通 | "打通数据" | 接入 / 联通 / 实现 XX 到 XX 的传输 |
| 升维 / 降维 | "升维思考" | 换个角度看 / 从 XX 层面看 |
| 击穿 | "击穿痛点" | 解决 / 消除 |
| 颗粒度 | "细化颗粒度" | 细化到 XX 级 / 拆到 XX 项 |
| 心智 | "占据用户心智" | 让用户记住 / 建立认知 |
| 生态 | "构建生态"（多数时候无实指） | 说明具体参与方，或删 |
| 护城河 | "形成护城河" | 说明具体壁垒是什么 |
| 组合拳 | "打出组合拳" | 列出具体是哪几项措施 |
| 打法 / 阵型 / 阵地 / 赛道 / 链路 | 军事/竞技隐喻，正式文体不适用 | 直接写本义 |
| 深度 | "深度融合/深度分析" | 删"深度"，或说明深到什么程度 |
| 全方位 / 多维度 / 立体化 | "全方位提升" | 列出到底是哪几个方位/维度 |
| 迭代 | "持续迭代"（无版本号无内容） | 说明改了什么 |
| 转型 / 升级 | "数字化转型" | 说明转成什么样 |

> 判定口诀：**这个词删掉后，句子信息量变少了吗？** 没变少 → 纯套路，删。

## 二、程度副词与强调套话

| 类型 | 典型词 | 处置 |
|------|--------|------|
| 程度泛滥 | 极大地、显著地、全面、充分、切实、扎实、积极、有效、不断、持续、进一步、稳步、大力 | 多数可删。若确需强调，换成**具体幅度**（提升 30%、缩短 2 天） |
| 元叙述 | 本文将、本文旨在、以下内容将、接下来我们来看、让我们、我们先看 | **必删**。读者知道你在写什么，不需要预告 |
| 推论口癖 | 值得注意的是、需要注意的是、不难发现、由此可见、综上所述、总而言之、换句话说、更重要的是、事实上、本质上、从根本上说、从某种意义上 | **必删或降级为必改**。直接陈述结论，不要铺垫 |
| 结构口癖 | 首先/其次/再次/最后（三者以上连用）、一方面…另一方面…、不仅…而且…、与此同时、在此基础上 | 少量无妨；**三处以上连用必改**，改为自然过渡或直接分段 |
| 模糊限定 | 某种、一定的、相关、若干、各种、一定程度上 | 换成具体数量或具体对象 |

## 三、内部策略词（正式对外文档零容忍）

来自 `pm-suite/pm-bid-proposal` 的合规红线，扩展为通用版——**内部思考过程不得出现在对外文档中**。

| 类别 | 禁用词 | 原因 |
|------|--------|------|
| 自评打分 | 匹配度 XX%、综合评分 XX 分、达标率、我方得分 | 自说自话，无公信力；正式场合可能被视为虚假响应 |
| 概率判断 | 中标概率、成功可能性、预计可拿下、胜算 | 暴露内部盘算，商务与合规风险 |
| 评分策略 | 高分响应、满分策略、必得满分、得分点、踩分、拿分项 | 暴露应对评分规则的策略，性质等同串通 |
| 竞品比较 | 相比对手、我方优势明显、对手较弱、业内领先 | 不正当竞争风险 |
| AI 标注 | 由 AI 生成、AI 辅助撰写、本方案由模型输出、以下是 AI 的建议 | 被视为非人工撰写，不符合多数正式文件要求 |
| 内部流程词 | 内部参考、草稿、待确认、占位、TODO、样例、模板残留 | 说明稿件未定稿 |

> 完整「不要写/应该写」对照另见 `pm-suite/pm-bid-proposal/references/forbidden_content.md`（招投标场景专用）。

## 四、夸张词

| 词 | 问题 | 替换为 |
|----|------|--------|
| 毫无疑问、绝对、100%、必定 | 违反可证伪性，正式文档禁用 | 删，或用数据支撑 |
| 最（最好/最先进/最强） | 绝对化用语，广告法与招投标均敏感 | 说明比较范围：在 XX 范围内 / 同类产品中 |
| 顶级、一流、卓越、完美、无懈可击 | 无法验证 | 换成可验证描述 |
| 革命性、颠覆性、前所未有、划时代 | 夸大 | 说明具体变化 |
| 彻底解决、完全消除、根治 | 过度承诺，易成验收争议 | 降低 XX% / 减少至 XX 以内 |
| 领先、首创、唯一 | 需证据，无证据即虚假宣传 | 给出依据或删除 |

## 五、机械句式（非词表，需句式扫描）

| 句式 | 症状 | 处置 |
|------|------|------|
| 排比三连 | "是 A，是 B，是 C" 连用三段 | 保留一段，其余改为具体说明 |
| "不是…而是…" | 对仗滥用，处处辩证 | 直接写肯定句 |
| 设问自答 | "那么如何做到呢？" 后自答 | 删设问，直接答 |
| 每段总起句 | 每段开头都是一句概括，后面三点并列 | 打散，允许有的段直接展开 |
| 每段总结句 | 每段末尾都回扣主题 | 只保留必要的段落，其余删 |
| 解释性插入 | 破折号/冒号后接补充说明，一段出现 2 次以上 | 合并进主句或另起一句 |
| 长定语句 | 一句超过 60 字仍不断句 | 拆分 |
| 结尾升华段 | "未来，我们将继续…" | 删（除非确有承诺内容） |

## 六、结构痕迹

| 痕迹 | 症状 | 处置 |
|------|------|------|
| 对称小标题 | 各标题字数、词性、结构完全一致 | 允许长短不一，按内容需要起名 |
| 段落等长 | 各段字数高度接近（标准差极低） | 打散，重要处多写，次要处一笔带过 |
| 项目符号泛滥 | 通篇列表，无成段叙述 | 列表与段落交替 |
| 图标/符号作前缀 | 每个条目前加统一符号 | 正式文档去符号 |
| 加粗泛滥 | 一段内多处加粗 | 只保留真正的关键处 |
| 三层以上嵌套 | 1.1.1.1 层级过深 | 压到两层 |

## 七、低信息密度（"正确的废话"）判定

满足以下任一条即标记为低密度段落：

- 全段无**具体数字**
- 全段无**专有名词**（人名、产品名、地名、标准号、条款号）
- 全段无**时间锚点**（日期、周期、频次）
- 全段无**因果关系**，只有并列与断言
- 抽掉主语后仍成立（说明没写清是谁做的）

**处置**：补具体信息，或整段删除（若确实无话可说，宁删勿凑）。

**参考阈值**：含数字句子占比建议 ≥20%（技术/商务文档），低于此值需重点复查。

## 八、替换建议库（速查）

| 不要写 | 应该写 |
|--------|--------|
| 本文将详细介绍 XX | （直接开始介绍） |
| 值得注意的是，XX 很重要 | XX 直接决定了 YY（说清影响什么） |
| 我们需要高度重视 XX | 需在第 X 阶段前完成 XX |
| 通过多种手段全方位提升 | 通过 A、B、C 三项措施，将 XX 从 60% 提升至 85% |
| 形成完整闭环 | 从申请、审批到归档共 X 个环节，全程留痕 |
| 综上所述，XX 具有重要意义 | XX 可带来 YY 收益（量化），代价是 ZZ |
| 不断优化，持续改进 | 每两周复盘一次，按复盘结论调整 |
| 深度融合 AI 技术 | 在 XX 环节接入 XX 模型，替代原有人工 XX 步骤 |
| 未来我们将继续深耕 | （删） |
