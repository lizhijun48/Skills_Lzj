# 保险精算与综合规划方法论

---

## Part A: 保险内在价值分析框架

### A.1 保险的三重价值

保险不是"花钱买概率"，而是三重价值的复合体：

| 价值维度 | 定义 | 衡量指标 | 决策权重 |
|----------|------|----------|----------|
| **风险转移价值** | 将个人不可承受的低频高损风险转移给保险公司 | EPV（期望现值） | 核心 |
| **强制储蓄价值** | 寿险/两全险的现金价值复利积累（2.5-3.5% 保证利率） | 105 岁 FV vs 外部投资 FV | 重要 |
| **心理安宁价值** | 免除"出险后家庭崩溃"的焦虑 | 无量化指标，情境分析辅助 | 辅助 |

> 决策准则：当风险转移价值 + 强制储蓄价值 + 心理安宁价值 > 已缴保费成本时，保单有正价值。
> 定量分析可覆盖前二者，心理安宁价值通过情境压力测试定性评估。

### A.2 风险转移价值的定量计算

```
风险转移 EPV = Σ(事件概率_t × 赔付金额_t × 折现因子_t)
```

其中事件概率来源于：
- **死亡概率**：CL1/CLT 生命表（见 actuarial_data.md §6）
- **CI 概率**：NCI 年龄分层发病率（见 actuarial_data.md §7）
- **意外概率**：行业理赔经验数据
- **折现因子**：1/(1+d)^t，d 为资本机会成本

### A.3 医疗通胀对保额的侵蚀

见 actuarial_data.md §10 的保额购买力衰减表。核心含义：

> 一张今天 ¥30 万的 CI 保额，按 6-8% 医疗通胀，20 年后实际购买力仅相当于 ¥6-10 万。
> CI 保额不足的保单，RPU 保留的"名义保额"的实质价值随时间急剧衰减。
> **决策含义**：高保费低保额的 CI 保单，长期持有价值有限。

## Part B: 核心精算方法

### B.1 期望现值 (EPV)

```
EPV = Σ(死亡概率_t × 赔付金额_t × 折现因子_t) for t in [当前年龄, 105 岁]
```

折现因子：1/(1+d)^t

**关键陷阱**：EPV 必须计算终身（到 105 岁），不得截断到保单缴费期。RPU 后保障是终身的。

### B.2 折现率 d 与市场利率

折现率 = 机会成本 = 放弃的无风险收益。**与市场利率同向运动**：
- 利率下降 → d 下降 → 未来现金流现值上升 → 终身保障的"现在价值"更高
- 利率上升 → d 上升 → 未来现金流现值下降

对保单分析：折现率越低，终身保障价值越高，RPU 越有利。

### B.3 退保 vs RPU 决策框架

```
退保方案终值：CV × (1+r)^n + Σ(年保费 × (1+r)^(n-t))
RPU 方案终值：EPV(d) × (1+d)^n + 残值 + Σ(年保费 × (1+r)^(n-t))

核心差异 = CV×(1+r)^n - 残值 - EPV(d)×(1+d)^n
  正值 → 退保有利
  负值 → RPU 有利
```

### B.4 利率路径概率加权

```
概率加权净优势 = Σ(路径概率_i × 净差_i)
```

| 净优势范围 | 结论 |
|------------|------|
| < -2,000 | RPU |
| -2,000 ~ +2,000 | 临界，需综合判断 |
| > +2,000 | 退保 |

### B.5 国际利率比较

| 经济体 | 路径 | 关键特征 |
|--------|------|----------|
| 日本 | 3% → <1%（17 年） | 深度老龄化 + 通缩 |
| 中国台湾 | → 1%（7 年） | 科技泡沫后快速降息 |
| 韩国 | 急降后回升至 2% | 金融危机后未持续走低 |

中国当前与日本/台湾相似的十字路口。10Y 国债从 3% → 1.73%，指向更低利率环境。

## Part C: 综合家庭保单规划框架

### C.1 投保人画像分析

对每张保单的投保人/被保人，构建画像矩阵：

| 维度 | 分析要素 | 影响决策 |
|------|----------|----------|
| 年龄 | 当前年龄 vs 退休年龄 vs 预期寿命 | EPV 参数、保障需求时段 |
| 健康状况 | 已知病史、体检异常项 | 核保通过性（替代产品可行性） |
| 收入/职业 | 当前收入、行业前景、稳定度 | 保费负担能力、失业风险 |
| 家庭角色 | 主要经济支柱 / 次要支柱 / 非支柱 | 保障优先级排序 |
| 婚姻状况 | 已婚 / 离异 | 受益人风险、投保人变更需求 |

### C.2 经济状态压力矩阵

| 经济状态 | 保费负担率 | 应对策略 |
|----------|------------|----------|
| 正常就业、双职工 | <10% 可承受 | 正常续缴或优化配置 |
| 正常就业、单职工 | <8% 可承受 | 警惕保费负担率上升 |
| **失业中** | 任何保费均构成压力 | 立即最小化现金流支出 |
| 失业中 + 有积蓄 | <3% 可维持 | 暂时维持核心保障，其余 RPU |
| 失业中 + 耗积蓄 | **0% 目标** | 所有可 RPU 保单立即 RPU |
| 长期失业（>6 月） | 需动用保险 CV | 优先级：RPU > 退保（避免亏损） |

### C.3 保单组合优化约束

```
优化目标：最小化年度现金流支出
约束条件：
  1. 每人最低 CI 保额 ≥ ¥300,000（基础刚需）
  2. 每人最低寿险保额 ≥ ¥100,000（最终费用覆盖）
  3. RPU 后保障不能出现空白（无任何 CI 或寿险覆盖的被保人）
  4. 未成年人的保障不能劣化（父母对其有法定抚养义务）
  5. 离婚保单必须解决受益人风险（不解决 = 废物保单）
```

### C.4 多保单协同决策

```
步骤：
1. 按被保人分组所有保单
2. 逐一分析每张保单的独立最优策略
3. 交叉检查：RPU 某保单后，剩余保单是否仍满足约束条件
4. 识别重叠保障：同类型/同被保人的多张保单，保留最优
5. 计算组合现金流：不同决策组合下的年保费时间轴
```

## Part D: 特殊场景压力测试

### D.1 离婚保单分析

当投保人与被保人存在离婚关系：

**风险清单：**
1. **受益人控制权风险**：投保人可单方面变更受益人 → 离婚后原配偶可能将受益人改为自己或他人
2. **道德风险**：继续缴费但无法确保赔付流向 → "给别人的保单打工"
3. **财产分割风险**：当前 CV 属投保人财产权益，离婚协议需明确归属

**处置路径（优先级从高到低）：**

```
第一优先：变更投保人为原配偶本人（30 天内）
  ↓ 不配合
降级方案：退保（拿回 CV，即时止损）
  ↓ 愿意接手
最佳结果：原配偶成为新投保人，自行缴费
          投保人彻底退出，释放年度现金流
```

**离婚协议建议条款：**
> "双方确认，以甲方为投保人、乙方为被保险人的 XX 保险合同（合同号：XXX），自本协议签署之日起 30 日内，双方配合办理投保人变更为乙方的手续。变更完成后，甲方不再承担保费缴纳义务。如乙方未在约定期限内配合，甲方有权自行退保，退保所得现金价值归甲方所有。"

### D.2 失业保单分析

**压力层级：**

| 层级 | 触发条件 | 动作 |
|------|----------|------|
| 黄色 | 预计失业 <3 个月，有积蓄 | 暂停非核心保单缴费（利用宽限期），核心保单维持 |
| 橙色 | 失业 3-6 个月，积蓄消耗中 | 所有可 RPU 保单立即办理 RPU；不可 RPU 的评估退保 |
| 红色 | 失业 >6 个月，积蓄耗尽 | RPU 全部可 RPU 保单；不可 RPU 的退保止损；惠民保补位 |

**关键原则**：失业状态下，每 ¥1 保费的机会成本急剧上升。现金优先于保障增量。

### D.3 医疗紧急情况压力测试

假设家中一人罹患重疾（保额内）：

```
家庭财务冲击链：
  医疗费用（医保报销后自付部分）→ 收入中断（陪护/康复）→ 储蓄消耗 → 其他保费断缴风险

现有保单压力测试：
  - CI 保额能否覆盖自付医疗 + 2 年收入损失？
  - 出险后其他家庭成员的保单能否继续缴费？
  - 豁免险是否覆盖全部保单？
```

## Part E: 参数体系

| 参数 | 默认值 | 说明 |
|------|--------|------|
| discount_rate (d) | 2.0% | 折现率 = 10Y 国债 + 风险溢价 |
| invest_return (r) | 3.0% | 外部投资回报率（实际可达成） |
| policy_guaranteed_rate | 2.5% | RPU 后 CV 复利增长率 |
| MAX_AGE | 105 | 生命表终点 |
| mort_adj | 0.80 | 死亡率调整（CL1 → CLT2025） |
| medical_inflation | 7.0% | 医疗费用年均增速假设 |
| ci_target_multiple | 3-5× | 目标 CI 保额 = 年收入倍数 |
