## ITTO 合约

### Input（输入）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `initial_investment` | Number | ✅ | 初始投资（C_0），单位：万元 |
| `cash_flows` | Array | ✅ | 运营期现金流数组（每年净现金流） |
| `discount_rate` | Number | ✅ | 折现率（i），如：0.10 表示 10% |
| `salvage_value` | Number | ⭕ | 残值（S_v），默认 0 |
| `periods` | Number | ✅ | 项目周期（年） |

**输入示例**：
```json
{
  "initial_investment": 100,
  "cash_flows": [30, 35, 40, 45, 50],
  "discount_rate": 0.10,
  "salvage_value": 20,
  "periods": 5
}
```

---

### Tools（工具与方法）

1. **现值计算公式**：
   $$
   NPV = -C_0 + \sum_{t=1}^{n} \frac{CF_t}{(1+i)^t} + \frac{S_v}{(1+i)^n}
$$

2. **判定标准**：
   - NPV > 0：项目可行（创造超额价值）
   - NPV = 0：项目持平（刚好覆盖资金成本）
   - NPV < 0：项目不可行（毁灭价值）

3. **敏感性测试**：
   - 对折现率 ±20% 测试，观察 NPV 是否转负

---

### Techniques（技巧与注意事项）

1. **现金流时点**：
   - 明确现金流发生在**年初**还是**年末**
   - 默认假设：初始投资在 t=0（年初），运营现金流在每年年末

2. **折现率选择**：
   - 使用公司**加权平均资本成本（WACC）**或**基准收益率**
   - 禁止使用银行贷款利率（偏低）

3. **增量分析**：
   - 改扩建项目：必须计算**增量 NPV**（有项目 - 无项目）
   - 严禁使用总量 NPV 决策改扩建项目

## 执行流程

### Step 1：输入验证
1. 检查必填参数是否齐全
2. 校验现金流数组长度 = 项目周期
3. 提醒用户确认：现金流时点（年初/年末）、折现率来源

### Step 2：计算 NPV
1. 使用现值公式计算各期现值
2. 加总得到 NPV
3. 计算盈亏平衡折现率（使 NPV=0 的折现率）

### Step 3：敏感性测试
1. 对折现率 ±20% 测试
2. 识别最敏感变量（若有其他变量，如：收入、成本）

### Step 4：输出报告
1. 按标准格式输出
2. 给出明确决策建议
3. 标注风险提示（若敏感性高）

---

## 边界与异常处理

### 边界1：改扩建项目
- **问题**：用户直接给出"改造后"的总现金流
- **处理**：
  1. 询问："这是总量现金流还是增量现金流？"
  2. 若总量：要求提供"无项目"现金流，计算增量
  3. 使用增量现金流计算 NPV

### 边界2：折现率缺失
- **问题**：用户未提供折现率
- **处理**：
  1. 询问公司基准收益率
  2. 若无法获取：使用行业平均值（如：互联网 10%、制造业 8%）
  3. 明确标注："使用行业基准，建议补充公司实际 WACC"

### 边界3：现金流不确定
- **问题**：用户给出的是估算值
- **处理**：
  1. 要求给出**乐观/中性/悲观**三种情景
  2. 分别计算 NPV
  3. 输出**NPV 分布区间**

## 调用示例

### 示例1：新项目立项
**用户提问**：
> "我有个新项目，初始投资 100 万，预计未来 5 年每年现金流分别是 30、35、40、45、50 万，折现率 10%，残值 20 万。帮我算一下 NPV。"

**技能调用**：
```
调用 @economic-npv
输入：
  - initial_investment: 100
  - cash_flows: [30, 35, 40, 45, 50]
  - discount_rate: 0.10
  - salvague_value: 20
  - periods: 5
```

**输出**：
```markdown

### 1. 核心指标
- **NPV（净现值）**：37.24 万元
- **判定结论**：✅ 可行（NPV > 0）
- **盈亏平衡点**：折现率需达到 15.3% 时，NPV 归零

### 2. 计算过程
| 年份 | 现金流（万元） | 折现因子 (i=10%) | 现值（万元） |
|------|----------------|-------------------|-------------|
| t=0 | -100           | 1.000             | -100.00     |
| t=1 | 30             | 0.909             | 27.27       |
| t=2 | 35             | 0.826             | 28.91       |
| t=3 | 40             | 0.751             | 30.04       |
| t=4 | 45             | 0.683             | 30.74       |
| t=5 | 70（50+20残值）| 0.621             | 43.47       |
| **合计** | -           | -                 | **37.24**   |

### 3. 敏感性分析
| 折现率 | NPV（万元） | 结论 |
|---------|-------------|------|
| 8%      | 47.89       | 可行 |
| 10%     | 37.24       | 可行 |
| 12%     | 27.56       | 可行 |
| 15%     | 12.45       | 临界 |
| 18%     | -1.23       | 不可行 |

### 4. 决策建议
- ✅ 项目可行，NPV = 37.24 万元 > 0
- ⚠️ 对折现率敏感，若融资成本超过 15%，项目不可行
- 建议：在立项报告中明确标注"融资成本上限 15%"
```
