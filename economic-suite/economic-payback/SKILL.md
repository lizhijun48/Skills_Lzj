## ITTO 合约

### Input（输入）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `initial_investment` | Number | ✅ | 初始投资（C_0），单位：万元 |
| `annual_cash_flows` | Array | ✅ | 年净现金流数组 |
| `salvage_value` | Number | ❌ | 残值（S_v），默认 0 |
| `discount_rate` | Number | ❌ | 折现率（i），若有则计算动态回收期 |

**输入示例**：
```json
{
  "initial_investment": 100,
  "annual_cash_flows": [30, 35, 40, 45, 50],
  "salvage_value": 20,
  "discount_rate": 0.10
}
```

---

### Tools（工具与方法）

1. **静态回收期**：
   $$
   \text{回收期} = \text{累计现金流由负转正的年份} - 1 + \frac{\text{上年累计未回收}}{\text{当年现金流}}
$$
   - 不考虑资金时间价值
   - 适用于快速评估

2. **动态回收期**：
   - 使用折现后现金流
   - 考虑资金时间价值
   - 更准确但计算复杂

3. **判定标准**：
   - 回收期 < 行业基准：可行
   - 回收期 ≥ 项目寿命：不可行（永远回不了本）

---

### Techniques（技巧与注意事项）

1. **与NPV结合**：
   - 回收期短但NPV < 0：❌ 不可行（如：短期回本但长期亏损）
   - 回收期长但NPV > 0：✅ 可行（如：前期投入大，但长期收益高）

2. **风险指示**：
   - 回收期越长，不确定性越高（风险越大）
   - 建议：回收期 > 项目寿命50% 时，需额外风险对冲

3. **与IRR区别**：
   - 回收期：关注**回本速度**
   - IRR：关注**整体回报率**

### Output（输出）

**标准输出格式**：

```markdown
## 投资回收期计算结果

### 1. 核心指标
- **静态回收期**：X.X 年
- **动态回收期**：X.X 年（折现率 i = XX%）
- **判定结论**：✅ 可行 / ❌ 不可行
- **行业基准**：XX 年

### 2. 累计现金流表
| 年份 | 年现金流（万元） | 累计现金流（万元） | 折现后现金流（万元） | 折现后累计（万元） |
|------|-----------------|-------------------|-------------------|-------------------|
| t=0 | -100           | -100              | -100              | -100              |
| t=1 | 30              | -70               | 27.27             | -72.73            |
| t=2 | 35              | -35               | 28.91             | -43.82            |
| t=3 | 40              | +5 ✅              | 30.04             | -13.78            |
| ...  | ...             | ...                | ...                | ...                |

- **静态回收期**：2 + 35/40 = **2.875 年**
- **动态回收期**：3 + 13.78/30.04 = **3.459 年**

### 3. 风险评估
- 回收期占项目寿命比：3.5年 / 5年 = **70%**
- ⚠️ 风险偏高（建议 ≤50%）

### 4. 决策建议
- 若行业基准回收期 < 2.875年：❌ 不可行
- 若行业基准回收期 ≥ 3年：✅ 可行，但需关注前期现金流
```

## 执行流程

### Step 1：输入验证
1. 检查年现金流数据是否完整
2. 确认是否计算动态回收期（需折现率）

### Step 2：计算回收期
1. 计算累计现金流
2. 找到由负转正的年份
3. 线性插值计算精确回收期

### Step 3：风险评估
1. 计算回收期占项目寿命比
2. 对标行业基准

### Step 4：输出报告
1. 按标准格式输出
2. 给出明确决策建议
3. 标注风险（若回收期过长）

---

## 边界与异常处理

### 边界1：永远回不了本
- **问题**：累计现金流始终为负
- **处理**：
  1. 输出："回收期 > 项目寿命，不可行"
  2. 建议：重新评估项目可行性（或砍投资规模）

### 边界2：折现率缺失
- **问题**：用户未提供折现率，但要求计算动态回收期
- **处理**：
  1. 使用静态回收期
  2. 标注："建议补充折现率，计算动态回收期"

## 调用示例

### 示例1：快速评估项目回本速度
**用户提问**：
> "我投100万，未来5年现金流分别是30、35、40、45、50万，多久回本？"

**技能调用**：
```
调用 @economic-payback
输入：
  - initial_investment: 100
  - annual_cash_flows: [30, 35, 40, 45, 50]
```

**输出**：
```markdown
## 投资回收期计算结果

### 1. 核心指标
- **静态回收期**：2.875 年
- **判定结论**：✅ 可行（假设行业基准 3 年）

### 2. 累计现金流表
| 年份 | 年现金流（万元） | 累计现金流（万元） |
|------|-----------------|-------------------|
| t=0 | -100           | -100              |
| t=1 | 30              | -70               |
| t=2 | 35              | -35               |
| t=3 | 40              | +5 ✅              |

- **静态回收期**：2 + 35/40 = **2.875 年**

### 3. 决策建议
- ✅ 回收期 2.875年 < 行业基准 3年，可行
- ⚠️ 但需关注：第3年才能回本，前期现金流压力大
```
