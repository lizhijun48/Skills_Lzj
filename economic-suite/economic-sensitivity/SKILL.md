## ITTO 合约

### Input（输入）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `base_case` | Object | ✅ | 基准情景（各变量值 + NPV） |
| `variables` | Array | ✅ | 待测试变量列表（如：价格、成本、销量） |
| `sensitivity_range` | Number | ⭕ | 波动范围（默认 ±20%） |
| `target_metric` | String | ⭕ | 测试指标（默认 NPV，可选 IRR） |

**输入示例**：
```json
{
  "base_case": {
    "price": 100,
    "cost": 60,
    "volume": 10000,
    "NPV": 37.24
  },
  "variables": ["price", "cost", "volume"],
  "sensitivity_range": 0.20,
  "target_metric": "NPV"
}
```

---

### Tools（工具与方法）

1. **单变量敏感性分析**：
   - 保持其他变量不变，单变量 ±X% 波动
   - 计算目标指标变化率

2. **敏感度系数**：
   $$
   \text{敏感度系数} = \frac{\text{目标指标变化率}}{\text{变量变化率}}
$$
   - 系数绝对值越大，该变量越敏感（越致命）

3. **盈亏平衡点（BEP）**：
   - 计算使 NPV = 0 的变量临界值
   - 公式：$BEP = \text{基准值} \times (1 + \frac{NPV}{\text{敏感度}})$

4. **龙卷风图（Tornado Diagram）**：
   - 按敏感度系数排序，可视化展示

---

### Techniques（技巧与注意事项）

1. **变量选择**：
   - 优先选择：**价格、销量、成本**（对 NPV 影响最大）
   - 避免：折现率（已通过 NPV 敏感性覆盖）

2. **非线性识别**：
   - 若变量 ±X% 导致 NPV 变化不对称（如：+20% → NPV +50%；-20% → NPV -80%）
   - 说明存在**凸性风险**，需额外标注

3. **概率分布结合**：
   - 若变量有概率分布（如：价格服从正态分布）
   - 建议调用 `@tools-monte-carlo` 进行蒙特卡洛模拟

## 执行流程

### Step 1：输入验证
1. 检查基准情景是否包含 NPV/IRR
2. 确认待测试变量是否在基准情景中定义

### Step 2：单变量测试
1. 对每个变量，计算 ±X% 波动下的目标指标
2. 计算敏感度系数

### Step 3：盈亏平衡分析
1. 对每个变量，计算使 NPV = 0 的临界值
2. 评估临界值达成的可能性（基于历史数据/行业基准）

### Step 4：输出报告
1. 按敏感度排序
2. 绘制龙卷风图数据（供可视化工具使用）
3. 给出风险应对建议

---

## 边界与异常处理

### 边界1：变量高度相关
- **问题**：价格与销量相关（降价 → 销量上升）
- **处理**：进行**多变量敏感性分析**（如：价格 -10% & 销量 +15%）

### 边界2：非线性响应
- **问题**：变量与 NPV 关系非线性
- **处理**：增加测试点（如：±5%, ±10%, ±15%, ±20%）
