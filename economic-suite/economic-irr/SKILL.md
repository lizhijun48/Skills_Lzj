## ITTO 合约

### Input（输入）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `initial_investment` | Number | ✅ | 初始投资（C_0），单位：万元 |
| `cash_flows` | Array | ✅ | 运营期现金流数组 |
| `salvage_value` | Number | ⭕ | 残值（S_v），默认 0 |
| `periods` | Number | ✅ | 项目周期（年） |

**输入示例**：
```json
{
  "initial_investment": 100,
  "cash_flows": [30, 35, 40, 45, 50],
  "salvage_value": 20,
  "periods": 5
}
```

---

### Tools（工具与方法）

1. **IRR 计算公式**：
   $$
   NPV = -C_0 + \sum_{t=1}^{n} \frac{CF_t}{(1+IRR)^t} + \frac{S_v}{(1+IRR)^n} = 0
$$
   - IRR 是使 NPV = 0 的折现率

2. **计算方法**：
   - **试错法**：尝试不同折现率，找到使 NPV ≈ 0 的 IRR
   - **线性插值法**：当 NPV 在相邻折现率下异号时，线性插值

3. **判定标准**：
   - IRR > 折现率（i_c）：项目可行
   - IRR = 折现率：项目持平
   - IRR < 折现率：项目不可行

---

### Techniques（技巧与注意事项）

1. **多解问题**：
   - 若现金流多次变号（正负交替），可能存在多个 IRR
   - **处理**：使用 **MIRR（修正内部收益率）** 或直接使用 NPV

2. **再投资假设**：
   - IRR 假设中间现金流以 IRR 再投资（可能不现实）
   - **缺陷**：高 IRR 项目可能 NPV 很低

3. **与 NPV 的优先级**：
   - **永远以 NPV 为最终决策依据**
   - IRR 仅作为辅助参考（效率指标）

---

### Output（输出）

**标准输出格式**：

```markdown
## IRR 计算结果

### 1. 核心指标
- **IRR（内部收益率）**：XX.XX%
- **基准收益率**：XX%（i_c）
- **判定结论**：✅ 可行 / ❌ 不可行
- **对应 NPV**：XX.XX 万元（在 i_c = XX% 下）

### 2. 计算过程
| 折现率 | NPV（万元） | 符号 |
|---------|-------------|------|
| 8%      | XX.XX       | +    |
| 10%     | XX.XX       | +    |
| 12%     | XX.XX       | -    |
| **IRR**  | **0**       | -    |

- **线性插值计算**：
  $$
  IRR = i_1 + \frac{NPV_1}{NPV_1 - NPV_2} \times (i_2 - i_1)
$$
  其中：i_1 = 10%, NPV_1 = 5.23；i_2 = 12%, NPV_2 = -2.45
  计算得：IRR = 11.37%

### 3. 与 NPV 对比
| 指标 | 值 | 判定 | 说明 |
|------|-----|------|------|
| **NPV** | XX.XX 万元 | ✅ 可行 | 绝对财富增量 |
| **IRR** | XX.XX%    | ✅ 可行 | 相对效率，但可能误导 |

### 4. 决策建议
- 若 IRR > i_c 且 NPV > 0：✅ 强烈推荐
- 若 IRR > i_c 但 NPV < 0：⚠️ 异常（检查多解问题）
- 若 IRR < i_c：❌ 不推荐
```

## 执行流程

### Step 1：输入验证
1. 检查必填参数
2. 检查现金流是否多次变号（可能多解）

### Step 2：计算 IRR
1. 使用试错法 + 线性插值
2. 计算对应 NPV（在基准收益率下）

### Step 3：多解检查
1. 若多个 IRR：输出所有 IRR，建议使用 NPV
2. 计算 MIRR（可选）

### Step 4：输出报告
1. 按标准格式输出
2. 明确标注"NPV 优先于 IRR"

---

## 边界与异常处理

### 边界1：多个 IRR
- **问题**：现金流多次变号，IRR 方程有多个解
- **处理**：
  1. 输出所有 IRR
  2. 建议使用 **NPV** 或 **MIRR**
  3. 标注："IRR 存在多解，建议以 NPV 为准"

### 边界2：无实数解
- **问题**：IRR 计算无实数解（如：所有现金流均为正）
- **处理**：
  1. 输出："IRR 无实数解"
  2. 建议使用 NPV

## 调用示例

### 示例1：独立项目评估
**用户提问**：
> "这个项目的 IRR 是多少？初始投资 100 万，5 年现金流 [30, 35, 40, 45, 50]，残值 20 万。"

**技能调用**：
```
调用 @economic-irr
输入：
  - initial_investment: 100
  - cash_flows: [30, 35, 40, 45, 50]
  - salvague_value: 20
  - periods: 5
```

**输出**：
```markdown
## IRR 计算结果

### 1. 核心指标
- **IRR（内部收益率）**：11.37%
- **基准收益率**：10%（i_c）
- **判定结论**：✅ 可行（IRR > i_c）
- **对应 NPV**：37.24 万元（在 i_c = 10% 下）

### 2. 计算过程
| 折现率 | NPV（万元） | 符号 |
|---------|-------------|------|
| 8%      | 47.89       | +    |
| 10%     | 37.24       | +    |
| 12%     | 27.56       | +    |
| 15%     | 12.45       | +    |
| 18%     | -1.23       | -    |

- **线性插值计算**：
  $$
  IRR = 15\% + \frac{12.45}{12.45 - (-1.23)} \times (18\% - 15\%) = 11.37\%
$$

### 3. 与 NPV 对比
| 指标 | 值 | 判定 | 说明 |
|------|-----|------|------|
| **NPV** | 37.24 万元 | ✅ 可行 | 绝对财富增量 |
| **IRR** | 11.37%     | ✅ 可行 | 相对效率 |

### 4. 决策建议
- ✅ IRR = 11.37% > 基准收益率 10%，项目可行
- ✅ NPV = 37.24 万元 > 0，双重确认可行
- 建议：通过立项
```
