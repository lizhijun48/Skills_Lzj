## 三、待核稿转正策略（数据源评估结论 2026-09-01）

**数据源评估结论**：flk.npc.gov.cn（国家法律法规数据库）**无开放 API 契约**（旧 GET 端点返 SPA、POST 返 405），程序化调用随时失效；中国政府网深链亦重定向首页。故确定：**主源切换为开源镜像（china-law-db / laws-data，均源自国家法律法规数据库、MIT、每周 git 同步），flk 降级为人工核验/补漏**。详见 `README.md`「数据源策略」。

**8 部待核稿转正操作（标准动作）**：自开源镜像取权威全文 → 对照写入 `laws/<法名>_<版本>.md`（frontmatter 状态 `待核`→`新鲜`，来源记主源镜像+同步日期，核实记"已对照开源镜像转正"）→ `law-manifest.md` 该条目改"已入库（新鲜）" → `registry/reverse-registry.md` 补/核引用登记 → 一更新一 commit。
- 待转正清单（§一中标**待核**的条目）：民法典合同编通则、保险法、建工司法解释一、劳动合同法、劳动法、招标投标法实施条例（版本）、政府采购法实施条例（修订）、16号令、民诉法、仲裁法。
- **2026-09-01 转正执行结果**：上述 10 部中，除 **16号令（必须招标的工程项目规定）** 因开源镜像 laws-data 未收录"部门规章"类（json/ 顶层仅 法律/行政法规/司法解释/宪法/监察法规）而缺源、保留待核外，其余 **9 部已对照镜像全文转正**（状态待核→新鲜，知识起草_待核文件移除）：民法典（存全本1260条，合同编通则含于内）、保险法_2015、建工司法解释一_法释25号、劳动合同法_2012、劳动法_2018、招标投标法实施条例_2019(709号)、政府采购法实施条例_2015(658号)、民诉法_2023、仲裁法_2025修订(现行)。16号令待从其他源（china-law-db / 官方法规库）补源后转正。
