# L2 领域解读层

> 定位：law-repository 的 **L2 层**。存放「司法解释原文之外」的**领域解读**——官方释义、权威实务解读、学理解释汇编。
> 治理身份：与 L1/L3 同属 data 基础设施，不占技能编号，纳入 GOV_SkillGovernance v3.6 管辖（QG4 数据溯源）。
>
> **与 L1 原文层的边界**：L1 只存有法律效力的文本（法律 / 法规 / 司法解释 / 部门规章**原文**）；L2 存「对原文的解读」（无独立法律效力，但具实务指引价值）。
> **与 L3 案例层的边界**：L2 是「条文解读」，L3 是「具体案件裁判要旨」。
>
> 用户需求 #1（2026-08-26 复盘结论）：法律法规库应包含【原文、司法解释、领域解读、案例引用】——本层承载「领域解读」。

## 文件命名

`<主题>_解读_<来源或口径>.md`

示例：
- `建设工程施工合同_解读_最高法理解与适用.md`
- `民法典合同编_解读_全国人大法工委释义.md`

## 内容规范

- 摘录原文要旨 + 适用口径 + 实务注意点，**不杜撰**：来源缺失标「待核实」。
- 必须挂「关联原文」回指 L1，形成 解读 → 原文 的正向溯源。
- 反向：行业技能引用本层解读时，标注 `来源：law-repository/L2-interpretation/<文件>(快照日期)`。
