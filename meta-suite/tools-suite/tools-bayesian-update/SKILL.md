## 核心概念：贝叶斯更新的直觉

### 为什么需要贝叶斯更新？

**传统做法（静态）**：
```
第一次投标：对手A报价下浮率估计 = 7.0%（拍脑袋）
第三次投标后：仍然用 7.0% → 模型没有进化
```

**贝叶斯做法（动态）**：
```
先验：对手A下浮率 ~ N(μ=7.0%, σ=3.0%)  [初始不确定，σ大]
第一次观测：对手A实际下浮 8.5% → 后验：μ=7.8%, σ=2.1%
第三次观测：对手A实际下浮 9.0%, 8.0%, 7.5% → 后验：μ=8.2%, σ=1.2%
→ 模型越来越准，σ越来越小（信心越来越高）
```

### 贝叶斯公式（直觉版）

```
后验 ∝ 先验 × 似然

即：更新后的参数 = 旧参数 ×（新证据的权重）+ 旧参数 ×（旧信念的权重）
```

**关键洞察**：先验越不确定（σ 大），新证据权重越大；先验越确定（σ 小），新证据权重越小。

### Input（输入 — 可验证）

| 类型 | 字段名 | 格式/说明 | 来源 |
|:----:|:------|:---------|:-----|
| [M] | prior_params | 先验参数（如：μ_old, σ_old） | 调用方 SKILL 的 Knowledge Sources 或上次运行结果 |
| [M] | observations | 新观测数据（如：本次对手实际报价） | 场景11（投标复盘）提供 |
| [M] | likelihood_model | 似然函数类型（normal/beta/gamma） | 调用方指定 |
| [O] | prior_type | 先验分布类型（normal/beta/gamma/conjugate） | 默认与 likelihood 共轭 |
| [O] | confidence_weight | 先验置信度（0-1，1=完全信任先验） | 默认 0.5（新旧各半） |

**输入格式示例（招投标场景）**：
```
prior_params:
  mu_old: 0.070      # 对手A下浮率先验均值 7.0%
  sigma_old: 0.030    # 先验标准差 3.0%（不确定度高）
observations:
  - 0.085             # 第一次：对手A实际下浮 8.5%
  - 0.090             # 第二次：9.0%
  - 0.080             # 第三次：8.0%
  - 0.075             # 第四次：7.5%
likelihood_model: normal
prior_type: normal      # 正态-正态共轭
confidence_weight: 0.3  # 更相信新数据（因为已观测4次）
```

### Tools & Techniques（处理逻辑 — 可追溯）

| 步骤 | 方法 | 标准出处 | 说明 |
|:---:|------|:--------|------|
| 1 | 先验-似然共轭检验 | 贝叶斯统计理论 | 确保先验与似然共轭，更新有解析解 |
| 2 | 计算后验参数（解析法或 MCMC） | 贝叶斯定理 | 小数据用解析解；大数据用 MCMC 采样 |
| 3 | 计算后验预测分布 | 决策理论 | 用后验参数预测下一次观测值 |
| 4 | 更新置信度（σ 缩小） | 信息论（Fisher 信息） | 观测越多，σ 越小，模型越确定 |
| 5 | 异常检测（Grubbs 检验） | 异常检测理论 | 检测观测值是否异常（如：对手犯错报超低） |

**共轭分布速查表**：

| 似然（观测数据分布） | 共轭先验 | 后验参数更新公式（直觉） |
|---------|---------|---------|
| Normal（正态） | Normal-Inverse-Gamma | μ_post = (σ²₀×μ₀ + n×σ²×x̄) / (σ²₀ + n×σ²) |
| Beta（比例） | Beta | α_post = α₀ + 成功次数；β_post = β₀ + 失败次数 |
| Gamma（正值） | Gamma | α_post = α₀ + Σx_i；β_post = β₀ + n |
| 离散分类 | Dirichlet | α_post,k = α₀,k + 观测到类别 k 的次数 |

> 📊 **不用写公式**：AI 执行时直接按共轭关系计算后验参数，输出文字解读即可。

## 使用流程（三步）

### 第一步：确定先验和似然

**先验从哪里来？**

| 先验来源 | 方法 | 示例 |
|---------|------|------|
| **历史数据** | 用历史数据拟合分布 → 参数作为先验 | 过去 10 次交锋：μ=7.2%, σ=2.8% |
| **专家判断** | 专家给出「最乐观/最可能/最悲观」→ 三角分布 → 近似为正态先验 | 专家估计：下浮率 5%-8%-12% → μ=8%, σ 用三角分布方差近似 |
| **无信息先验** | 用扩散先验（σ 很大）| μ=7%, σ=10%（相当于"我完全不知道"） |

**似然函数怎么选？**

| 观测数据类型 | 似然分布 | 共轭先验 |
|---------|---------|---------|
| 连续值（报价下浮率/成本/工期） | Normal | Normal-Inverse-Gamma |
| 比例（中标率/成功率） | Binomial → Beta 共轭 | Beta |
| 正值（工期天数/成本万元） | Gamma 或 Lognormal | Gamma |
| 分类（对手类型：激进/保守/跟随） | Multinomial | Dirichlet |

---

### 第二步：执行更新

**小数据（观测 ≤ 30 次）：解析法（推荐）**

```
# 正态-正态共轭的直觉计算（AI 执行时按此逻辑）
先验：μ₀, σ₀²
观测：n 个数据点，均值 x̄，样本方差 s²

后验 μ：
  μ_post = (σ₀⁻² × μ₀ + n × σ_obs⁻² × x̄) / (σ₀⁻² + n × σ_obs⁻²)
  → 直觉：先验和新数据的加权平均，权重 = 置信度

后验 σ²：
  σ_post² = 1 / (σ₀⁻² + n × σ_obs⁻²)
  → 直觉：观测越多，后验方差越小（越确定）
```

**大数据（观测 > 30 次）：MCMC 采样法**

> AI 执行时：描述 MCMC 逻辑，输出后验分布的描述性统计（均值/中位数/HDI 最高密度区间）

---

### 第三步：输出决策建议

**核心输出不是"新参数是多少"，而是"这对决策意味着什么"**：

```
基于后验预测分布，回答决策问题：

Q1：下次投标，我方报价下浮多少时，中标概率 > 70%？
→ 用后验预测分布模拟 10000 次，找到 P(中标|我方下浮=x) ≥ 70% 的 x 区间

Q2：对手 A 下次报价下浮 > 10% 的概率有多少？
→ P(对手A下浮 > 10%) = 1 - Φ((10% - μ_post) / σ_post)
  = 1 - Φ((10% - 8.18%) / 1.45%) ≈ 11.5%

Q3：博弈系数 K 应该调整为多少？
→ K_new = K_old × 修正系数
  修正系数 = f(μ_post, σ_post, 项目类型, 历史命中率)
```

### 场景 A：招投标 — 对手画像更新（pm-bid-proposal 调用）

```
## 先验（来自历史 10 次交锋）
对手 A 下浮率 ~ N(μ=7.0%, σ=2.5%)

## 新观测（本次投标结果）
对手 A 实际下浮率 = 9.2%（比预期更激进）

## 贝叶斯更新
μ_post = 7.56%   （向 9.2% 靠拢，但权重受先验 σ 影响）
σ_post = 1.97%   （信心提高）

## 更新后对手画像
- 对手 A 报价偏好：下浮率 ~ N(μ=7.56%, σ=1.97%)
- 判断：激进型（μ > 7.0%），下次相遇应适当跟进下浮率
- 博弈系数 K 调整：K_new = K_old + 0.05

## 决策建议
下次遇对手 A：
  - 若我方成本允许下浮 ≥ 8.5%：可正面价格战
  - 若我方成本不允许：避开价格战，强化技术方案差异化
```

### 场景 B：招投标 — 博弈系数 K 的贝叶斯更新（pm-bid-proposal 调用）

```
## K 的含义
K = 报价调整系数（用于：目标价 = (最高价+最低价)/2 × K）
K > 1.0：更激进（报价更高，适合技术优势明显时）
K < 1.0：更保守（报价更低，适合价格战时）

## 先验
K ~ N(μ=1.00, σ=0.10)  [初始中性，不确定]

## 新观测（过去 5 次投标结果）
| 次数 | K_used | 是否中标 | 复盘结论 |
|------|--------|----------|---------|
| 1 | 1.00 | ✅ 中标 | K=1.0 合理 |
| 2 | 0.95 | ❌ 未中标 | K 过低，价格战失败 |
| 3 | 1.05 | ✅ 中标 | 技术分高时，K 可 >1.0 |
| 4 | 1.02 | ✅ 中标 | K=1.02 合理 |
| 5 | 0.98 | ❌ 未中标 | 对手 A 激进压价，K 应适当提高 |

## 贝叶斯更新（K 的后验分布）
将"是否中标"视为 Bernoulli 结果，K 的影响用 Logistic 模型建模：
→ 后验：推荐使用 K ∈ [1.02, 1.06]（技术分占优时）
→ 若技术分不占优：推荐使用 K ∈ [0.97, 1.01]（保守报价）

## 决策规则（可写入 pm-bid-proposal 的 Boundary）
IF 我方技术分预计 > 对手最高分 + 5分:
    K ∈ [1.03, 1.06]   # 适当提高报价，保利润
ELSE IF 价格分权重 > 40%:
    K ∈ [0.97, 1.00]   # 价格敏感，保守报价
ELSE:
    K = 1.01   # 中性
```

### 场景 C：项目风险概率更新（pm-risk-management 调用）

```
## 先验
某风险事件发生概率 P(R) = 20%（基于历史数据估计）

## 新观测
本项目进行到第 3 个月：该风险事件**未发生**
→ 这是「删失数据」（right-censored），需要提供「未发生」的证据

## 贝叶斯更新（指数分布寿命模型）
用指数分布建模风险事件发生时间：
  - 先验：故障率 λ ~ Gamma(α=2, β=10)  [对应 P(R)≈20%]
  - 观测：3 个月未发生 → 似然 = exp(-λ × 3)
  - 后验：λ_post 偏向更小的值

## 更新后
P(R) 从 20% ↓ 降至约 12%（因为 3 个月都没发生，说明风险可能被高估了）

## 决策建议
可减少该风险的预留金（从 20% 降至 12%），释放预算到其他高概率风险
```

## 进阶：在线学习（持续更新）

> 把贝叶斯更新做成「持续学习循环」，每次新数据到来自动触发更新。

```
初始化：
  μ = μ₀, σ = σ₀

FOR EACH 新观测 data_i:
    后验 = bayesian_update(μ, σ, data_i)
    μ = 后验.μ
    σ = 后验.σ
    SAVE (μ, σ) to 模型文件

输出：最终 (μ, σ) 作为模型的最新状态
```

**在 pm-bid-proposal 场景11 的实现**：
```
每次投标结束（中标/未中标）→ 自动触发 tools-bayesian-update
  → 输入：旧对手画像参数 + 本次观测数据
  → 输出：新对手画像参数 → 写回 references/对手画像库.md
  → 输出：新博弈系数 K → 写回 references/报价博弈系数K记录.md
```
