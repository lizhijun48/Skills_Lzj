# tools-monte-carlo · 蒙特卡洛模拟工具

> **定位**：通用定量风险分析工具。接收不确定性变量的概率分布，通过大量随机抽样，输出目标指标的概率分布，支持决策。
> **Track**: `S`（共用层）| **Phase**: `P3`（规划）+ `P5`（控制）| **Sub-position**: `P3-c 风险量化` / `P5-b 风险监控`
> **Knowledge Sources**: [PMI PMBOK 风险量化分析, 决策分析理论, 概率论与数理统计]
> **Review Cadence**: `annually`

## 一句话定位

> 把"不确定"变成"可知的不确定"——用概率分布替代单一数值，帮你在模糊中找到最优决策点。

## ITTO 契约（GOV v3.0）

### Input（输入 — 可验证）

| 类型 | 字段名 | 格式/说明 | 来源 |
|:----:|:------|:---------|:-----|
| [M] | variables | 变量清单：名称/分布类型/参数 | 调用方 SKILL 提供 |
| [M] | objective_function | 目标函数（计算公式） | 调用方 SKILL 提供 |
| [M] | trials | 抽样次数（建议 ≥5000，高精度 ≥10000） | 调用方指定或默认 10000 |
| [O] | confidence_level | 置信水平（默认 95%） | 调用方指定 |
| [O] | output_format | 输出格式：`chart`（图表）+ `table`（数据表）| 调用方指定或默认两者 |

**variables 格式示例**：
```
variables:
  - name: 我方报价下浮率
    distribution: normal
    params: {mu: 0.062, sigma: 0.018}
    bounds: [0.03, 0.12]
  - name: 对手A报价下浮率
    distribution: normal
    params: {mu: 0.081, sigma: 0.022}
    bounds: [0.03, 0.15]
  - name: 控制价下浮率
    distribution: uniform
    params: {low: 0.03, high: 0.10}
```

**支持的分布类型**：

| 分布类型 | 参数 | 适用场景 |
|---------|------|---------|
| `normal`（正态） | mu, sigma | 历史数据充足，呈钟形分布（如下浮率） |
| `uniform`（均匀） | low, high | 完全不知道偏好，只在范围内等可能 |
| `triangular`（三角） | low, mode, high | 有最可能值，但分布不对称 |
| `beta`（贝塔） | alpha, beta | 专家判断场景，可刻画偏态 |
| `lognormal`（对数正态） | mu, sigma | 成本/工期，右偏分布 |
| `discrete`（离散） | values, weights | 分类变量（如：对手类型 = 激进/保守/跟随） |

### Tools & Techniques（处理逻辑 — 可追溯）

| 步骤 | 方法 | 标准出处 | 说明 |
|:---:|------|:--------|------|
| 1 | 分布拟合与校验 | 概率论与数理统计 | 检查变量定义完整性、参数合理性、边界约束 |
| 2 | 随机抽样（伪随机数生成） | Monte Carlo 方法 | 对每个变量按指定分布抽取 trials 次 |
| 3 | 目标函数计算 | 决策分析理论 | 每次抽样计算目标函数值（如：是否中标、总成本） |
| 4 | 统计分析 | PMBOK 11.4 定量风险分析 | 计算均值/中位数/标准差/分位数/置信区间 |
| 5 | 敏感性分析（Spearman 秩相关） | 决策分析 | 识别对输出影响最大的输入变量 |
| 6 | 图表生成 | 数据可视化规范 | 生成概率分布曲线图 + 累积概率图 + 敏感性排序图 |

**Branch Conditions（场景分支）**：

| 条件 | 触发时机 | 处理差异 |
|:----|:--------|:--------|
| trials < 5000 | 调用方指定的抽样次数过少 | 警告：结果可能不稳定，建议 ≥5000 |
| 变量数 > 10 | 高维问题 | 启用方差缩减技术（控制变量法） |
| 目标函数为二元（是/否） | 如"是否中标" | 输出概率 = 获胜次数 / 总次数 |
| 目标函数为连续值 | 如"总成本""NPV" | 输出完整概率密度分布 |

## 核心概念速查

### 为什么要做蒙特卡洛模拟？

**确定性分析的陷阱**：
```
确定性：成本 = 800万 → 决策：报价 1000万
现实：成本实际可能是 750万~950万（分布）
→ 报价 1000万 可能利润过高（丢标）或过低（亏本）
```

**蒙特卡洛的答案**：
```
模拟 10000 次：
  - 成本 ≤ 800万 的概率：62%
  - 成本 ≤ 850万 的概率：85%
  → 决策：预留 850万 成本底线，对应中标概率 72%
```

## 使用流程（三步）

### 第一步：定义变量分布

> 调用方（如 pm-bid-proposal）先帮用户确定每个变量的分布类型和参数

**如何从有限数据估计分布参数？**

| 数据情况 | 推荐方法 | 示例 |
|---------|---------|------|
| 有 20+ 条历史数据 | 拟合优度检验 → 选最佳分布 | 下浮率数据 → Shapiro-Wilk 检验 → 正态分布 OK |
| 有 5-20 条数据 | 用样本均值/标准差 → 正态分布 | μ = 样本均值，σ = 样本标准差 |
| 只有 3-5 条数据 | 用三角分布（专家判断） | low=最悲观，mode=最可能，high=最乐观 |
| 只有范围，无数据 | 用均匀分布 | low=下限，high=上限 |

---

### 第二步：运行模拟

**伪代码逻辑**（AI 执行时按此逻辑推演）：

```
输入：variables = [v1, v2, ..., vn], objective_function, trials = 10000
输出：results = []

FOR i FROM 1 TO trials:
    FOR EACH variable v IN variables:
        sample_i[v] = random_sample(v.distribution, v.params)
    END FOR
    result_i = evaluate(objective_function, sample_i)
    results.APPEND(result_i)
END FOR

统计：
    mean = AVERAGE(results)
    median = PERCENTILE(results, 0.50)
    P10 = PERCENTILE(results, 0.10)
    P90 = PERCENTILE(results, 0.90)
    敏感性 = SPEARMAN_CORRELATION(sample_i, results)
```

| 输出项 | 含义 | 决策用途 |

## 场景示例

### 场景 A：招投标报价策略（pm-bid-proposal 调用）

```
变量定义：
  - 我方报价下浮率 ~ N(μ=6.2%, σ=1.8%)
  - 对手A报价下浮率 ~ N(μ=8.1%, σ=2.2%)  [激进型]
  - 对手B报价下浮率 ~ N(μ=4.5%, σ=1.1%)  [保守型]
  - 控制价下浮率 ~ Uniform(3%, 10%)

目标函数（是否中标）：
  FOR EACH trial:
    我方得分 = 技术分_我方 + 商务分_我方 + 价格分(我方报价, 所有报价)
    对手A得分 = ...
    是否中标 = (我方得分 == MAX(所有方得分))

输出：
  - 我方中标概率 vs 下浮率曲线（X轴：下浮率 3%-12%，Y轴：中标概率）
  - 最优下浮率区间：6.0%-7.0%（中标概率 72.8%）
  - 敏感性：控制价下浮率（相关系数 0.68）> 对手A下浮率（0.52）> 我方下浮率（0.31）
```

## 抽样次数选择建议

| 用途 | 推荐 trials | 说明 |
|------|------------|------|
| 快速探索（初步判断） | 1000 | 结果粗糙，但速度快 |
| 标准分析（报告用） | 5000-10000 | PMBOK 推荐 ≥5000 |
| 高精度（重大决策） | 10000-50000 | 分位数稳定，可用于正式报告 |
| 敏感性分析 | ≥10000 | 需要稳定的相关性估计 |

**稳定性检验**：运行两次模拟，比较 P50 差异 < 5% → 次数足够。

## 常见问题

**Q1：没有历史数据，怎么确定分布参数？**
→ 用专家判断：让领域专家给出「最乐观/最可能/最悲观」三值 → 三角分布；或给出「最低/最高」范围 → 均匀分布。

**Q2：模拟结果和实际情况差很远，为什么？**
→ 三个常见原因：（1）分布类型选错（数据不是正态的却用了正态）；（2）变量之间实际相关，但模拟时假设独立；（3）抽样次数不够，结果不稳定。建议：先做分布拟合检验，再跑模拟。

**Q3：变量之间有相关性（如：对手A和对手B都不会同时报高价），怎么处理？**
→ 进阶用法：用** copula 函数**建模变量间依赖关系。当前版本建议：将相关变量合并为一个「联合变量」，或在 objective_function 里加入相关性约束。

**Q4：蒙特卡洛和决策树怎么选？**
→ 决策树适合**离散决策节点**（如：做/不做，选方案A/B/C）；蒙特卡洛适合**连续不确定性**（如：成本是多少~分布）。两者可以结合：决策树每个节点用蒙特卡洛模拟计算期望 value。
