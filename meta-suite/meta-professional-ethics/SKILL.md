# meta-professional-ethics · 职业道德与专业行为规范

> **核心定位**：产品经理和项目经理共享的职业道德底线——无论做什么产品、管什么项目，这些是不可逾越的红线。
> **被调用方**：pd-integration（产品整合管理-职业道德章节）+ pm-integration（项目整合管理-职业道德章节）

---

## 为什么需要职业道德框架？

| 场景 | 后果 | 职业道德的作用 |
|------|------|---------------|
| 隐瞒项目风险 | 上线后事故，追责 | 诚实原则要求主动披露 |
| 供应商是亲戚 | 利益输送，审计风险 | 公正原则要求回避 |
| 数据未经授权使用 | 隐私泄露，法律追责 | 责任原则要求合规 |
| 对甲方承诺无法兑现 | 信任崩塌，合同纠纷 | 尊重原则要求诚实沟通 |

**核心逻辑**：职业道德不是"好人好事"，而是**风险防火墙**——守住了底线，就守住了项目/产品的安全边界。

## 一、PMI四大核心价值观

### 1. 责任（Responsibility）

**定义**：对自己的决策和行为承担责任，包括对错误承担责任。

| 具体行为 | 正确做法 | 违规表现 |
|---------|---------|---------|
| 决策可追溯 | 记录决策过程和依据 | 口头决策无记录 |
| 错误主动报告 | 发现问题立即上报 | 等别人发现再解释 |
| 授权范围内行动 | 不越权承诺 | 越权签合同/承诺 |
| 后果承担 | 主动分析失误原因 | 甩锅给团队/环境 |

**实操规则**：
- 每个关键决策必须留文档（邮件/会议纪要/决策记录表）
- 发现错误24小时内上报——拖延=隐瞒
- 不在自己专业能力范围外做判断——求助不是软弱，乱决策才是

### 2. 尊重（Respect）

**定义**：尊重他人、尊重资源、尊重流程。

| 具体行为 | 正确做法 | 违规表现 |
|---------|---------|---------|
| 尊重他人时间 | 会议有议程、有结论 | 开无结果会议 |
| 尊重他人专业 | 不越俎代庖 | 替工程师做技术决策 |
| 尊重流程 | 变更走CCB | 绕过流程改需求 |
| 尊重知识产权 | 引用注明来源 | 剽窃他人方案 |

**实操规则**：
- 跨部门沟通前先发议程，会中记结论，会后发纪要
- 不在公开场合否定他人——有异议私下沟通
- 承认他人贡献——"这个方案是小王提出的"

### 3. 公正（Fairness）

**定义**：不受偏见影响，平等对待各方利益。

| 具体行为 | 正确做法 | 违规表现 |
|---------|---------|---------|
| 供应商选择 | 加权评分，公开透明 | 内定供应商 |
| 团队评价 | 统一标准，一视同仁 | 因人设岗 |
| 利益冲突 | 主动申报回避 | 隐瞒利益关系 |
| 信息披露 | 对各方提供同等信息 | 选择性披露 |

**实操规则**：
- 有利益冲突必须书面申报→详见"利益冲突管理"
- 采购/供应商选择必须留完整评分记录
- 不因甲方/乙方的地位差异而区别对待信息

### 4. 诚实（Honesty）

**定义**：不撒谎、不隐瞒、不误导。

| 具体行为 | 正确做法 | 违规表现 |
|---------|---------|---------|
| 进度汇报 | 如实反映，红就是红 | 绿化报告 |
| 能力声明 | 只承诺能做到的 | 夸大团队能力 |
| 数据报告 | 原始数据，不美化 | 选择性展示数据 |
| 风险披露 | 主动告知已知风险 | 等甲方问再说 |

**实操规则**：
- 坏消息越早说越好——拖延不会让问题消失，只会让后果更严重
- 不确定的事说"不确定"——"我目前没有这个信息，周三前给你确认"
- 数据展示必须说明口径——"月活"还是"日活"，是否包含机器人

## 二、中国法规约束（PdM/PgM必须知道的）

### 产品经理相关法规

| 法规 | 核心要求 | 违规后果 |
|------|---------|---------|
| 《个人信息保护法》 | 收集个人信息需明确同意 | 罚款5000万或上一年度营业额5% |
| 《数据安全法》 | 数据分类分级+安全评估 | 罚款1000万+个人罚100万 |
| 《网络安全法》 | 网络安全等级保护 | 罚款100万+停业整顿 |
| 《广告法》 | 不得虚假宣传 | 罚款100-200万 |
| 《消费者权益保护法》 | 产品质量+售后责任 | 3倍赔偿+行政处罚 |
| 《生成式AI服务管理暂行办法》 | AI产品合规要求 | 约谈+下架 |

### 项目经理相关法规

| 法规 | 核心要求 | 违规后果 |
|------|---------|---------|
| 《招标投标法》 | 公开公平公正+不得串标 | 中标无效+罚款+刑责 |
| 《政府采购法》 | 采购程序合规 | 罚款+列入黑名单 |
| 《民法典》合同编 | 合同履行+违约责任 | 赔偿+强制履行 |
| 发改委55号令 | 政府信息化项目全流程规范 | 验收不通过+审计整改 |
| 《建筑法》 | 施工许可+质量责任 | 罚款+停工+降低资质 |

### 通用红线

1. **不行贿受贿**——《刑法》第163/389条，企业人员行贿/受贿均追刑责
2. **不侵犯商业秘密**——《反不正当竞争法》第9条
3. **不虚假投标**——《招标投标法》第54条，串标/围标追刑责
4. **不侵犯个人隐私**——《个人信息保护法》，违规收集使用个人信息

## 三、利益冲突管理

### 识别利益冲突

**以下情况必须主动申报**：

| 冲突类型 | 示例 | 处理方式 |
|---------|------|---------|
| 经济利益 | 持有供应商股份 | 申报+回避相关决策 |
| 亲属关系 | 老婆在竞品公司 | 申报+评估是否影响公正 |
| 二次就业 | 在甲方兼职顾问 | 申报+终止兼职或退出项目 |
| 礼物款待 | 收受供应商礼品 | 拒收/上交+申报 |
| 学术利益 | 论文数据来自项目 | 申报+获得授权 |

### 申报流程

```
Step 1: 识别 → 发现潜在利益冲突
Step 2: 书面申报 → 向上级/PMO/合规部门提交《利益冲突申报表》
Step 3: 评估 → 合规部门评估冲突严重程度
Step 4: 处理 → 三选一：
  a) 回避（退出相关决策/项目）
  b) 透明化（公开利益关系，各方同意后参与）
  c) 建立防火墙（信息隔离+监督机制）
Step 5: 记录 → 归档备查
```

### 踩坑预警
- ❌ "小利益不算冲突"→100元礼品也可能触发合规红线
- ❌ "我保证公正就行"→利益冲突看的是可能性，不是你的自觉
- ❌ 申报了就没事→申报只是第一步，必须走完处理流程

## 四、数据伦理

### 产品经理的数据伦理

| 原则 | 要求 | 违规示例 |
|------|------|---------|
| 最小必要 | 只收集必要数据 | App强制获取通讯录 |
| 知情同意 | 明确告知用途并获授权 | 隐私条款藏在100页协议里 |
| 目的限制 | 不得超出承诺用途使用 | 说好用于推荐，实际用于画像售卖 |
| 安全保护 | 加密存储+访问控制 | 明文存储用户密码 |
| 退出权 | 提供数据删除机制 | 注销账号后数据仍保留 |

### 项目经理的数据伦理

| 原则 | 要求 | 违规示例 |
|------|------|---------|
| 数据保密 | 项目数据不外泄 | 把甲方数据给竞品 |
| 数据真实 | 不篡改项目数据 | 美化进度数据 |
| 数据权限 | 按需授权访问 | 所有人都能看全量数据 |
| 数据留存 | 按合同/法规保留 | 项目结束直接删数据 |

## 五、举报与维权

### 什么情况需要举报

| 级别 | 情况 | 行动 |
|------|------|------|
| 🔴 必须举报 | 违法行为、安全事故、数据泄露 | 立即上报+留证 |
| 🟡 建议举报 | 违反职业道德、利益冲突隐瞒 | 书面报告上级 |
| 🟢 自行处理 | 流程违规、沟通不当 | 5W1H分析后纠正 |

### 举报3步流程

**Step 1：收集证据**
- 文件/邮件/聊天记录截图
- 时间、地点、人物、事件
- ⚠️ 举报内容必须基于事实，不得臆测

**Step 2：选择渠道**
- 内部：上级→合规部门→PMO→高管
- 外部：监管机构/行业协会
- ⚠️ 优先内部渠道，保护自己也给组织纠正机会

**Step 3：保护自己**
- 举报前备份证据（非原始设备上）
- 了解《举报人保护制度》
- 不公开扩散举报内容

### 维权3步流程

当你的专业判断被否决但你认为有重大风险时：

1. **书面记录**：邮件说明你的判断和依据
2. **升级上报**：向更高层/PMO/合规部门反映
3. **保留证据**：如果最终决策不是你做的，确保你的反对意见有记录

**关键原则**：你可以执行你不赞同的决策（如果决策者有权限），但你必须确保你的反对意见被记录——这是你未来免责的依据。

## 六、政企项目专项伦理

| 场景 | 伦理要求 | 实操建议 |
|------|---------|---------|
| 招投标 | 不得串标/围标/行贿 | 不与竞标方私下接触 |
| 需求收集 | 不得引导甲方指定供应商 | 技术方案写参数不写品牌 |
| 验收 | 不得弄虚作假 | 测试数据必须真实 |
| 变更 | 不得通过变更虚增成本 | 变更必须走正式审批 |
| 数据 | 甲方数据不得他用 | 数据隔离+脱敏 |
| 礼品 | 不得收受超过200元礼品 | 收到即上交+申报 |

## 核心原则

1. **底线思维**：职业道德不是上限追求，而是底线守护——先守住底线，再追求卓越
2. **主动披露**：发现问题主动说，比被发现后解释好一万倍
3. **记录为王**：口头承诺=没有承诺，书面记录=你的保险单
4. **利益冲突零容忍**：不申报的利益冲突=埋雷，迟早引爆
5. **数据伦理是新红线**：在AI时代，数据伦理违规的后果远超传统伦理违规
6. **保护举报人**：敢于说真话的人是组织的免疫系统，不能让免疫系统被摧毁
