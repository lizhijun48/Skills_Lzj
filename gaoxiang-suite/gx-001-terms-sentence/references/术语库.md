## 四、进度管理（Ch.10）★ 案例高频

| 你的实战表达 | 考试标准术语 | 英文 | 使用场景/例句 |
|------------|------------|------|-------------|
| 排工期、排计划 | 定义活动 / 估算 duration / 制定进度计划 | Define Activities | "我运用关键路径法识别关键活动，制定进度基准。" |
| 哪条线最紧、不能拖 | 关键路径（CPM） | Critical Path Method | "我识别关键路径为 A→C→E，重点监控其浮动时间。" |
| 万一不确定怎么办 | 三点估算（PERT） | PERT / Three-Point Estimate | "对高风险活动采用三点估算：Te=(O+4M+P)/6。" |
| 工期太紧要赶 | 赶工 / 快速跟进 | Crashing / Fast Tracking | "我对关键路径活动采取赶工（增加资源），压缩总工期5天。" |
| 活儿同时干 | 快速跟进（并行） | Fast Tracking | "我将设计完成后才施工的串行关系改为快速跟进，但带来返工风险。" |
| 进度慢了 | 进度偏差（SV<0）/ SPI<1 | Schedule Variance | "当 SPI 降至 0.85，我启动偏差分析并纠正。" |
| 缓冲时间 | 总浮动时间 / 自由浮动时间 | Total Float / Free Float | "非关键活动拥有10天总浮动，我将其作为进度缓冲。" |

## 五、成本管理（Ch.11）★ EVM 核心

| 你的实战表达 | 考试标准术语 | 英文 | 使用场景/例句 |
|------------|------------|------|-------------|
| 计划花多少钱 | 计划价值 PV（BCWS） | Planned Value | "截至本月末，计划价值 PV=120万元。" |
| 实际花了多少 | 实际成本 AC（ACWP） | Actual Cost | "实际成本 AC=135万元，超支15万元。" |
| 干了多少活的当量钱 | 挣值 EV（BCWP） | Earned Value | "按完成比例计算的挣值 EV=100万元。" |
| 超支了 | 成本偏差 CV<0 / 成本绩效指数 CPI<1 | Cost Variance | "CV=EV-AC=-35万元，CPI=0.74，成本严重超支。" |
| 进度落后 | 进度偏差 SV<0 / 进度绩效指数 SPI<1 | Schedule Variance | "SV=EV-PV=-20万元，SPI=0.83，进度滞后。" |
| 最后要花多少 | 完工估算 EAC | Estimate at Completion | "EAC=BAC/CPI=200/0.74≈270万元。" |
| 还剩多少要花 | 完工尚需估算 ETC | Estimate to Complete | "ETC=EAC-AC=270-135=135万元。" |
| 要不要纠偏 | 完工偏差 VAC / 偏差管理储备 | Variance at Completion | "VAC=BAC-EAC=200-270=-70万元，需动用管理储备。" |
| 典型偏差会持续 | EAC=BAC/CPI（典型） | Typical Variance | "假设偏差典型延续，EAC=BAC/CPI。" |
| 偏差不持续了 | EAC=AC+BAC-EV（非典型） | Atypical Variance | "若采取纠正措施后偏差不再发生，EAC=AC+BAC-EV。" |

## 使用提示

- **写论文时**：先定位知识域 → 查本表取标准术语 → 套句式库三段式
- **写案例时**：诊断句用标准术语（如"未建立变更控制流程"而非"没人管改动"）
- **综合知识**：本表英文列对应专业英语题，可同步背
- **待补充**：学到新章节（如信息化基础 Ch.1-2）时回填术语
