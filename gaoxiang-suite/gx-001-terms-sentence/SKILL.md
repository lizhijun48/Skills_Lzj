# GX-001 术语句式库

> 高项备考的「语言翻译通道」。
> 你的实战经验是 7 分，考试表达是 3 分。本技能把中间那 4 分补上：
> **把"我做了什么"翻译成"我运用了什么方法论"。**

## 1. 这个技能解决什么问题

你的情况（2026-08-06 自诊）：
- 基础概念知道但不透彻
- 实操强、理论弱，习惯"多学多沟通多检查"
- PMP 老思路还在，但第四版已融入 PMBOK 7 绩效域
- **写论文语言贫乏**：同样的事，别人写得比你好

核心矛盾：**经验→理论→表达 的转化通道没有建立**。

本技能提供三件东西：
1. **术语库**（references/术语库.md）：你的口语/实战表达 → 考试标准术语 → 英文 → 使用场景
2. **句式库**（references/句式库.md）：论文/案例可直接套用的高频句式模板
3. **框架库**（references/框架库.md）：每个知识域对应 1-2 个理论框架，论文中引用提升专业度

## 2. 怎么用这个技能

**场景 A：用户说"这个用考试语言怎么说" / "记术语"**
1. 在 references/术语库.md 中检索用户的实战表达，给出对应考试术语 + 英文 + 例句
2. 若未收录，现场补一条进术语库（保持本技能"越用越厚"）
3. 顺带给一个句式库中的套用示例

**场景 B：用户说"帮我写一段论文" / "怎么写论文"**
1. 明确知识域（如成本管理/进度管理/绩效域）
2. 从 框架库 取对应理论框架
3. 从 句式库 取"理论引用句 + 实践展开句 + 效果句"三段
4. 套入用户真实项目素材（从 GX-002 论文工坊的素材库取，或请用户口述）

**场景 C：用户写案例/论文后要求批改**
1. 标出"口语化表达"（如"对不上的""加班赶"）
2. 用术语库逐条替换为考试术语
3. 用句式库优化"理论引用"密度

## 4. 使用纪律（重要）

- **每学完一个知识域，回填术语**：看到教材/真题里"你认识但不会写"的词，立即加进术语库
- **论文必须引用框架**：低分论文 = 只写"我做了什么"；高分论文 = "我运用了 XX 框架/技术"
- **量化优先**：能用数字表达的（SPI=0.85、提前7天、成本节约12%）优先于形容词（很好、及时）
- **术语库是单一事实源**：不要散落在聊天记录里，全部沉淀到此技能
