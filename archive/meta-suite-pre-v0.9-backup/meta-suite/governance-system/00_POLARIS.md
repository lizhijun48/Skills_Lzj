# 北极星（Scope & Success）— v3 双轨版

> 基于 PMP + NPDP + 一级建造师 三标准融合框架。
> 服务对象定位：产品+项目双轨发展的三证专业人士。
> 更新：2026-06-06

---

## 一、服务对象（Persona）

**持有三证的双轨实践者：**

| 证书 | 对应轨道 | 核心能力域 |
|------|---------|-----------|
| **NPDP** | 产品轨（Product Track） | 新产品战略、市场研究、Stage-Gate、组合管理、产品生命周期 |
| **PMP** | 项目轨（Project Track） | 项目全生命周期管理、49 个过程、10 大知识领域、12 项原则 |
| **一级建造师** | 项目轨（工程合规维度） | 工程项目管理、中国法规体系、工程经济、合同管理、施工实务 |

**双轨特征：** 不是"产品经理"也不是"项目经理"，而是**同时承担产品决策和项目交付**的角色。日常在两条轨道间频繁切换——上午在评审产品战略（NPDP），下午在开项目进度会（PMP），晚上在看合同条款（一建）。

**核心痛点：** 两条轨道的知识体系各自独立，但实际工作中的问题往往横跨两轨。需要一个系统把三套标准融合为一套可即时调用的能力体系。

## 三、交付物定义（基于双轨的 ITTO 模式）

**产品轨交付物：**
- [ ] **机会评估报告**（PT1）：市场机会 + 战略一致性 + 初步可行性
- [ ] **商业分析报告**（PT2）：概念评估 + NPV/IRR + Stage-Gate 评审意见
- [ ] **产品规划文档**（PT3）：商业模式画布 + 价值主张 + 路线图 + Go/No-Go 决策
- [ ] **上市后评审**（PT6）：KPI 达成度 + 组合再平衡建议

**项目轨交付物：**
- [ ] **项目章程**（JT1）：项目目标 + 干系人登记册 + 高层级风险
- [ ] **项目管理计划**（JT2）：WBS + 进度 + 成本 + 质量 + 风险各子计划
- [ ] **工程文档**（JT3）：施工组织设计 + 技术交底 + 安全检查
- [ ] **竣工验收**（JT5）：验收报告 + 结算 + 保修管理

**共用层交付物：**
- [ ] **需求文档**（P3/P4）：PRD / User Story / Job Story / WWA
- [ ] **优先级矩阵**（P3）：评分表 + 排序结果 + 取舍建议
- [ ] **控制报告**（P5）：偏差分析 + 指标看板 + 纠偏措施
- [ ] **合规意见**（CX-1）：法律风险评估 + 法条引用 + 建议
- [ ] **复盘总结**（P6）：经验教训 + 行动项 + 组织资产更新

**每个交付物必须可追溯：** 标注来自哪个标准的哪个方法（NPDP §3.2 / PMBOK §5.1 / 一建经济 Ch.4），方便在正式场合引用。

## 四、边界（明确不做）

- **不做**：替代专业判断签字 — 体系提供分析和建议，不替代持证人的专业判断
- **不做**：跨标准混搭降级 — 该走 PMP 完整流程的不简化，该走法规审查的不跳过
- **不做**：无材料就硬编 — 缺关键输入必须走追问流程（ITTO 原则）
- **不做**：用产品轨的方法做项目轨的事（反之亦然） — Stage-Gate 门径不能跳过，PMP 变更控制不能省略

---

## 五、验收标准（什么叫成功）

- 双轨切换**无感**：用户说一个问题，系统自动识别走哪条轨、哪个阶段，不需要用户自己选
- 交付物**专业级**：质量达到持证人在正式场合可直接使用的水平
- 标准**可追溯**：每个分析结论标注标准出处，用户可溯源到 PMBOK/NPDP/一建原文
- 跨轨任务**能串联**：比如"从产品战略到项目落地"能打通 PT→JT 全链路
